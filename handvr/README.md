# HAND VR 🖐 — 웹캠으로 내 손을 그대로 움직이는 3D 손

웹캠이 손 21개 관절을 실시간으로 인식해서, 화면 속 **실제 사람 손 3D 모델(뼈대 리깅된 스킨 메시)** 이 내 손과 똑같이 움직입니다.
하얀 바닥, 파란 하늘, 뭉게구름, 해가 있는 곳에 **제자리로 서서 손만 움직여 보는** 화면이에요. 이동이나 물체는 없습니다.

## 실행 방법

```
# 저장소 최상위 폴더에서
python3 -m http.server 8080
# 브라우저(Chrome/Edge 권장)로 접속
http://localhost:8080/handvr/
```

- **카메라는 `https://` 또는 `http://localhost` 주소에서만 켜집니다.** (파일 더블클릭으로는 실행되지 않아요)
- 손 인식 AI(MediaPipe)와 모델(약 10MB)은 처음 실행할 때 인터넷에서 받습니다.
- 카메라 영상은 내 컴퓨터 안에서만 처리되고 밖으로 보내지 않습니다.

**잘 인식되게 하는 팁:** 밝은 곳에서, 손 전체가 카메라에 들어오게 하고, 카메라에서 40~60cm 정도 떨어져 손을 들어 주세요.
처음 손을 보여줄 때 1~2초간 편한 위치에 두면 그 거리가 “기준 거리”가 됩니다. (나중에 `K` 키로 다시 맞출 수 있어요)

## 손 — 화면 속 손이 내 손을 그대로 따라함

| 내 손 | 화면에서 |
|---|---|
| 손을 위·아래·좌·우로 움직임 | 화면 속 손이 같은 쪽으로 움직임 (거울처럼) |
| 손을 카메라 쪽으로 내밂 / 당김 | 화면 속 손이 앞으로 뻗음 / 몸 쪽으로 옴 |
| 손가락 하나하나 구부리기 | 손가락마다 펴짐 / 반쯤 / 접힘 을 판단해서 그 모양으로 구부러짐 (왼쪽 위에 표시) |
| 팔을 움직임 | 팔꿈치까지 인식해서 화면 속 팔뚝도 같은 방향으로 움직임 |
| 처음 2~3초 손가락 벌리고 손바닥 보여주기 | 손 스캔: 손가락 굵기·피부색·소매 색을 내 손에 맞춤 |

| 키 | 기능 |
|---|---|
| `K` | 손 거리·손 스캔 다시 하기 |
| `X` | 왼손·오른손 바꾸기 (손등/손바닥이 뒤집혀 보일 때) |
| `Q` | 화질: 자동(기기 성능에 맞춰 해상도·그림자·후처리 조절) → 고품질 → 보통(빠름) |
| `V` | 오른쪽 아래 카메라 화면 보이기/숨기기 |
| `H` | 도움말 |

## 구조

| 파일 | 역할 |
|---|---|
| `js/tracking.js` | 웹캠 + MediaPipe HandLandmarker·PoseLandmarker(팔꿈치) (Web Worker 에서 인식, 안 되면 메인 스레드 / GPU → 안 되면 CPU) |
| `js/track-worker.js` | 손 인식 워커 |
| `js/hands.js` | 손 관절 → 화면 좌표 변환(화면 위치 + 손 크기로 깊이 추정), One-Euro 필터로 떨림 제거, 왼손/오른손 판별, 같은 손이 두 번 잡히면 하나로 합침 |
| `js/finger-pose.js` | **손가락 모양 판단기**: 손가락마다 관절 각도와 손끝 거리(3D + 카메라 화면)로 펴짐/반쯤/접힘 판단, 이상한 프레임은 버림 |
| `js/hand-rig.js` | **리깅된 3D 손 모델** 불러오기 + Loop 세분화, 판단한 관절 각도로 뼈 회전(뼈 길이 고정), 손가락 겹침 방지, 손톱 생성, 팔꿈치 방향을 따르는 팔뚝·소매 |
| `js/skin.js` | 피부 셰이더(SSS·역광 투과, 모공·마디 주름·마디 금·손금·손등 힘줄 범프, 손가락 굵기 보정), 손톱·소매 질감 |
| `js/scan.js` | 손 스캔: 카메라 픽셀에서 손가락 마디 굵기·피부색·소매 색 측정 |
| `models/` | 손 3D 모델 `hand-left.glb`, `hand-right.glb` — WebXR Input Profiles `generic-hand` (MIT, `models/LICENSE.md`) |
| `js/world.js` | 하얀 바닥(옅은 격자), 그라디언트 하늘 + 해, 뭉게구름, 햇빛 그림자 |
| `js/main.js` | 화질 조절, HUD, 카메라 미리보기, 메인 루프 |

## 손 구현 방식

**모델:** 사람 손 형태로 만든 스킨 메시(뼈 25개, 정점별 가중치)를 불러와 한 번 세분화합니다(손당 약 4,600 정점 / 9,300 삼각형). 구나 원기둥을 이어 붙인 손이 아닙니다.

**움직임:**
1. 손목·검지·중지·새끼 뿌리 관절로 손바닥 좌표계를 만들고, 모델 손바닥을 그 회전으로 돌립니다.
2. **손가락 모양 판단** (`finger-pose.js`): 카메라 관절을 그대로 따라가지 않고, 손가락마다
   - 뿌리·둘째·끝 마디 굽힘 각도와 벌림 각도를 손바닥 좌표계에서 재고,
   - 손끝이 손목에서 얼마나 먼지(3D 추정과 카메라 화면 둘 다 보고 더 펴진 쪽)를 함께 봐서
   - **펴짐 / 반쯤 / 접힘** 을 정합니다. 문턱에 여유를 둬서 경계에서 오락가락하지 않습니다.
   - 펴짐이면 곧게, 접힘이면 자연스러운 주먹 각도 쪽으로 끌어당기고, 끝마디는 둘째 마디와 함께 굽게 합니다.
   - 엄지는 엄지 끝이 손바닥 안쪽(약지 뿌리)에 얼마나 가까운지와 두 마디 굽힘으로 판단합니다.
   - 손 크기가 갑자기 튀는 프레임은 버리고 직전 모양을 유지합니다. 손이 안 보이면 마지막 모양 그대로 사라집니다.
3. 뼈는 이 각도로만 돌리고 길이는 모델 길이 × 손 크기 × 내 마디 비율로 고정해서, 손가락이 늘어나거나 꼬이지 않습니다. 네 손가락의 벌림 순서를 지켜 서로 겹치지 않습니다.
4. 각도에는 One-Euro 필터를, 뼈 회전에는 프레임마다 slerp를 걸어서 부드럽게 움직입니다.
   - 인식은 Web Worker(별도 스레드)에서 돌아서 화면이 끊기지 않습니다. 워커를 못 쓰면 메인 스레드에서 인식합니다.
   - 왼손·오른손은 직전 위치, MediaPipe 라벨, 3D 손 모양(엄지 위치)을 함께 봅니다. 같은 손이 두 번 잡히면 하나로 합쳐서 손이 여러 개로 늘어나지 않습니다.
5. **팔:** 몸 인식(PoseLandmarker)으로 손목→팔꿈치 방향과 길이를 재서 팔뚝을 그 방향으로 놓습니다. 팔꿈치가 안 보이면 손 방향으로 추정합니다.

**피부·손톱·조명**
- 피부: 빛이 살 속에서 퍼지는 효과(SSS)와 역광일 때 손가락이 붉게 비치는 효과를 넣었습니다. 손바닥 쪽은 더 밝고, 손끝과 마디는 붉은 기가 돕니다. 모공, 손등 마디 주름, 손바닥 쪽 마디 금, 손금도 표현합니다.
- 손톱: 손끝 표면에 맞춰 휘어진 판으로 만들었습니다. 반달과 하얀 자유연이 있고, 아래 살빛이 비칩니다.
- 조명: 하늘 반사 환경광, 햇빛 그림자(고품질 4096), 블룸을 씁니다.

**한계 (솔직하게)**
- 웹캠 한 대로는 손의 절대 크기를 정확히 잴 수 없어서, 손 크기는 MediaPipe의 3D 추정값을 따릅니다.
- 손가락 굵기는 스캔값으로 모델을 손가락별로 0.85~1.2배 보정할 뿐, 손 모양을 처음부터 새로 만들지는 않습니다.
- 손톱 크기는 모델 손끝과 굵기 보정을 따릅니다. 내 손톱을 직접 인식하지는 않습니다.
- 손가락 판단은 카메라에 보이는 관절로 하므로, 손가락이 다른 손가락에 완전히 가려지면 틀릴 수 있습니다.
- 손금 위치는 일반적인 위치이고, 내 손금이 아닙니다.
- 팔꿈치는 카메라에 팔꿈치까지 보여야 따라갑니다. 위팔과 어깨는 그리지 않습니다.

고급: 주소 뒤에 `?delegate=cpu` 를 붙이면 손 인식을 CPU 로 돌립니다. `?mp=<경로>&models=<경로>` 로 MediaPipe 라이브러리와 모델을 직접 호스팅한 곳에서 받을 수도 있어요.
