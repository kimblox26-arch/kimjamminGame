# HAND VR 🖐 — 웹캠으로 내 손을 그대로 움직이는 VR 스타일 게임

웹캠이 손 21개 관절을 실시간으로 인식해서, 게임 속 **실제 사람 손 모양의 3D 손**이 내 손과 똑같이 움직입니다.
하얀 바닥, 파란 하늘, 뭉게구름, 해가 있는 맵에서 공과 풍선을 손으로 치고, 잡고, 던질 수 있어요.

## 실행 방법

```
# 저장소 최상위 폴더에서
python3 -m http.server 8080
# 브라우저(Chrome/Edge 권장)로 접속
http://localhost:8080/handvr/
```

- **카메라는 `https://` 또는 `http://localhost` 주소에서만 켜집니다.** (파일 더블클릭으로는 실행되지 않아요)
- 손 인식 AI(MediaPipe)와 모델(약 10MB)은 처음 실행할 때 인터넷에서 받습니다.
- 카메라 영상은 내 컴퓨터 안에서만 처리되고 밖으로 보내지 않습니다.
- 카메라가 없으면 “카메라 없이 시작”으로 키보드·마우스만 써서 둘러볼 수 있어요.

**잘 인식되게 하는 팁:** 밝은 곳에서, 손 전체가 카메라에 들어오게 하고, 카메라에서 40~60cm 정도 떨어져 손을 들어 주세요.
처음 손을 보여줄 때 1~2초간 편한 위치에 두면 그 거리가 “기준 거리”가 됩니다. (나중에 `K` 키로 다시 맞출 수 있어요)

## 손 — 게임 속 손이 내 손을 그대로 따라함

| 내 손 | 게임에서 |
|---|---|
| 손을 위·아래·좌·우로 움직임 | 화면 속 손이 같은 쪽으로 움직임 (거울처럼) |
| 손을 카메라 쪽으로 내밂 / 당김 | 게임 속 손이 앞으로 뻗음 / 몸 쪽으로 옴 |
| 손가락 하나하나 구부리기 | 손가락 관절이 그대로 구부러짐 |
| 손바닥·손가락으로 공·풍선 건드리기 | 물리적으로 밀리고 튕겨 나감 |
| 🤏 엄지+검지 집기, 또는 공 옆에서 ✊ 주먹 | 공·풍선 잡기 → 손을 펴면 손 움직임 속도로 **던지기** |
| 🤏 멀리 있는 공을 향해 집기 | 공이 손으로 날아옴 (원거리 잡기) |

## 이동 방법 (3가지, 같이 써도 됨)

### 1) 손 제스처로 이동 (기본 켜짐, `G` 키로 끄고 켜기)

| 제스처 | 동작 |
|---|---|
| ☝️ 검지만 펴기 (아무 손) | **앞으로 걷기**. 손가락을 왼쪽/오른쪽으로 기울이면 그쪽으로 돌면서 걷기 |
| ☝️☝️ 양손 검지 | **달리기** |
| ✌️ 브이 | **뒤로 걷기** |
| ✊ 왼손 주먹 | **이동 조이스틱**: 주먹 쥔 자리가 중심. 앞으로 밀면 전진, 당기면 후진, 좌우로 옮기면 옆걸음 |
| ✊ 오른손 주먹 | **시점 조이스틱**: 좌우로 옮기면 몸 돌리기, 위아래로 옮기면 위/아래 보기 |
| 👍 엄지척 | **점프** |
| 손을 펴기 | 멈춤 (조이스틱 해제) |

주먹 조이스틱을 쥐면 게임 화면에 파란/주황 고리가 생기고, 고리에서 손이 멀어질수록 빨리 움직여요.

### 2) 몸 추적으로 이동 (시작 화면에서 체크, 또는 `B` 키)

카메라에 **어깨까지** 보이게 앉거나 서세요. 켜면 1.5초 동안 지금 자세를 “기준 자세”로 저장합니다.

| 내 몸 | 게임에서 |
|---|---|
| 상체를 카메라 쪽으로 숙이기 | 앞으로 (많이 숙일수록 빠르게) |
| 상체를 뒤로 빼기 | 뒤로 |
| 몸을 왼쪽/오른쪽으로 기울이기 | 그쪽으로 회전 |
| 실제로 점프 (또는 몸을 빠르게 들어올리기) | 점프 |
| 몸을 낮추기 | 웅크리기 |

### 3) 키보드 · 마우스 (항상 사용 가능)

| 키 | 기능 |
|---|---|
| `W A S D` / 방향키 | 이동 (`←` `→` / `Q` `E` 회전) |
| 마우스 (화면 클릭 후) | 둘러보기 (`Esc` 로 마우스 해제) |
| `Space` / `Shift` / `C` | 점프 / 달리기 / 웅크리기 |
| `G` | 손 제스처 이동 켜기/끄기 |
| `B` | 몸 추적 켜기/끄기 |
| `K` | 기준 자세·손 거리 다시 맞추기 |
| `X` | 왼손·오른손 바꾸기 (손등/손바닥이 뒤집혀 보일 때) |
| `V` | 오른쪽 아래 카메라 화면 보이기/숨기기 |
| `R` | 공·풍선 제자리로 |
| `H` | 조작법 보기 |

## 구조

| 파일 | 역할 |
|---|---|
| `js/tracking.js` | 웹캠 + MediaPipe HandLandmarker / PoseLandmarker (GPU → 안 되면 CPU 자동 전환) |
| `js/hands.js` | 손 관절 → 게임 좌표 변환(화면 위치 + 손 크기로 깊이 추정), One-Euro 필터로 떨림 제거, 제스처 인식, 왼손/오른손 판별 |
| `js/hand-model.js` | 실제 손 형태 3D 모델: 매끈한 곡선 튜브 손가락(타원 단면·마디 굴곡), 쿠션형 손바닥, 손톱, 손목·팔뚝·소매 |
| `js/world.js` | 하얀 바닥(옅은 격자), 그라디언트 하늘 + 해, 뭉게구름, 햇빛 그림자 |
| `js/player.js` | 1인칭 이동·회전·점프·웅크리기 |
| `js/physics.js` | 탁자, 공, 풍선 물리 · 손 충돌 · 잡기/던지기/끌어오기 |
| `js/body.js` | 상체 자세 → 이동 입력 |
| `js/main.js` | 입력 합치기, HUD, 카메라 미리보기, 메인 루프 |

고급: 주소 뒤에 `?delegate=cpu` 를 붙이면 손 인식을 CPU 로 돌립니다. `?mp=<경로>&models=<경로>` 로 MediaPipe 라이브러리와 모델을 직접 호스팅한 곳에서 받을 수도 있어요.
