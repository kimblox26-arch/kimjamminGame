# HAND VR 🖐 — 웹캠으로 내 손을 그대로 움직이는 VR 스타일 게임

웹캠이 손 21개 관절을 실시간으로 인식해서, 게임 속 **실제 사람 손 3D 모델(뼈대 리깅된 스킨 메시)** 이 내 손과 똑같이 움직입니다.
하얀 바닥, 파란 하늘, 뭉게구름, 해가 있는 맵에서 공과 풍선을 손으로 치고, 잡고, 던질 수 있어요.

## 실행 방법

```
# 저장소 최상위 폴더에서
python3 -m http.server 8080
# 브라우저(Chrome/Edge 권장)로 접속
http://localhost:8080/handvr/
```

- **카메라는 `https://` 또는 `http://localhost` 주소에서만 켜집니다.** (파일 더블클릭으로는 실행되지 않아요)
- 손 인식 AI(MediaPipe)와 모델(약 10MB)은 처음 실행할 때 인터넷에서 받습니다.
- 카메라 영상은 내 컴퓨터 안에서만 처리되고 밖으로 보내지 않습니다.
- 카메라가 없으면 “카메라 없이 시작”으로 키보드·마우스만 써서 둘러볼 수 있어요.

**잘 인식되게 하는 팁:** 밝은 곳에서, 손 전체가 카메라에 들어오게 하고, 카메라에서 40~60cm 정도 떨어져 손을 들어 주세요.
처음 손을 보여줄 때 1~2초간 편한 위치에 두면 그 거리가 “기준 거리”가 됩니다. (나중에 `K` 키로 다시 맞출 수 있어요)

## 손 — 게임 속 손이 내 손을 그대로 따라함

| 내 손 | 게임에서 |
|---|---|
| 손을 위·아래·좌·우로 움직임 | 화면 속 손이 같은 쪽으로 움직임 (거울처럼) |
| 손을 카메라 쪽으로 내밂 / 당김 | 게임 속 손이 앞으로 뻗음 / 몸 쪽으로 옴 |
| 손가락 하나하나 구부리기 | 손가락 관절이 그대로 구부러짐 |
| 손바닥·손가락으로 공·풍선 건드리기 | 물리적으로 밀리고 튕겨 나감 |
| 🤏 엄지+검지 집기, 또는 공 옆에서 ✊ 주먹 | 공·풍선 잡기 → 손을 펴면 손 움직임 속도로 **던지기** |
| 🤏 멀리 있는 공을 향해 집기 | 공이 손으로 날아옴 (원거리 잡기) |

## 이동 방법 (3가지, 같이 써도 됨)

### 1) 손 제스처로 이동 (기본 켜짐, `G` 키로 끄고 켜기)

| 제스처 | 동작 |
|---|---|
| ☝️ 검지만 펴기 (아무 손) | **앞으로 걷기**. 손가락을 왼쪽/오른쪽으로 기울이면 그쪽으로 돌면서 걷기 |
| ☝️☝️ 양손 검지 | **달리기** |
| ✌️ 브이 | **뒤로 걷기** |
| ✊ 왼손 주먹 | **이동 조이스틱**: 주먹 쥔 자리가 중심. 앞으로 밀면 전진, 당기면 후진, 좌우로 옮기면 옆걸음 |
| ✊ 오른손 주먹 | **시점 조이스틱**: 좌우로 옮기면 몸 돌리기, 위아래로 옮기면 위/아래 보기 |
| 👍 엄지척 | **점프** |
| 손을 펴기 | 멈춤 (조이스틱 해제) |

주먹 조이스틱을 쥐면 게임 화면에 파란/주황 고리가 생기고, 고리에서 손이 멀어질수록 빨리 움직여요.

### 2) 몸 추적으로 이동 (시작 화면에서 체크, 또는 `B` 키)

카메라에 **어깨까지** 보이게 앉거나 서세요. 켜면 1.5초 동안 지금 자세를 “기준 자세”로 저장합니다.

| 내 몸 | 게임에서 |
|---|---|
| 상체를 카메라 쪽으로 숙이기 | 앞으로 (많이 숙일수록 빠르게) |
| 상체를 뒤로 빼기 | 뒤로 |
| 몸을 왼쪽/오른쪽으로 기울이기 | 그쪽으로 회전 |
| 실제로 점프 (또는 몸을 빠르게 들어올리기) | 점프 |
| 몸을 낮추기 | 웅크리기 |

### 3) 키보드 · 마우스 (항상 사용 가능)

| 키 | 기능 |
|---|---|
| `W A S D` / 방향키 | 이동 (`←` `→` / `Q` `E` 회전) |
| 마우스 (화면 클릭 후) | 둘러보기 (`Esc` 로 마우스 해제) |
| `Space` / `Shift` / `C` | 점프 / 달리기 / 웅크리기 |
| `G` | 손 제스처 이동 켜기/끄기 |
| `B` | 몸 추적 켜기/끄기 |
| `K` | 기준 자세·손 거리·손 스캔 다시 하기 |
| `Q` | 화질: 고품질(블룸·4096 그림자) ↔ 보통(빠름) |
| `X` | 왼손·오른손 바꾸기 (손등/손바닥이 뒤집혀 보일 때) |
| `V` | 오른쪽 아래 카메라 화면 보이기/숨기기 |
| `R` | 공·풍선 제자리로 |
| `H` | 조작법 보기 |

## 손 구현 방식

**모델:** 사람 손 형태로 만든 스킨 메시(뼈 25개, 정점별 가중치)를 불러와 한 번 세분화합니다(손당 약 4,600 정점 / 9,300 삼각형). 구나 원기둥을 이어 붙인 손이 아닙니다.

**움직임(리타기팅):**
1. 손목·검지·중지·새끼 뿌리 관절로 손바닥 좌표계를 만들고, 모델 손바닥을 그 회전으로 돌립니다.
2. 손가락 뼈는 **방향만** 카메라 관절에 맞추고, 길이는 모델 길이 × 손 크기 × 내 마디 비율(여러 프레임 중앙값, ±15%)로 고정합니다. 그래서 손가락이 프레임마다 늘었다 줄었다 하지 않습니다.
3. 뼈의 옆 방향(굽힘 축)을 손바닥 회전으로 옮겨서 정하므로 손가락이 축을 따라 꼬이지 않습니다.
4. 관절 제한
   - 둘째·셋째 마디는 굽힘 축으로만 움직이고, 굽힘 범위는 −8°~112°, −12°~88°입니다.
   - 뿌리 관절은 굽힘 −30°~98°, 벌림 ±22°로 제한합니다.
   - 네 손가락의 벌림 각 순서를 지켜서 이웃 손가락과 겹치거나 교차하지 않게 합니다.
   - 엄지는 원뿔 범위로 제한합니다.
5. 관절 좌표에는 One-Euro 필터를, 뼈 회전에는 프레임마다 slerp를 걸어서 부드럽게 움직입니다. 손 크기도 천천히만 바뀝니다.
6. 손 모양은 MediaPipe의 3D 관절(미터 단위)을 씁니다. 카메라 각도가 바뀌어도 비율이 유지됩니다.

**피부·손톱·조명**
- 피부: 빛이 살 속에서 퍼지는 효과(SSS)와 역광일 때 손가락이 붉게 비치는 효과를 넣었습니다. 손바닥 쪽은 더 밝고, 손끝과 마디는 붉은 기가 돕니다. 모공, 손등 마디 주름, 손바닥 쪽 마디 금, 손금도 표현합니다.
- 손톱: 손끝 표면에 맞춰 휘어진 판으로 만들었습니다. 반달과 하얀 자유연이 있고, 아래 살빛이 비칩니다.
- 조명: 하늘 반사 환경광, 햇빛 그림자(고품질 4096), 블룸을 씁니다.

**한계 (솔직하게)**
- 웹캠 한 대로는 손의 절대 크기를 정확히 잴 수 없어서, 손 크기는 MediaPipe의 3D 추정값을 따릅니다.
- 손가락 굵기는 스캔값으로 모델을 손가락별로 0.85~1.2배 보정할 뿐, 손 모양을 처음부터 새로 만들지는 않습니다.
- 손톱 크기는 모델 손끝과 굵기 보정을 따릅니다. 내 손톱을 직접 인식하지는 않습니다.
- 손금 위치는 일반적인 위치이고, 내 손금이 아닙니다.
- 팔뚝은 추적하지 않습니다. 손 방향과 몸 쪽 방향을 섞어 추정합니다.

고급: 주소 뒤에 `?delegate=cpu` 를 붙이면 손 인식을 CPU 로 돌립니다. `?mp=<경로>&models=<경로>` 로 MediaPipe 라이브러리와 모델을 직접 호스팅한 곳에서 받을 수도 있어요.
