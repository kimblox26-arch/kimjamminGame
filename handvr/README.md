# HAND VR 🖐 — 웹캠으로 내 손을 그대로 움직이는 3D 손

웹캠이 손 21개 관절과 팔꿈치를 실시간으로 인식해서, 화면 속 **실제 사람 손·팔 3D 조각 모델** 이 내 손과 팔처럼 움직입니다.
하얀 바닥, 파란 하늘, 뭉게구름, 해가 있는 곳에 **제자리로 서서 손만 움직여 보는** 화면이에요. 이동이나 물체는 없습니다.

## 실행 방법

```
# 저장소 최상위 폴더에서
python3 -m http.server 8080
# 브라우저(Chrome/Edge 권장)로 접속
http://localhost:8080/handvr/
```

- **카메라는 `https://` 또는 `http://localhost` 주소에서만 켜집니다.** (파일 더블클릭으로는 실행되지 않아요)
- 손 인식 AI(MediaPipe)와 모델(약 10MB)은 처음 실행할 때 인터넷에서 받습니다.
- 카메라 영상은 내 컴퓨터 안에서만 처리되고 밖으로 보내지 않습니다.

**잘 인식되게 하는 팁:** 밝은 곳에서, 손 전체가 카메라에 들어오게 하고, 카메라에서 40~60cm 정도 떨어져 손을 들어 주세요.
처음 손을 보여줄 때 1~2초간 편한 위치에 두면 그 거리가 “기준 거리”가 됩니다. (나중에 `K` 키로 다시 맞출 수 있어요)

## 손 — 화면 속 손이 내 손을 그대로 따라함

| 내 손 | 화면에서 |
|---|---|
| 손을 위·아래·좌·우로 움직임 | 화면 속 손이 같은 쪽으로 움직임 (거울처럼) |
| 손을 카메라 쪽으로 내밂 / 당김 | 화면 속 손이 앞으로 뻗음 / 몸 쪽으로 옴 |
| 손가락 하나하나 구부리기 | 손가락마다 펴짐 / 반쯤 / 접힘 을 판단해서 그 모양으로 구부러짐 (왼쪽 위에 표시) |
| 팔을 움직임 | 몸 인식으로 내 팔꿈치·어깨를 찾아서 화면 속 팔이 같은 자세로 움직임 (카메라에 팔이 보여야 함) |
| 양손 엄지·검지로 사각 틀 만들기 | 틀 안에 카메라 영상이 필터로 보임 (열화상·야간 투시경·엑스레이·만화·픽셀·무지개). 틀을 다시 만들 때마다 다음 필터 |
| 손을 빠르게 움직임 | 손 인식이 잠깐 끊겨도 몸 인식 손목을 따라 손이 이어서 움직임 (최대 0.8초) |
| 처음 2~3초 손가락 벌리고 손바닥 보여주기 | 손 스캔: 손가락 굵기·피부색을 내 손에 맞춤 |

| 키 | 기능 |
|---|---|
| `K` | 손 거리·손 스캔 다시 하기 |
| `X` | 왼손·오른손 바꾸기 (손등/손바닥이 뒤집혀 보일 때) |
| `Q` | 화질: 자동(기기 성능에 맞춰 해상도·그림자·후처리 조절) → 고품질 → 보통(빠름) |
| `V` | 오른쪽 아래 카메라 화면 보이기/숨기기 |
| `F` / `🎨 필터` | 틀 안 필터 바꾸기 |
| `C` / `📷 AR` | AR 화면: 카메라 영상을 화면 가득(거울), 손가락 틀 안만 필터 |
| `↔ 가로` 버튼 | 휴대폰에서 전체 화면 + 가로로 고정 (아이폰은 휴대폰을 직접 가로로 돌리기) |
| `H` | 도움말 |

## 베이컨 플레이어 · 각성 모드 (`player.html`)

같은 하얀 바닥 위에서 **로블록스 베이컨 헤어 캐릭터**를 움직이는 화면이에요. 카메라(웹캠)는 쓰지 않아요.
시작 화면의 **베이컨 플레이어 · 각성 모드** 버튼, 또는 `http://localhost:8080/handvr/player.html` 로 들어가요.

- **캐릭터:** R15 블록 몸(머리·위/아래 몸통·위/아래 팔·손·위/아래 다리·발), 둥근 원기둥 머리 + 기본 웃는 얼굴, 물결 모양 갈색 베이컨 머리(Pal Hair), 검은 재킷·흰 티·청바지·흰 운동화.
- **움직임:** 가만히(숨쉬기·둘러보기) · 걷기 · 달리기 · 점프 · 낙하 · 떠 있기 · 빠른 비행(주먹 앞으로) · 기 모으기 · 착지. 걸음 위상을 실제 이동 거리에 맞추고, 동작끼리 0.1초 정도로 부드럽게 섞어요.
- **아랫쪽 아이템 칸 (로블록스식):** `1` 각성 · `2` 비행 · `3` 각성 풀기. 아이콘은 모두 그림(SVG)이에요.
- **각성 4단계 (참고 영상처럼):** 각성을 누르면 기를 모으면서 점점 강해져요. 1 하늘빛 → 2 보랏빛 → 3 분홍빛 → 4 금빛(머리카락도 금빛). 모으는 중에 다시 누르면 그 단계에서 멈추고, 움직여도 멈춰요.
  - 몸을 감싸는 빛 구(가로 빛줄기가 흐름) + 둘레를 도는 작은 빛 구슬 + 위로 솟는 반짝이 + 그 단계 색으로 물든 바닥 + 하늘에 줄지어 뜬 빛 구슬
  - 기 모을 때 바닥 조각이 둥실 떠오르고, 단계가 오를 때마다 빛 돔이 터지며 바닥이 물들고 빛 고리가 퍼져요. 바닥 조각이 튀고 **바닥에 금이 가고 바닥판이 깨져 들려요**. 4단계는 화면이 하얗게 터져요
- **비행:** `F`(또는 공중에서 Space 한 번 더). Shift 로 빠르게 날면 하얗게 터지면서 **하얀 빛줄기**가 되어 긴 꼬리를 끌며 날아가요. 높은 곳에서 떨어지거나 세게 내려꽂으면 바닥이 갈라져요.

| 키 | 기능 |
|---|---|
| `W A S D` / 방향키 | 걷기 (카메라 기준) |
| `Shift` | 달리기 · 빠르게 날기 |
| `Space` | 점프 · 날 때 위로 |
| `Q` / `C` | 날 때 아래로 (가만히 누르면 착지) |
| `1` `2` `3` | 각성 · 비행 · 각성 풀기 |
| 마우스 끌기 / 휠 | 카메라 돌리기 / 확대·축소 |
| 휴대폰 | 왼쪽 아래를 끌어 이동, 오른쪽 버튼(점프·빠르게·아래로), 화면을 끌어 카메라, 두 손가락으로 확대·축소 |

| 파일 | 역할 |
|---|---|
| `js/bacon.js` | 베이컨 캐릭터 모델(둥근 블록, 얼굴 텍스처, 머리카락 가닥) + 동작 섞기 |
| `js/awaken.js` | 빛 구·빛 구슬·솟는 반짝이·바닥 빛·하늘 빛 구슬·빛 돔·빛줄기·바람 줄·충격파·먼지·불티·바닥 조각·바닥 금·깨진 바닥판 |
| `js/player-main.js` | 움직임 물리(로블록스 기본 걷기 16·점프 50·중력 196.2 스터드 기준), 비행, 각성 단계, 카메라, 아이템 칸, 소리(실시간 합성) |

## 손 구현 방식

**모델:** 어깨부터 손끝까지 한 덩어리인 사람 팔 조각 모델(약 2만 정점 / 3만 4천 삼각형)과 그 텍스처(피부색, 주름·핏줄·손톱이 담긴 노멀맵, 거칠기·AO)를 씁니다. 구나 원기둥을 이어 붙인 손이 아닙니다.
- 원본은 왼팔 하나라서 오른팔은 좌우로 뒤집어 씁니다.
- 원본에는 뼈대가 없어서, 모델을 여러 방향에서 렌더링하고 손 인식 AI 로 손 관절 21개 위치를 찾았습니다. 팔꿈치·어깨는 팔의 단면 중심선으로 정했습니다.
- 손가락 관절은 손가락 단면(메시를 자른 둘레선)의 중심으로 다시 맞춰서, 뼈가 손가락 한가운데를 지나게 했습니다.
- 스킨 가중치는 게임이 시작될 때 계산합니다.
  - 어느 손가락 살인지는 **피부 표면을 따라 잰 거리**로 정합니다. 그래서 엄지 끝 바로 아래 손바닥처럼 가깝지만 이어져 있지 않은 살이 엄지를 따라가 찢어지지 않습니다.
  - 관절마다 경계면을 두고 그 앞뒤로 두 뼈를 부드럽게 섞어서, 손·손목·팔뚝·팔꿈치가 한 피부로 이어집니다. 손톱은 섞이는 범위 밖이라 마디를 굽혀도 휘지 않습니다.

**움직임:**
1. 손목·검지·중지·새끼 뿌리 관절로 손바닥 좌표계를 만들고, 모델 손바닥을 그 회전으로 돌립니다.
2. **손가락 모양 판단** (`finger-pose.js`): 카메라 관절을 그대로 따라가지 않고, 손가락마다
   - 뿌리·둘째·끝 마디 굽힘 각도와 벌림 각도를 손바닥 좌표계에서 재고,
   - 손끝이 손목에서 얼마나 먼지(3D 추정과 카메라 화면 둘 다 보고 더 펴진 쪽)를 함께 봐서
   - **펴짐 / 반쯤 / 접힘** 을 정합니다. 문턱에 여유를 둬서 경계에서 오락가락하지 않습니다.
   - 펴짐이면 곧게, 접힘이면 자연스러운 주먹 각도 쪽으로 끌어당기고, 끝마디는 둘째 마디와 함께 굽게 합니다.
   - 엄지는 엄지 끝이 손바닥 안쪽(약지 뿌리)에 얼마나 가까운지와 두 마디 굽힘으로 판단합니다.
   - 손 크기가 갑자기 튀는 프레임은 버리고 직전 모양을 유지합니다. 손이 안 보이면 마지막 모양 그대로 사라집니다.
3. 뼈는 이 각도로만 돌리고 길이는 모델 길이 × 손 크기 × 내 마디 비율로 고정해서, 손가락이 늘어나거나 꼬이지 않습니다. 네 손가락의 벌림 순서를 지켜 서로 겹치지 않습니다.
4. 각도에는 One-Euro 필터를, 뼈 회전에는 프레임마다 slerp를 걸어서 부드럽게 움직입니다.
   - 인식은 Web Worker(별도 스레드)에서 돌아서 화면이 끊기지 않습니다. 워커를 못 쓰면 메인 스레드에서 인식합니다.
   - 왼손·오른손은 직전 위치, MediaPipe 라벨, 3D 손 모양(엄지 위치)을 함께 봅니다. 같은 손이 두 번 잡히면 하나로 합쳐서 손이 여러 개로 늘어나지 않습니다.
5. **팔:** 몸 인식(PoseLandmarker)으로 내 팔의 손목→팔꿈치, 손목→어깨 방향을 재서 화면 속 팔을 같은 자세로 놓습니다. 팔 길이는 모델 길이 × 손 크기라서 손과 비율이 맞고, 팔은 항상 손목에 붙어 있습니다.
   - 팔꿈치가 안 보이면: 몸 쪽 어깨에서 두 마디 IK 를 하고, 손목이 편하게 펴진 방향을 섞습니다. 팔꿈치가 어깨-손목 축 둘레 어느 쪽을 향할지는 팔뚝이 가장 덜 비틀리는 쪽으로 고릅니다(손을 돌리면 팔꿈치도 따라 돎).
   - 손목은 팔뚝 방향에서 70° 이상 꺾이지 않습니다.
   - 팔뚝 비틀림: 손이 돌아간 만큼 손목 쪽으로 갈수록 더 비틀립니다(최대 95°). 그보다 더 돌아간 만큼은 팔꿈치 쪽이 같이 돌아서 손목이 꼬여 가늘어지지 않습니다.
   - 팔꿈치·어깨는 천천히 따라가서 튀지 않습니다. 카메라 미리보기에 인식된 팔이 초록 선으로 보입니다.
6. **손을 놓쳤을 때:** 빠르게 움직여 손 인식이 끊기면, 최대 0.8초 동안 몸 인식의 손목이 움직인 만큼 손(마지막 손가락 모양 그대로)을 옮겨서 이어 갑니다. 손 인식은 놓친 손을 다시 찾는 기준을 조금 낮춰(0.4) 덜 끊기게 했습니다.

**손가락 틀 필터**
- 손마다 엄지·검지가 펴지고 나머지 세 손가락이 펴지지 않았으면 'ㄱ' 모양으로 봅니다. 두 손 모두 그렇다면 엄지 끝·검지 끝 4점을 이은 사각형이 틀입니다.
- 게임 화면에서는 화면 속 두 손의 손가락 끝 사이에 창이 생깁니다. 창에는 진짜 카메라 영상 중 내 손가락 끝 사이 부분을 필터로 보여 줍니다. 창은 손가락보다 1.5cm 뒤에 있어서 손가락이 틀 앞을 가립니다.
- AR 화면에서는 카메라 영상이 배경이고 틀 안만 필터입니다. 이때 3D 손은 숨깁니다.
- 열화상 필터는 피부색(붉은 기)을 '뜨겁게' 보고 밝기를 섞어 색을 매깁니다. 진짜 체온을 재는 것은 아닙니다.
- 인식이 잠깐 끊겨도 0.25초는 틀을 유지하고, 틀은 부드럽게 나타나고 사라집니다.

**피부·조명**
- 피부: 모델 텍스처의 주름·핏줄·손톱을 그대로 쓰고, 고른 피부 톤(또는 카메라로 잰 내 피부색)에 맞게 색을 곱합니다.
- 빛이 살 속에서 퍼지는 효과(SSS)와, 역광일 때 손가락이 붉게 비치는 효과를 넣었습니다.
- 모공: 가까이 볼 때만 보이는 아주 작은 요철을 피부에 붙은 좌표로 더해서, 텍스처 해상도보다 촘촘한 결이 보입니다.
- 그림자: 햇빛 그림자를 손이 있는 곳(눈앞 약 0.9m 범위)만 좁게 그려서, 손가락이 손바닥·옆 손가락에 드리우는 그림자까지 또렷합니다.
- 화질 단계는 해상도 0.85~2배, 그림자 1024~4096 입니다. 자동 모드는 기기 속도에 맞춰 조절합니다.
- 조명: 하늘 반사 환경광, 햇빛 그림자(고품질 4096), 블룸을 씁니다.

**한계 (솔직하게)**
- 웹캠 한 대로는 손의 절대 크기를 정확히 잴 수 없어서, 손 크기는 MediaPipe의 3D 추정값을 따릅니다.
- 손가락 굵기는 스캔값으로 손가락별로 0.85~1.2배만 보정합니다.
- 손 모양·손톱·주름은 조각 모델(성인 남성 팔)의 것이고, 크기·손가락 마디 길이·굵기·피부색만 내 손에 맞춥니다.
- 손가락 판단은 카메라에 보이는 관절로 하므로, 손가락이 다른 손가락에 완전히 가려지면 틀릴 수 있습니다.
- 팔은 카메라에 팔꿈치·어깨가 보여야 실제 자세를 따라갑니다. 안 보이면 자연스러운 자세로 추정합니다.
- 손을 놓쳤을 때 이어 가는 동안 손가락 모양은 멈춰 있습니다.
