# 어린이 주식 놀이터

초등학생이 게임 속 가상 코인으로 주식을 사고팔며 투자, 수익, 손실, 배당금, 분산 투자를 배우는 교육용 주식 시뮬레이션 게임입니다. 진짜 돈은 쓰지 않습니다.

## 실행 (게임 서버 열기)

```
cd stock
npm start          # 또는 node server.js
```

브라우저에서 `http://localhost:3000` 을 엽니다. 같은 와이파이의 다른 기기에서는 서버 창에 나오는 주소로 접속합니다.
포트를 바꾸려면 `PORT=8080 npm start` 처럼 실행합니다. 설치할 라이브러리는 없습니다 (Node 18 이상).

## 화면

가로 화면에 맞춰 만들었어요. 왼쪽 메뉴 버튼으로 모든 화면에 갈 수 있고, 휴대폰을 세로로 들면 가로로 돌려 달라는 안내가 나와요("세로로 그냥 할게요"로 넘길 수 있어요).

| 메뉴 | 내용 |
|---|---|
| 주식창 (홈) | 진짜 주식 프로그램처럼 꾸민 화면: 계좌 요약, 뉴스 한 줄, 관심 종목(가격이 바뀌면 깜빡임), 캔들 차트와 거래량, 5개/20개 평균선, 오늘 시가/고가/저가/거래량, 호가창, 시장가 매수/매도 주문, 실시간 체결 |
| 주식 시장 | 상장 기업 8곳(삼쏭전자, 떼슬라, GL전자, 지금자동차, SK안녕닉스, 애쁠, 마크로부드러움, 엔삐디아)의 로고, 이름, 주가, 변동률, 작은 그래프, 정렬 |
| 주식 상세 정보 | 하루/일주일/한 달 선 그래프(눌러서 가격 확인), 보유 현황, 회사 정보, 관련 소식 |
| 주식 구매 창 / 판매 창 | 수량 고르기, 필요한 돈과 남는 현금, 예상 수익/손실, 확인 창, 완료 창 |
| 뉴스 | 모든 소식 모아 보기(좋은 소식/나쁜 소식/경제 소식). 새 소식이 오면 메뉴 버튼에 숫자가 생겨요. 화면에 바로 뜨는 알림은 설정에서 켤 수 있어요. |
| 은행 | 예금 맡기기/찾기(확인 창), 매일 밤 12시에 하루 0.1% 이자, 은행과 주식 비교표, 은행 기록 |
| 내 자산 | 총자산(현금 + 주식 + 은행 예금) 그래프, 원 그래프, 분산 투자 도움말 |
| 보유 주식 | 평균 구매가, 평가 금액, 수익/손실 |
| 거래 기록 | 매수, 매도, 배당금, 은행(입금/출금/이자) 기록과 실현 수익 |
| 주식 공부하기 | 그림과 함께 보는 주식 이야기 9편(캔들 차트 읽는 법, 은행과 주식 포함), 용어 사전, 퀴즈 12문제 |
| 설정 | 이름, 게임 속도, 시간 멈추기, 뉴스 알림, 소리, 글자 크기, 밝기(자동/밝게/어둡게), 안내 창 다시 보기, 처음부터 다시 하기 |

## 게임 규칙

- 처음에 100,000 코인을 받습니다.
- 게임 시간은 1시간씩 흐르고(보통 속도에서 1.5초), 24시간이 지나면 하루가 지납니다.
- 회사마다 가격이 움직이는 정도(조용해요/보통이에요/활발해요)가 다릅니다.
- 좋은 소식과 나쁜 소식이 가끔씩 생기고, 소식은 몇 시간에 걸쳐 주가에 영향을 줍니다. 여러 회사에 함께 영향을 주는 경제 소식도 있습니다.
- 배당금을 주는 회사의 주식을 가지고 있으면 일주일(게임 속 7일)마다 배당금이 들어옵니다.
- 변동률은 어제 마감 가격과 비교합니다. 빨간색은 오름, 파란색은 내림입니다.
- 은행에 맡긴 돈은 줄어들지 않고 매일 하루 0.1% 이자가 붙습니다(1,000 코인 이상).
- 주가는 호가 단위(가격에 따라 1/5/10/50/100 코인)로 움직이고, 1시간마다 캔들(시가, 고가, 저가, 종가, 거래량)이 만들어집니다.
- 게임 기록은 브라우저(localStorage)에 저장됩니다.

## 파일

- `index.html`, `css/style.css` : 화면 틀과 디자인
- `js/data.js` : 회사, 뉴스, 용어, 공부 자료, 퀴즈, 안내 문구
- `js/art.js` : 직접 그린 아이콘, 기업 로고, 마스코트(부엉 선생님), 공부 그림 (SVG)
- `js/engine.js` : 시간, 주가 변화, 뉴스, 거래, 배당금, 저장
- `js/chart.js` : 선 그래프, 작은 그래프, 원 그래프
- `js/app.js` : 화면, 창, 알림
- `server.js` : 의존성 없는 게임 서버
- `tools/build-artifact.mjs` : 모든 파일을 한 HTML 파일로 묶어요 (`node tools/build-artifact.mjs` → `dist/index.html`). 서버 없이 파일 하나로 공유할 때 써요.
