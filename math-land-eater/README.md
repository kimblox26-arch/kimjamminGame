# 매뜨 땅먹 (Math Land Eater) 🗺️⚔️

초등 수학 문제를 풀어 **우리 학교 땅을 넓히고**, 다른 학교와 땅이 닿으면 **문제 대결로 땅을 빼앗는** 전국 학교 땅따먹기 게임입니다.

```bash
cd math-land-eater
node server.js          # 또는 npm start
# → http://localhost:3000
```
- Node.js 18 이상만 있으면 됩니다. 설치할 라이브러리는 없습니다.
- 회원·땅 정보는 `math-land-eater/data/db.json` 에 저장됩니다. (git 에는 올라가지 않음)
- 환경 변수: `PORT`(기본 3000), `DATA_DIR`(저장 폴더), `DEBUG_PASSWORD`(비밀 창 비밀번호)

## 게임 규칙
| 항목 | 내용 |
|---|---|
| 로그인 | 회원가입·로그인을 해야만 플레이할 수 있어요. |
| 나이 인증 | 가입할 때 출생연도를 고르면 학년이 자동으로 정해져요. (3월 새 학년 기준, 2026년이면 2019년생 = 1학년 … 2014년생 = 6학년) |
| 시작 전 설정 | 학교(검색 또는 직접 등록), 학년(나이 인증으로 결정), 학기, 닉네임 |
| 학년별 서버 | 1학년 서버 ~ 6학년 서버가 모두 따로 있어요. 같은 학교를 여러 명이 골라도 되고, 같은 학교 친구들은 땅을 함께 넓혀요. |
| 지도 | 한국 지도를 약 2.2km 크기의 칸 **19,870개**로 잘게 나눴어요. 전국 583개 학교가 처음 땅을 가지고 시작해요. |
| 땅 뺏기 | 땅을 누르면 **⚔️ 땅 뺏기 / 🛡️ 땅 방어하기** 버튼이 나와요. 우리 땅과 닿은 칸만 뺏을 수 있고, 한 칸에 **문제 2개**를 풀어야 해요. |
| 땅 방어 | 우리 땅을 골라 방어 수(1~20)를 정하고 그만큼 문제를 풀면 방어가 올라가요(최대 99). 방어된 땅은 **방어 수만큼** 문제를 풀어야 뺏을 수 있어요. |
| 힌트 | 문제를 틀리면 **💡 힌트보기** 버튼이 나와요. |
| 학교 본부 | 각 학교의 본부 칸(동그라미)은 빼앗기지 않아요. |

## 수학 문제
학년·학기(2022 개정 교육과정 단원)에 맞는 문제가 자동으로 만들어져요.
예) 1-1 9까지의 덧셈·뺄셈, 2-2 곱셈구구, 3-2 나눗셈과 나머지, 4-1 각도, 5-1 약수와 배수·약분, 5-2 어림하기, 6-2 비례배분·원의 넓이 …
분수 답은 `3/4`, `2와 1/3`, `2 1/3` 처럼 쓸 수 있어요.

## 파일 구성
```
math-land-eater/
├─ server.js            # 로그인, 학년별 월드, 땅 뺏기/방어, 실시간 소식(SSE)
└─ public/
   ├─ index.html, style.css
   └─ js/
      ├─ shared.js      # 한국 지도 칸 나누기, 전국 학교 목록, 출생연도→학년 (서버와 함께 사용)
      ├─ problems.js    # 학년·학기별 문제와 힌트, 답 채점
      └─ app.js         # 화면, 지도 그리기, 문제 풀기, 설정
```
