# 매뜨 땅먹 (Math Land Eater) 🗺️⚔️

초등 수학 문제를 풀어 **우리 학교 땅을 넓히고**, 다른 학교와 땅이 닿으면 **문제 대결로 땅을 빼앗는** 전국 학교 땅따먹기 게임입니다.

```bash
cd math-land-eater
node server.js          # 또는 npm start
# → http://localhost:3000
```
- Node.js 18 이상만 있으면 됩니다. 설치할 라이브러리는 없습니다.
- 회원·땅 정보는 `math-land-eater/data/db.json` 에 저장됩니다. (git 에는 올라가지 않음)
- 환경 변수: `PORT`(기본 3000), `DATA_DIR`(저장 폴더), `DEBUG_PASSWORD`(비밀 창 비밀번호), `ADMIN_PASSWORD`·`DEV_PASSWORD`(운영자·개발자 비밀번호)

## 폰 브라우저에서 하기 (서버 없이)
`node tools/build-static.js` 를 실행하면 `dist/static/` 에 서버 없이 돌아가는 판이 만들어져요.
게임 서버 역할은 `public/js/backend.js` 가 브라우저 안에서 해요.
- 계정·기록·오답 노트는 그 기기(브라우저)에 저장돼요.
- claude.ai 페이지로 올리면, 같은 링크로 들어온 친구들과 땅·소식·채팅·순위를 함께 써요. (공유 저장소를 못 쓰는 사람은 혼자 하기)
- `dist/static/index.html` 은 GitHub Pages 같은 정적 호스팅에도 그대로 올릴 수 있어요. (이때는 혼자 하기)

## 게임 규칙
| 항목 | 내용 |
|---|---|
| 로그인 | 회원가입·로그인을 해야만 플레이할 수 있어요. |
| 나이 인증 | 가입할 때 출생연도를 고르면 학년이 자동으로 정해져요. (3월 새 학년 기준, 2026년이면 2019년생 = 1학년 … 2014년생 = 6학년) |
| 시작 전 설정 | 학교(검색 또는 직접 등록), 학년(나이 인증으로 결정), 학기, 닉네임 |
| 학년별 서버 | 1학년 서버 ~ 6학년 서버가 모두 따로 있어요. 같은 학교를 여러 명이 골라도 되고, 같은 학교 친구들은 땅을 함께 넓혀요. |
| 지도 | 실제 한국 해안선(Natural Earth) 위를 **사각형·오각형·육각형…** 모양의 무작위 다각형 땅 약 **788,000칸**(한 칸 약 280m)으로 아주 촘촘하게 나눴어요. 섬은 뱃길로 이어지고(섬 끝 땅을 누르면 점선이 보여요), 바다는 아무 표시 없이 해안 가까이 얕은 물빛·물거품·모래사장으로 그려요. |
| 북한·산·섬 | **북한** 땅도 보여요(게임 칸이 없는 보기용 땅, 🗺️ 전체 보기에 한반도 전체). **산 이름과 높이**(▲, 1500m 넘으면 눈 덮인 봉우리, 산 둘레는 초록 그늘)와 **섬 이름**을 보여 줘요 (`mapdata/korea-places.txt`, `mapdata/north-korea.json`). |
| 학교 위치 | 전국 초등학교 6,303곳이 **실제 위치**에 있고, 처음엔 학교 자리 한 칸(🏫 본부)만 가져요. 나머지는 모두 **회색 빈 땅**이에요. |
| 땅 뺏기 | 땅을 누르면 **⚔️ 땅 뺏기 / 🛡️ 땅 방어하기** 버튼이 나와요. 우리 땅과 닿은 칸만 뺏을 수 있고, 한 칸에 **문제 2개**를 풀어야 해요. |
| 🚀 멀리 있는 땅 | **4학년부터**는 우리 땅과 닿지 않은 멀리 있는 땅도 **문제 50개**(방어가 더 높으면 방어 수)를 풀면 뺏을 수 있고, 거기서부터 땅을 넓힐 수 있어요. |
| 🚪 탈출길 | 다른 학교 땅과 본부에 막혀 둘레에 빈 땅이 하나도 없으면, 가장 가까운 빈 땅이 **초록 점선 탈출길**이 되어 문제 2개로 차지할 수 있어요. |
| 🏷️ 땅 팔기 | 우리 땅을 눌러 **땅 팔기** → 살 학교와 칸 수(1~30)를 골라요. 3학년까지는 그 학교 땅과 **닿아 있는 땅만**, 4학년부터는 멀리 있는 학교에도 팔 수 있어요. 산 학교는 🏷️ 땅을 눌러 **🛒 땅 사기**로 문제 없이 가져가요. (48시간 뒤 사라짐) |
| 땅 방어 | 우리 땅을 골라 방어 수(1~20)를 정하고 그만큼 문제를 풀면 방어가 올라가요(최대 99). 방어된 땅은 **방어 수만큼** 문제를 풀어야 뺏을 수 있어요. |
| 틀렸을 때 | 정답과 **💡 힌트보기**가 나오고, **한 단계 뒤로** 가서 같은 문제가 아닌 **새 문제**를 풀어요. |
| 🛠️ 운영자·개발자 | 운영자(`game-admin`)는 게임을 관리해요: 학년 서버 바꾸기, 공지 보내기, 땅·학교 땅 비우기, 가짜 학교 지우기, 채팅 지우기, 학년 서버 처음으로. 개발자(`game-developer`)는 운영자 기능 + 버그 창이 처음부터 열려 있고, **🧨 서버 초기화**(1~6학년 서버의 땅·방어·땅 팔기·소식·채팅을 모두 처음부터, 계정과 기록은 그대로)를 할 수 있어요. 일반 가입으로는 이 아이디를 만들 수 없고, 닉네임에 운영자·개발자·관리자 같은 말을 쓸 수 없어요. 비밀번호는 환경 변수 `ADMIN_PASSWORD`, `DEV_PASSWORD`로 바꿀 수 있어요. |
| 학교 본부 | 각 학교의 본부 칸(동그라미)은 빼앗기지 않아요. |

## 게임 화면
- 확대할수록 자세해지는 지도(조각 그림 캐시), 바다 물결과 바닷가 물빛, 시도 이름표
- 뺏을 수 있는 땅은 노란 점선으로 반짝, 땅을 뺏으면 색종이와 효과음 🎉
- 왼쪽 아래 작은 지도(누르면 그곳으로 이동), 학교 찾기, 학교 순위 / 친구 순위 / 실시간 소식
- 문제 창의 숫자 키패드(태블릿용), 🔥 연속 정답, 💡 힌트, 내 기록(푼 문제·뺏은 땅·올린 방어)

## 게임 기능
| 기능 | 내용 |
|---|---|
| 🏫 학교 정보 | 학교를 누르면 땅·순위·방어 합계와 같은 서버 친구 목록(접속 중 표시)을 볼 수 있어요. |
| 🌐 학교 홈페이지 | 홈페이지 주소가 있으면 바로 열고, 없으면 네이버 검색으로 찾아 줘요. 직접 등록하는 학교는 주소를 함께 쓸 수 있어요. |
| ✏️ 연습하기 | 땅과 상관없이 문제 10개를 풀어요. 푼 문제는 기록과 배지에 들어가요. |
| 📒 오답 노트 | 틀린 문제가 정답·힌트와 함께 모여요(최대 30개). 다시 풀어 맞히면 지워져요. |
| 🏅 배지 | 땅 차지, 결투 승리, 문제 풀기, 방어, 연속 정답, 출석 배지 17개 |
| 📅 출석 체크 | 하루에 한 번 접속하면 출석 일수와 연속 출석이 올라가요. |
| 💬 빠른 채팅 | 정해진 말(“여기 방어해 줘! 🛡️” 등)만 보낼 수 있어 안전해요. 우리 학교 / 전체 채널 |
| 🔑 비밀번호 바꾸기 | 설정에서 바꿀 수 있고, 다른 기기는 로그아웃돼요. |
| 🔎 지역의 모든 학교 | "호평동", "남양주시"처럼 동네·시군구 이름을 쓰면 그 지역의 모든 학교를 동네별로 보여 줘요. 게임 안에서는 "📍 우리 동네 학교", "🏙️ 우리 시·군·구 학교" 버튼도 있어요. |
| 🗺️ 지역 표시 | 지도에 **경기도** 같은 시·도 이름과 경계, 확대하면 **남양주시**(시·군·구), 더 확대하면 **호평동**(동·읍·면) 이름과 경계가 나와요. 화면 위(폰은 아래)에 "📍 경기도 › 남양주시 › 호평동"처럼 지금 보는 곳을 알려 줘요. 경계는 가까운 학교를 기준으로 한 대략적인 모양이에요. |
| 📍 동네로 학교 고르기 | 시·도 → 시·군·구 → 동·읍·면 순서로 골라 그 동네 학교를 찾아요. 직접 등록할 때도 동을 적어요. |
| ⚡ 빠르게 모드 | 폰에서는 처음부터 켜져요. 화면 선명도와 움직임 효과를 줄여 렉을 줄이고, 렉이 심하면 저절로 켜져요. 설정에서 켜고 끌 수 있어요. |
| ❓ 첫 접속 안내 | 처음 들어오면 놀이 방법을 보여 줘요. |

## 전국 모든 초등학교를 실제 위치로 넣기
학교 목록(`mapdata/schools.txt`)은 공공데이터포털 전국초중등학교위치표준데이터(2026-03-20 기준)에서 가져온 **전국 초등학교 6,303곳**(분교 포함)이에요. 학교마다 실제 위치와 동·읍·면이 들어 있어요. 새 자료로 바꾸려면:
1. 공공데이터포털 [전국초중등학교위치표준데이터](https://www.data.go.kr/data/15021148/standard.do)에서 CSV 를 내려받아요.
2. `node tools/import-schools.js 내려받은파일.csv [학교기본정보.csv]`
   - 주소에서 동·읍·면을 읽어 학교마다 동네를 붙여 줘요.
   - 나이스 교육정보 개방 포털의 "학교기본정보" CSV 를 두 번째로 주면 **학교 홈페이지 주소**도 함께 들어가요.
3. 서버를 다시 켜면 새 지도가 만들어져요. (지도가 바뀌면 땅 주인은 처음부터 다시 시작해요)

## 수학 문제
학년·학기(2022 개정 교육과정 단원)에 맞는 문제가 자동으로 만들어져요.
예) 1-1 9까지의 덧셈·뺄셈, 2-2 곱셈구구, 3-2 나눗셈과 나머지, 4-1 각도, 5-1 약수와 배수·약분, 5-2 어림하기, 6-2 비례배분·원의 넓이 …
분수 답은 `3/4`, `2와 1/3`, `2 1/3` 처럼 쓸 수 있어요.

## 파일 구성
```
math-land-eater/
├─ server.js              # 로그인, 학년별 월드, 땅 뺏기/방어, 실시간 소식(SSE)
├─ lib/mapgen.js          # 해안선 + 학교 위치 → 무작위 다각형(보로노이) 땅 만들기
├─ mapdata/
│  ├─ korea-land.json     # 한국 해안선 (Natural Earth 1:10m, 퍼블릭 도메인) + 독도
│  └─ schools.txt         # 학교 이름과 위도·경도
├─ tools/import-schools.js # 공공데이터 CSV → schools.txt
├─ tools/build-static.js  # 서버 없이 돌아가는 판 만들기 (dist/static)
└─ public/
   ├─ index.html, style.css
   └─ js/
      ├─ shared.js        # 지도 좌표계, 출생연도→학년
      ├─ problems.js      # 학년·학기별 문제와 힌트, 답 채점
      ├─ app.js           # 화면, 지도 그리기, 문제 풀기, 설정, 효과음
      └─ backend.js       # 서버 없이 돌릴 때 브라우저 안의 게임 서버
```
