# 매뜨 땅먹 (Math Land Eater) 🗺️⚔️

초등학교 1학년부터 고등학교 3학년까지, 수학 문제를 풀어 **우리 학교 땅을 넓히고**, 다른 학교와 땅이 닿으면 **문제 대결로 땅을 빼앗는** 전국 학교 땅따먹기 게임입니다.

```bash
cd math-land-eater
node server.js          # 또는 npm start
# → http://localhost:3000
```
- Node.js 18 이상만 있으면 됩니다. 설치할 라이브러리는 없습니다.
- 회원·땅 정보는 `math-land-eater/data/db.json` 에 저장됩니다. (git 에는 올라가지 않음)
- 환경 변수: `PORT`(기본 3000), `DATA_DIR`(저장 폴더), `DEBUG_PASSWORD`(비밀 창 비밀번호), `ADMIN_PASSWORD`·`DEV_PASSWORD`(운영자·개발자 비밀번호)

## 폰 브라우저에서 하기 (서버 없이)
`node tools/build-static.js` 를 실행하면 `dist/static/` 에 서버 없이 돌아가는 판이 만들어져요.
게임 서버 역할은 `public/js/backend.js` 가 브라우저 안에서 해요.
- 계정·기록·오답 노트는 그 기기(브라우저)에 저장돼요.
- claude.ai 페이지로 올리면, 같은 링크로 들어온 친구들과 땅·소식·채팅·순위를 함께 써요. (공유 저장소를 못 쓰는 사람은 혼자 하기)
- `dist/static/index.html` 은 GitHub Pages 같은 정적 호스팅에도 그대로 올릴 수 있어요. (Firebase 설정이 없으면 오프라인)
- 같은 명령이 게임 사이트도 만들어요: `dist/web/` → 저장소 맨 위 `docs/`.
  맨 위는 소개 페이지(`site/`)이고, `play/`는 게임 앱(PWA)판이에요. 앱판에는 홈 화면 아이콘(`manifest.webmanifest`)과 오프라인 저장(`sw.js`)이 들어 있어요. 개인정보처리방침(`privacy.html`)도 같이 만들어져요.
  GitHub Pages(브랜치의 `/docs`)로 올린 뒤 구글 플레이 앱으로 만드는 방법은 [`store/README.md`](store/README.md)에 있어요.

## 게임 화면
- 확대할수록 자세해지는 지도(조각 그림 캐시), 바다 물결과 바닷가 물빛, 시도 이름표
- 뺏을 수 있는 땅은 노란 점선으로 반짝, 땅을 뺏으면 색종이와 효과음 🎉
- 왼쪽 아래 작은 지도(누르면 그곳으로 이동), 학교 찾기, 학교 순위 / 친구 순위 / 실시간 소식
- 문제 창의 숫자 키패드(태블릿용), 🔥 연속 정답, 💡 힌트, 내 기록(푼 문제·뺏은 땅·올린 방어)

## 게임 기능
| 기능 | 내용 |
|---|---|
| 🏫 학교 정보 | 학교를 누르면 땅·순위·방어 합계와 같은 서버 친구 목록(접속 중 표시)을 볼 수 있어요. |

## 전국 모든 초등학교를 실제 위치로 넣기
학교 목록(`mapdata/schools.txt`)은 공공데이터포털 전국초중등학교위치표준데이터(2026-03-20 기준)에서 가져온 **전국 초등학교 6,303곳**(분교 포함)이에요. 학교마다 실제 위치와 동·읍·면이 들어 있어요. 새 자료로 바꾸려면:
1. 공공데이터포털 [전국초중등학교위치표준데이터](https://www.data.go.kr/data/15021148/standard.do)에서 CSV 를 내려받아요.
2. `node tools/import-schools.js 내려받은파일.csv [학교기본정보.csv]` (중학교는 `--level=m` → `schools-m.txt`, 고등학교는 `--level=h` → `schools-h.txt`)
   - 주소에서 동·읍·면을 읽어 학교마다 동네를 붙여 줘요.
   - 나이스 교육정보 개방 포털의 "학교기본정보" CSV 를 두 번째로 주면 **학교 홈페이지 주소**도 함께 들어가요.
3. 서버를 다시 켜면 새 지도가 만들어져요. (지도가 바뀌면 땅 주인은 처음부터 다시 시작해요)

## 수학 문제
학년·학기(2022 개정 교육과정 단원)에 맞는 문제가 자동으로 만들어져요.
예) 1-1 9까지의 덧셈·뺄셈, 2-2 곱셈구구, 3-2 나눗셈과 나머지, 4-1 각도, 5-1 약수와 배수·약분, 5-2 어림하기, 6-2 비례배분·원의 넓이 …
분수 답은 `3/4`, `2와 1/3`, `2 1/3` 처럼 쓸 수 있어요.

## 파일 구성
```
math-land-eater/
├─ server.js              # 로그인, 학년별 월드, 땅 뺏기/방어, 실시간 소식(SSE)
├─ lib/mapgen.js          # 해안선 + 학교 위치 → 무작위 다각형(보로노이) 땅 만들기
├─ mapdata/
│  ├─ korea-land.json     # 한국 해안선 (Natural Earth 1:10m, 퍼블릭 도메인) + 독도
│  └─ schools.txt         # 학교 이름과 위도·경도
├─ tools/import-schools.js # 공공데이터 CSV → schools.txt
├─ tools/build-static.js  # 서버 없이 돌아가는 판 만들기 (dist/static)
└─ public/
   ├─ index.html, style.css
   └─ js/
      ├─ shared.js        # 지도 좌표계, 출생연도→학년
      ├─ intro.js         # 인트로·로딩 화면 (한반도 땅따먹기 애니메이션, 진행률, 팁)
      ├─ problems.js      # 학년·학기별 문제와 힌트, 답 채점
      ├─ app.js           # 화면, 지도 그리기, 문제 풀기, 설정, 효과음
      └─ backend.js       # 서버 없이 돌릴 때 브라우저 안의 게임 서버
```
