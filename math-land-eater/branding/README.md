## 홍보 영상 (`promo.mp4`) — 쇼츠 · 틱톡 · 릴스용
세로 1080×1920, **22.5초**, 30fps. 배경 음악과 효과음은 코드로 직접 만든 소리라 저작권 걱정이 없어요. 표지는 `promo-cover.jpg`(첫 장면)예요.
영상은 `tools/promo/` 로 다시 만들 수 있어요 (진짜 게임 화면을 찍어서 박자에 맞춰 이어 붙여요).

알고리즘에 잘 뜨게 만든 점
- **첫 1초 승부**: 화면이 뜨자마자 "3초 안에 풀면 이 땅 우리 학교 거!" + `8 × 7 = ?` 문제와 3·2·1 초읽기 → 보는 사람이 직접 풀게 돼서 끝까지 봐요.
- **박자마다 장면 전환**(128 BPM): 0.5~1초마다 화면이 바뀌어 지루할 틈이 없어요.
- **소리 없이 봐도 이해되게**: 모든 장면에 큰 자막 (쇼츠 · 틱톡 아래쪽 글자 · 오른쪽 버튼에 안 가리게 위쪽에 배치).
- **티어가 줄줄이 오르는 장면**: 브론즈 → … → 아크블랙 네메시스까지 반 박마다 '띵!' (가장 짜릿한 구간).
- **댓글 유도**: 마지막에 "댓글에 우리 학교 이름 남겨줘 👇" → 댓글이 많을수록 더 많이 퍼져요.
- **무한 반복**: 끝 장면이 첫 장면으로 자연스럽게 이어져서 다시 보기(시청 시간)가 늘어요.

장면 순서
1. 0~3초: 3초 안에 풀면 이 땅 우리 학교 거! (8 × 7 = ?, 3·2·1) → 정답 56! 땅 획득 🎉
2. 진짜 한반도 지도 위 전국 초·중·고 11,983곳 (숫자가 올라가요)
3. 다른 학교 땅도 문제 풀어 뺏기 ⚔️ · 내 학년 문제만
4. 실시간 1:1 수학 배틀 🔥 (VS → 승리 · 승급)
5. 랭크 티어 올려 볼까? (8단계가 차례로)
6. 주말엔 전국 학교 대항전 🏟️ · 남산타워 · 독도 · 한라산 랜드마크 쟁탈전
7. 보스 잡고 모험 떠나기 · 시즌 패스 보상 · 우리 학교는 전국 몇 등?
