# 매뜨 땅먹 — 구글 플레이에 올리기

구글 플레이 개발자 계정은 **만 18세 이상만** 만들 수 있어요. 아래 과정은 **부모님과 함께** 해 주세요.

## 이 폴더에 있는 것

| 파일 | 쓰는 곳 |
| --- | --- |
| `icon-512.png` | 앱 아이콘 (512×512) |
| `feature-graphic.png` | 그래픽 이미지 (1024×500) |
| `screen-1.png` ~ `screen-4.png` | 휴대전화 스크린샷 (1080×1920) |
| `privacy.html` | 개인정보처리방침 (웹에는 `docs/privacy.html`로 올라가요) |

게임 사이트는 저장소 맨 위 `docs/` 폴더에 있어요. 맨 위 주소는 소개 페이지이고, 게임은 `play/`에 있어요. 게임을 고친 뒤에는 `node tools/build-static.js`를 실행하면 `docs/`가 새로 만들어져요.

## 1단계: 나만의 무료 주소로 올리기 (GitHub Pages)

1. GitHub 단체 `math-land-eater` 안에 이름이 `math-land-eater.github.io`인 **Public** 저장소가 있어요.
2. `docs/` 폴더의 내용을 그 저장소 맨 위(`main` 브랜치)에 그대로 올려요. 이 저장소는 GitHub가 Pages를 자동으로 켜 줘요.
3. 몇 분 뒤 `https://math-land-eater.github.io/` 에서 소개 페이지가 열리고, 게임은 `https://math-land-eater.github.io/play/` 에서 열려요.
4. 폰 크롬으로 열고 **홈 화면에 추가**를 하면 바로 앱처럼 쓸 수 있어요.

⚠️ `docs/privacy.html`의 **[보호자 연락 이메일을 여기에 적어 주세요]** 부분을 보호자 이메일로 바꾼 뒤 다시 올려 주세요. 구글 플레이 심사에 꼭 필요해요.

## 2단계: 앱 파일 만들기 (PWABuilder)

1. https://www.pwabuilder.com 에 게임 주소(`https://math-land-eater.github.io/play/`)를 넣고 **Start**를 눌러요.
2. **Package For Stores → Android → Google Play**를 골라요.
   - Package ID 예: `io.github.mathlandeater.twa`
   - App name: `매뜨 땅먹`
3. 받은 zip 파일 안에 이런 파일이 있어요.
   - `*.aab`: 구글 플레이에 올리는 앱 파일
   - `signing.keystore`, `signing-key-info.txt`: **서명 열쇠**. 잃어버리면 앱을 업데이트할 수 없어요. 꼭 안전한 곳에 따로 보관해 주세요.
   - `assetlinks.json`: 앱 위쪽의 주소창을 없애 주는 파일
4. 주소창을 없애려면 `assetlinks.json`을 `math-land-eater.github.io` 저장소의 `.well-known/assetlinks.json`에 올려요.
   - 안 올려도 앱은 잘 돌아가요. 대신 위쪽에 작은 주소창이 보여요.

## 3단계: 구글 플레이 콘솔

1. https://play.google.com/console 에서 **보호자 이름으로** 개발자 계정을 만들어요. 등록비 25달러를 한 번 내고, 신분 확인을 해요.
2. **앱 만들기**: 이름 `매뜨 땅먹`, 기본 언어 한국어, 게임, 무료.
3. **새 개인 계정의 테스트 규칙**: 정식 출시 전에 **비공개 테스트에 테스터 12명 이상**이 **14일 동안 계속** 참여해야 해요.
   - 테스터는 가족이나 친구의 구글 계정 이메일로 초대해요.
   - 14일이 지나면 **프로덕션 출시 신청**을 할 수 있어요.
4. **앱 콘텐츠**에서 아래 항목을 채워요.
   - 개인정보처리방침: `https://math-land-eater.github.io/privacy.html`
   - 광고: 없음
   - 타겟층: 6~8세, 9~12세. 어린이가 대상이라 **가족 정책**을 지켜야 해요. 이 게임은 광고가 없고, 채팅은 정해진 문장만 쓸 수 있어요.
   - 데이터 보안: "수집하는 데이터 없음"을 골라요. 게임 정보는 기기 안에만 저장되고 서버로 보내지 않아요.
   - 콘텐츠 등급 설문: 폭력·도박 등 없음 → 전체이용가
5. **스토어 등록정보**에 아래 글과 이 폴더의 이미지를 넣어요.
6. 비공개 테스트 트랙에 `.aab`를 올리고 → 테스터를 초대하고 → 14일 뒤 프로덕션으로 출시해요.

- 땅 방어를 올려서 다른 학교로부터 우리 땅을 지켜요.

■ 힌트와 오답 노트
모르는 문제는 힌트를 보고, 틀린 문제는 오답 노트에 모여서 다시 풀 수 있어요.

■ 배지와 랭킹표
연속 정답 불꽃, 출석 배지, 학교·학생·시도 랭킹표로 실력을 확인해요.

■ 안심하고 쓰는 게임
- 광고가 없어요.
- 채팅은 정해진 문장만 쓸 수 있어요.
- 게임 정보는 내 기기 안에만 저장돼요.
