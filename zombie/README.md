# 서울 감염 — DAY ZERO 🧟

서울에서 감염이 시작된 날, 집에 있던 주인공이 **긴급재난문자**에 깨어나 살아남는 1인칭 좀비 서바이벌 웹 게임입니다.
설치 없이 브라우저에서 실행되며, three.js(저장소 `vendor/` 포함)만 사용합니다.

```
저장소 루트에서:  python3 -m http.server 8080
브라우저:        http://localhost:8080/zombie/
```

## 흐름
1. **인트로 애니메이션** (메뉴 버튼 외 모든 UI 숨김) — 오전 8시 재난문자 경보음 → 눈을 뜨고 휴대폰 확인 → 창밖에서 감염자가 시민을 쫓아 물어뜯는 장면 → TV 속보(앵커·현장 기자). 메뉴에서 건너뛸 수 있습니다.
2. **튜토리얼** — 끝나면 화면 가운데에 첫 할 일 "물 모으기"가 뜹니다. 실제 재난 대비 순서대로 진행:
   물 모으기(욕조·페트병) → 식량 확인 → 현관 봉쇄(잠금·신발장 바리케이드) → 빛과 소리 줄이기 → 생존 물품(손전등·구급상자·방망이) → 라디오 재난방송 → 탈출
3. **오픈월드** — 대피소(새빛초등학교) → 수원 군 집결지(약 34km) → 부산항(약 325km).

## 특징
- **대한민국 1:1 맵**: 실제 위경도로 만든 해안선·제주도·휴전선, 40여 개 도시(도시 규모별 밀도), 한강·낙동강·금강·영산강, 북한산·지리산·설악산·한라산 등 산, 태백·소백산맥, 경부·서해안·호남·영동 등 고속도로. 240m 청크 스트리밍 + 원경 지형(약 14km).
- **도시**: 아파트 단지(동 번호), 상가와 한글 간판, 들어갈 수 있는 편의점(전리품), 빌라·주택, 은행나무 가로수, 교회 네온 십자가, 방치 차량, 피난 정체 고속도로. 시골은 논·곤포 사일리지·비닐하우스·숲.
- **좀비**: 21개 본 스키닝 인체(관절 블렌딩), 절차적 애니메이션 — 절뚝임, 고개 꺾임, 팔 뻗기, **달리는 좀비**, 공격, 섭식, 사망 낙하, 죽은 시민이 다시 일어남. 시각/청각 감지, 계단을 올라오고(내비 그래프), 문을 부숨.
- **감정 시스템**: 공포·스트레스·희망 → 심장박동/숨소리, 화면 비네팅·색수차·손 떨림·조준 흔들림, 상황별 독백(음성).
- **생존**: 체력·기력·배고픔·갈증(굶거나 목말라서 죽지는 않음, 기력·스트레스에 영향), 아이템, 근접무기/총, 손전등, 차량 운전.
- **시간**: 좌상단에 연도·날짜·시간 표시, **현실 1초 = 게임 1분**. 11월 서울 일출/일몰, 밤에는 정전·더 많은 달리는 좀비, 비.
- **소리**: 전부 실시간 합성 3D 사운드(HRTF·거리 감쇠·음속 지연·실내/실외 잔향) — 재난문자음, 비명, 좀비 신음, 총성, 물, 사이렌, 헬기, 개, 까마귀, 폭발 등. `sounds/`에 실제 녹음을 넣어 교체 가능.
- **목소리**: 브라우저 한국어 TTS로 주인공·앵커·라디오·군인 대사 + 자막.
- **그래픽**: PBR + ACES 톤매핑, 실시간 그림자, 하늘 환경광, 블룸·컬러그레이딩·필름 그레인·비네팅, 노출 적응.
- **최적화 모드**: 타이틀/메뉴에서 켜면 해상도·그림자·후처리·시야·좀비 수를 낮춥니다. 품질 4단계.

## 조작
| 키 | 기능 |
|---|---|
| WASD / Shift / C / Space | 이동 / 달리기 / 앉기 / 점프 |
| 마우스 왼쪽 / 오른쪽 | 공격·사격 / 조준 |
| E (길게) | 상호작용 |
| 1~5, R | 무기 선택, 재장전 |
| F | 손전등 |
| H / X / Z | 치료 / 먹기 / 마시기 |
| Tab / M / Esc | 가방 / 지도 / 메뉴 |
| 차량 | W/S 가속·후진, A/D 조향, Space 브레이크, E 하차 |

## 한계 (솔직하게)
- 외부 3D 모델·사진 텍스처 없이 코드로 생성하므로 영화 같은 "실사"에는 못 미칩니다. 브라우저에서 가능한 범위의 PBR 조명과 후처리로 최대한 사실적으로 만들었습니다.
- TTS 음성 품질은 OS/브라우저에 따라 다릅니다(크롬·엣지 권장). 한국어 음성이 없으면 자막만 나옵니다.
- 맵은 실제 지형 데이터가 아닌 실제 좌표 기반 근사입니다. 실제 건물·도로 배치와는 다릅니다.
- 데스크톱(키보드·마우스) 전용입니다.
