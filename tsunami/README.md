# 🌊 해랑시 쓰나미 — 물리 기반 쓰나미 재난 시뮬레이터

지도에서 **바다를 터치**하면 그 지점에서 쓰나미가 발생합니다.
파도가 퍼져 해안에 부딪히고, 육지가 침수되고, 건물이 무너지고, 사람들이 감정을 느끼며 도망칩니다.
**지도 모드**로 침수를 내려다보거나, **사람 모드(1인칭)**로 도시 안에서 쓰나미를 맞이할 수 있습니다.

```
저장소 루트에서 웹서버 실행 후 /tsunami/ 로 접속
  python3 -m http.server 8080     →  http://localhost:8080/tsunami/
```
> three.js 는 저장소의 `vendor/` 를 공유하므로 인터넷 없이도 동작합니다 (글꼴만 온라인).
> `?q=low|medium|high|ultra` 로 품질을 강제할 수 있습니다. 모바일은 자동으로 `낮음`.

## 1. 무엇을 할 수 있나

| 기능 | 내용 |
|---|---|
| 쓰나미 발생 | 지도에서 바다를 터치. 발생원 4종 — **해저 지진**(단층 융기·침강, 먼저 바닷물이 빠짐) · **해저 산사태**(국지적 고파) · **운석 충돌**(물기둥·충격파·동심원 파) · **원거리 해일**(해안과 나란한 진행파). 규모 슬라이더, 여러 번 터치해 중첩 가능 |
| 지도 모드 | 드래그 이동 · 휠/핀치 확대 · 우클릭/두 손가락 회전·기울기. **침수 지도**(최대 침수심 색상), **구 경계**, 사람들의 **감정 색 점**, 대피소 표시 |
| 사람 모드 | 육지를 터치해 그 자리에서 1인칭 시작. 걷기·달리기(체력)·점프, 고층 건물 앞에서 **E** → 계단으로 옥상 대피. 휩쓸리면 헤엄쳐 건물·얕은 곳으로 탈출. 심박·공포가 화면(비네트·심장 소리)에 드러남 |
| 관찰 모드 | 사람을 터치 → 인물 카드(이름·나이·성격·감정·심박·일행) → **이 사람 시점**으로 그 사람의 눈으로 대피 과정을 봄 |
| 구(區) | 항구구 · 강변구 · 해변구 · 중앙구 · 등대곶구 · 산마루구 — 구마다 건물 양식·인구 구성이 다르고, 상황판에서 **구별 대피율·침수율·붕괴 건물**을 실시간 집계 |
| 경보 | 지진 감지 또는 해상 부이 이상 수위 → 사이렌 + **긴급재난문자**(휴대폰 알림). 끄고 비교해 볼 수 있음 |

## 2. 사람들 — 구별 · 감정 · 행동

- **구별**: 어린이 · 청소년 · 성인 남성 · 성인 여성 · 노인 / 관광객 · 주민 · 회사원 · 학생 · 항만 노동자 · 어부 · 상인 · 은퇴자 · 서퍼.
  키·체격·피부·머리·옷(작업복+안전모, 교복, 정장, 수영복…)이 다르고, 걷기/달리기 속도·체력·물살에 버티는 한계(수심×유속)가 다릅니다.
- **성격**: 침착성 · 이타심 · 호기심 · 재난 대비성 · 정상화 편향 — 같은 상황에서도 반응이 달라집니다.
- **감정 11종**: 평온 🙂 · 호기심 🤔 · 당황 😕 · 불안 😟 · 공포 😨 · 패닉 😱 · 결연 😤 · 얼어붙음 😶 · 허우적 🆘 · 안도 😮‍💨 · 슬픔 😢 — 머리 위 말풍선과 대사로 표시.
- **인지**: 지진 흔들림, 사이렌, 재난문자(휴대폰 소지자), 바다 쪽 파도·침수 목격(거리·높이), 바닷물이 빠지는 현상, 주변 사람의 대피 행렬.
- **행동**: 지진 중 웅크리기 → 판단 지연(정상화 편향) → 대피(달리기·체력 고갈·넘어짐) / 바닷물이 빠지면 구경하러 가는 사람 / 가족은 함께, 리더는 가장 느린 가족에 맞춤 / 이타적인 사람은 근처 노인·아이를 부축 / 공포에 얼어붙음 / 공포의 전염 / 고지대 도착 시 안도, 가족을 잃으면 슬픔 / 옥상에서 손 흔들며 구조 요청 / 휩쓸리면 허우적대며 헤엄 → 건물 지붕을 붙잡거나 얕은 곳에서 탈출, 오래 휩쓸리면 실종.
- **대피 경로**: 10 m 격자 다익스트라 거리장 — 지역 주민은 고지대 + 지정 대피 건물(수직 대피), 관광객은 고지대만 압니다.

## 3. 물리 모델

```
비선형 천수방정식 (엇갈린 격자 Arakawa C, 192²~384² 셀, 셀 크기 10~21 m)
  ∂h/∂t + ∇·(h u) = 0
  ∂u/∂t + (u·∇)u = −g ∇η − g n² |u| u / h^{4/3}
  ├ 정수압 재구성 상류 플럭스 + 유출 제한기 → 질량 보존, 음수 수심 없음, 침수/건조
  ├ 반암시적 매닝 마찰 (바다 0.025, 육지 0.035, 주택가 0.075, 숲 0.055)
  ├ 건물 = 고체 셀 (붕괴 시 해제되어 물이 흘러듦)
  ├ 개방 경계 스펀지 흡수층, CFL 조건으로 서브스텝 분할
  └ 프루드 수 쇄파 판정·수렴 흐름 → 거품, 육지 통과 흐름 → 흙탕물(이류) · 퇴적 흔적

건물 손상: 압력 지표 P = ½gh² + h|u|² 가 구조 강도(목조 주택 ≪ 상가 < 창고 < 철근콘크리트)를 넘으면 손상 누적 → 붕괴 · 잔해 생성
표류물: 자동차(~0.55 m 수심에서 부양) · 컨테이너(적재 지지) · 어선 · 화물선 · 잔해 — 부력, 상대유속 제곱 항력, 접지 쿨롱 마찰, 건물 충돌 에너지 → 건물 손상
사람 안정성: 수심×유속 한계(어린이 0.22 · 노인 0.3 · 성인 0.5~0.65 m²/s) 또는 부양 수심 초과 시 휩쓸림
```

렌더링: PBR + ACES 톤매핑, 대기 산란 하늘(`src/world/sky.js` 공유), 시뮬레이션 수위·유속·거품·흙탕물로 변위·채색되는 수면 셰이더(프레넬 반사, 흐름 따라 움직이는 잔물결, 파봉 투과광, 해안 쇄파 띠), 젖은 지면·퇴적 흔적, 절차적 건물 파사드(창문·야간 조명), 실시간 그림자, 물보라/충돌 물기둥 파티클, 관절 애니메이션 인물(걷기·달리기·웅크림·허우적·손 흔들기·촬영·울기).

소리: 전부 WebAudio 합성 — 파도 · 바람 · 지진 굉음 · 쓰나미 포효 · 사이렌 · 군중 · 비명 · 붕괴 · 심장박동 · 재난문자 알림 · 새소리 · 수중 먹먹함.

## 5. 구조

```
tsunami/
  index.html, style.css
  js/
    main.js      게임 루프 · 모드 · 사건(지진·경보·도달) · 카메라 · 환경 · 소리 연결
    config.js    품질 프리셋 · 구 · 감정 · 인물 유형 · 대사
    geo.js       해안선·해저·하천·언덕·항만·방파제의 해석적 지형 정의, 구 판정
    terrain.js   하이트필드 메시 · 정확한 지면 질의 · 지형 셰이더(젖음·침수 지도·구 경계)
    swe.js       천수방정식 솔버 · 발생원 · 추적자 · 위협 지도
    water.js     수면 셰이더 (시뮬레이션 상태 보간)
    city.js      도로 · 건물(파사드 셰이더) · 나무 · 시설물 · 유체력 손상
    nav.js       대피 거리장 (다익스트라)
    bodies.js    표류물 물리
    people.js    군중 AI · 감정 · 관절 애니메이션
    player.js    1인칭 조작
    controls.js  입력 · 지도 카메라
    fx.js        물보라 · 운석 · 충격파
    audio.js     합성 사운드
    ui.js        패널 · 상황판 · 말풍선 · 인물 카드 · 미니맵
```

콘솔에서 `__TSUNAMI__` 로 게임 인스턴스에 접근할 수 있고, `__TSUNAMI__.trigger('quake', 0, 1200, 0.7)` 로 발생원을 만들고
`__TSUNAMI__.debugStep(초)` 로 렌더 없이 물리·사람을 진행시킬 수 있습니다.
