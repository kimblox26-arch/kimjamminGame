# 해랑시 쓰나미 — 물리 기반 쓰나미 재난 시뮬레이터

**세계지도**에서 바다를 누르면 그 자리에 설정 카드가 열립니다. 종류(지진·산사태·운석)와 **높이 · 크기 · 방향**을 정하고 **발생**을 누르면,
쓰나미가 실제 수심을 따라 대양을 건너 퍼지고, 가상의 도시 **해랑시**(한반도 남동 해안)에 도달하면 도시가 침수됩니다.
도시는 **2D 지도**, **3D**, **사람 모드(1인칭)**, **다른 사람의 시점**으로 볼 수 있습니다.

```
저장소 루트에서 웹서버 실행 후 /tsunami/ 로 접속
  python3 -m http.server 8080     →  http://localhost:8080/tsunami/
```
> three.js 는 저장소의 `vendor/` 를 공유합니다 (글꼴만 온라인). `?q=low|medium|high|ultra` 로 품질 강제, 모바일은 자동 `낮음`.

## 1. 화면

| 보기 | 내용 |
|---|---|
| 세계 | Natural Earth 해안선·수심 기반 2D 세계지도. 바다 터치 → 설정 카드(미리보기 타원, 모멘트 규모 Mw·에너지·**해랑시 도달 예상 시간**). 파고 색, 최대 파고 해안 발광, 1시간 등시선. 해랑시 표지에 남은 시간 |
| 도시 | 위에서 본 2D 지도: 지형 음영·도로·건물(붕괴 표시)·사람 점·침수/흙탕물/거품. 바다 터치 → 도시 앞바다 쓰나미, 사람 터치 → 그 사람의 시점, 육지 터치 → 그 자리에서 사람 모드 |
| 3D | 궤도 카메라로 도시 전체 |
| 사람 | 1인칭. 걷기·달리기(체력)·점프, 고층 건물 앞에서 E → 옥상 대피 |

상단에는 모드 전환 · 시각/경과 시간 · 재생/일시정지 · 배속(세계 1분/초~1시간/초, 도시 1×~10×) · 설정만 있습니다.
쓰나미가 도시에 20분 이내로 다가오면 세계지도 배속이 자동으로 10× 이하로 묶여 도시 시뮬레이션이 함께 진행됩니다.
아이콘과 감정 얼굴은 모두 직접 그린 SVG 입니다(이모지 없음).

## 2. 물리

```
전 지구: 구면 선형 장파 방정식 (MOST/COMCOT 방식, 엇갈린 격자, 코리올리, 수심 200 m 이하 매닝 마찰)
  1024×512 격자(저사양 512×256), CFL 시간 간격, 웹 워커에서 계산 · 극지방 흡수층
  발생원: 지진 = 단층 길이 L × 폭 W 의 융기/침강 쌍, Mw = ⅔(log₁₀M₀ − 9.1), M₀ = μ·L·W·미끄럼
          산사태 = 쌍극자, 운석 = 공동 + 테두리
  도달 시간: 관측점에서 다익스트라(이동 비용 = 거리/√(gh)) — 가역성으로 '발생원→도시' 시간
도시: 비선형 천수방정식 (Arakawa C, 192²~384² 셀, 침수/건조, 매닝 마찰, 건물 = 고체 셀)
  둥지 결합: 전 지구 관측점 수위 × 그린 법칙 (D_관측/D_경계)^¼ 를 외해 경계에서 수위·진행파 유속 η√(g/h) 로 강제
건물: 압력 지표 ½gh² + h|u|² > 구조 강도 → 손상 누적 → 붕괴
유리창: 침수 높이·하중이 유리 한계를 넘는 층까지 파손(지진 시 일부) → 파편: 중력·공기저항·반발·물에서 표류
전신주: 밑동 항력 ½ρC_dDhu² 초과 → 강체 막대 전도 θ'' = (3g/2L)sinθ → 단선, 아크·불꽃, 활선 끝 주변 물 감전(반경 18 m),
        보호 계전기 차단 → 구역 정전(야간 창문 조명 꺼짐)
공: 배구공·비치볼 — 포물선(중력), 놓치면 자유 물체: 반발, 아르키메데스 부력, 흐름 항력으로 떠내려감
표류물: 자동차·컨테이너·어선 — 부력, 상대유속 항력, 쿨롱 마찰, 건물 충돌
파도: 바람 파랑(분산 ω=√(gk)) + 9초 너울의 천수(그린 법칙)·수심 한계 쇄파(H>0.78h)·보어·스워시, 코스틱, 셀룰러 거품
```

## 3. 사람

- **몸**: 해부학적 프리미티브의 부드러운 합집합 SDF → Surface Nets 다각형화 → 스킨 가중치 (`js/humans/body.js`).
  체형 5종(남·여·어린이·노년 남·노년 여) × LOD 3단계를 `tools/bake-humans.mjs` 로 미리 구워 `data/humans/` 에 저장.
- **렌더링**: GPU 스키닝(뼈 행렬 데이터 텍스처, 사람당 한 줄) 인스턴싱. 옷(소매·바지 길이·데님·주머니 티·줄무늬 운동화·손목시계),
  수영복, 머리 모양·모자, 얼굴(눈·눈썹·입·짧은 수염)과 **표정**(평온·웃음·공포·패닉·슬픔·고통)을 셰이더로 칠함.
- **동작**: 걷기는 사용자 제공 참고 자료(Renderpeople 걷기 애니메이션)에서 추출한 **모션캡처 관절각 곡선**(고관절·무릎·발목·어깨·팔꿈치·골반 회전/기울기/상하/좌우, 몸통 반대 회전)을 속도에 맞춰 재생,
  달리기는 체공기를 가진 절차적 보행으로 부드럽게 전환. 실제 지면 속도로 위상을 진행해 발이 미끄러지지 않음.
  그 밖에 앉기·모래 위 앉기·엎드려/누워 일광욕·선베드·자유형 수영·입영·허우적·웅크림·지진 시 머리 감싸기·모래성 쌓기·던지기·받기·배구(토스/스파이크 점프)·손 흔들기·휴대폰/셀카·넘어짐·감전 경련·울기·오르기·안기 — 0.35초 교차 페이드.
- **평소 생활**: 해수욕장 파라솔(줄무늬)·수건·선베드·모래성, 배구장 2면에서 2:2 배구, 공 던지기, 물놀이, 셀카, 산책·조깅.
  대피가 시작되면 누워 있던 사람은 일어나는 데 시간이 걸리고, 공은 그 자리에서 물리 물체가 됩니다.
- **구별·감정·인지·행동**: 나이·성별·직업·체격·성격(침착성·이타심·호기심·대비성·정상화 편향), 감정 11종, 사이렌·재난문자·목격·공포 전염,
  가족 단위 대피·부축·얼어붙음·넘어짐·수직 대피·휩쓸림·감전.

## 4. 구조

```
tsunami/
  index.html, style.css
  data/world/   세계 수심·육지·경계선 (Natural Earth 가공)
  data/humans/  구운 인체 메시
  tools/bake-humans.mjs
  js/
    main.js        게임 루프 · 모드 · 사건 · 전 지구↔도시 결합 · 카메라 · 소리
    ui.js, icons.js  화면 UI · SVG 아이콘/감정 얼굴
    world/         worlddata.js · worldmap.js(2D 세계지도) · globalsim.js · globalswe.worker.js
    city2d.js      도시 2D 지도
    swe.js water.js terrain.js city.js nav.js bodies.js hazards.js fx.js audio.js geo.js config.js
    people.js      군중 AI · 감정 · 놀이 · 동작 선택
    humans/        body.js(인체 생성) · anim.js(동작·모션캡처 보행·순운동학) · crowd.js(GPU 스키닝 렌더러)
    player.js controls.js
```

콘솔: `__TSUNAMI__.launch({ kind: 'world', type: 'quake', lon: 133.5, lat: 37.6, height: 6, size: 400, strike: 30 })`,
`__TSUNAMI__.debugStep(초)` 로 렌더 없이 도시 물리·사람 진행.

## 5. 한계

절차적으로 만든 사람은 실제 사람과 구별이 안 될 정도는 아닙니다(특히 가까이서 본 얼굴). 세계 격자는 약 39 km 간격이라 만·해협의 국지 증폭은
도시 모델에서만 계산됩니다. 실제 GPU 프레임률은 기기에 따라 다릅니다.
