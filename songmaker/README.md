# KIM 송메이커 — 격자를 눌러 만드는 웹 작곡기

칸을 눌러 멜로디를 찍고, 아래 두 줄로 리듬을 넣은 뒤 ▶ 를 누르면 바로 연주됩니다.
소리는 전부 WebAudio로 실시간 합성해서 외부 라이브러리나 음원 파일이 필요 없어요.

```
# 저장소 최상위 폴더에서
python3 -m http.server 8080
http://localhost:8080/songmaker/
```

## 사용법
| 동작 | 결과 |
|---|---|
| 칸 클릭 / 드래그 | 음표 그리기 (이미 있는 칸에서 시작하면 지우기) |
| 아래 ▲ 줄 / ● 줄 | 높은 타악기 / 낮은 타악기 |
| `Space` | 재생 / 정지 |
| `Ctrl+Z` | 되돌리기 |
| 휠 · 두 손가락 드래그(모바일) | 화면 이동 |

- **악기**: 피아노 · 마림바 · 현악기 · 관악기 · 신시사이저 (버튼을 누를 때마다 바뀜)
- **리듬**: 일렉트로닉 · 드럼 세트 · 우드블록 · 콩가
- **템포**: 40 ~ 240 BPM
- **길이 · 높이**: 아래 막대에서 − / + 를 누르거나 숫자를 직접 입력 (길이 1~64마디, 높이 2~72줄 · 맨 위 음은 C8까지). 재생 중에도 바꿀 수 있어요.
- **설정**: 길이·높이, 마디당 박자(2~7), 박자 쪼개기(1~4), 음계(장조/단조/5음계/반음계), 시작 음, 시작 옥타브(1~6)
- **공유**: 곡 전체가 주소(URL)에 담겨 복사됩니다. 링크를 열면 같은 곡이 그대로 나와요.
- **저장**: WAV(오디오) · MIDI(다른 작곡 프로그램용) 파일로 내려받기. 작업 중인 곡은 브라우저에 자동 저장됩니다.
- 아이콘은 이모티콘 대신 전부 직접 그린 SVG 그림입니다.
