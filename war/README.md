# 🌍 픽셀 월드 워 — 실시간 세계 땅따먹기 전쟁

세계지도를 **2400 × 1435 픽셀 격자**(약 111만 칸의 땅)로 촘촘하게 쪼갠 실시간 전쟁 게임입니다.
Natural Earth 1:10m 국경 데이터를 래스터화해서 **248개 나라·영토**가 모두 들어있고,
나우루·투발루·몰디브 같은 작은 섬나라와 아주 작은 섬도 최소 1픽셀로 빠짐없이 표시됩니다.

## 실행 (서버 열기)

```bash
cd war
npm install
npm start            # → http://localhost:3000
```

- 같은 서버에 접속한 사람들은 **같은 세계에서 실시간으로** 함께 플레이합니다 (멀티플레이).
- 포트 변경: `PORT=8080 npm start`
- 친구와 하려면 서버 컴퓨터의 IP(예: `http://192.168.0.10:3000`)로 접속하거나, 클라우드 서버(Render, Railway, Fly.io 등)에 올리면 됩니다.
- 서버 없이 혼자 하려면: `node tools/build_standalone.js` → `dist/pixel-world-war.html` 을 더블클릭 (AI 국가들과 싱글플레이).

## 게임 방법

| 기능 | 설명 |
|---|---|
| 나라 선택 | 시작 화면 목록 또는 지도에서 아무 나라나 클릭 → 그 나라를 지휘 |
| 선전포고 | 나라 클릭 → ⚔️ 선전포고 |
| 공격 (땅 뺏기) | 병력 %를 정하고 🔥 공격 → 국경선이 **실시간으로 한 픽셀씩** 밀려 들어갑니다. 국경이 없으면 클릭한 곳으로 상륙 |
| 평화 | 🕊️ 평화 제안 (AI는 전황에 따라 수락/거절, AI도 먼저 제안해옴) |
| 무주지 | 남극 등 회색 땅은 주인이 없어 선전포고 없이 점령 가능 |
| 수도 | ★ 표시. 빼앗기면 병력·자금 손실 후 수도 이전. 땅이 0이 되면 멸망 |

### 유닛

| 키 | 유닛 | 비용 | 특징 |
|---|---|---|---|
| 1 | 🪖 군인 | 30 | 싸고 많이. 지나가는 적 땅 점령 |
| 2 | 🛡️ 탱크 | 200 | 튼튼하고 빠름, 넓게 점령, 소총에 강함 |
| 3 | 💥 포병 | 260 | 사거리 11, 범위 피해 |
| 4 | 🎯 방공포 | 220 | 전투기·폭격기·**미사일 요격** |
| 5 | ✈️ 전투기 | 500 | 매우 빠름, 공중 우선 공격, 지상 지원 |
| 6 | 🛩️ 폭격기 | 800 | 지상 유닛 범위 폭격 |
| 7 | 🚢 군함 | 700 | 바다 전용, 해안 포격 |
| 8 | 🚀 미사일 | 1,200 | 수도에서 발사, 착탄 지점 범위 피해 |
| 9 | ☢️ 핵미사일 | 25,000 | 반경 내 모든 유닛 소멸 + 적 땅 즉시 점령 (재장전 90초) |

조작: 드래그=지도 이동, 휠/핀치=확대, WASD/화살표=이동, Q=선택 모드(드래그로 유닛 선택), E=전체 선택,
우클릭(또는 선택 모드에서 클릭)=이동 명령, Space=우리나라로, Esc=취소.

### 경제
- 💰 자금: 영토 크기 + 원래 GDP 비례 수입 → 유닛 구매
- 🪖 병력: 영토·인구 비례로 회복 → 공격(전선 밀기)에 사용, 방어 밀도도 결정

AI 국가들은 서로 전쟁을 선포하고, 유닛을 뽑아 적 수도로 진격하며, 미사일·핵도 씁니다.

## 구조

```
war/
  server.js               Node HTTP + WebSocket(/ws) 서버, 10Hz 게임 루프
  public/sim.js           게임 규칙 시뮬레이션 (서버와 브라우저 싱글모드 공용)
  public/client.js        캔버스 픽셀 렌더링, 입력, UI
  data/map.bin.gz         소유국 격자 (Uint16, 65535 = 바다)
  data/countries.json     나라 이름(한국어)·색·수도·인구·GDP·인접국
  tools/build_map.py      Natural Earth GeoJSON → 픽셀 격자 생성기
  tools/build_standalone.js  단일 HTML 싱글플레이 빌드
```

지도 다시 만들기: `python3 tools/build_map.py ne_10m_admin_0_countries.geojson` (numpy, Pillow 필요).
지도 데이터: [Natural Earth](https://www.naturalearthdata.com/) (퍼블릭 도메인).
