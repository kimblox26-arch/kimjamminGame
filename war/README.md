# 졸라맨 세계대전

손그림 스타일의 웹 전략 게임입니다. 대한민국에서 시작해 세계의 도시를 하나씩 점령하고 전 세계를 통일하세요.

## 실행
`war/index.html` 을 브라우저로 열면 바로 실행됩니다. (웹서버 없이 더블클릭으로도 실행됩니다.)
로컬 서버를 쓰려면 저장소 루트에서 `python3 -m http.server 8080` 을 실행한 뒤 `http://localhost:8080/war/` 로 접속하세요.

## 스토리
2048년 어느 밤, 하늘에서 푸른 유성이 쏟아지고 '에테르'라는 자원이 세계 곳곳에 생겨납니다.
에테르를 차지하려고 모든 나라가 전쟁을 시작하고, 혼란 속에서 대한민국의 새 대통령이 된 당신은 세계를 하나로 만들어 전쟁을 끝내기로 합니다.

## 하는 법
- **세금**: 내 도시 가운데에 있는 `세금` 버튼을 누르면 돈이 들어옵니다. 쿨타임은 1초이고, 누르면 버튼이 어두워졌다가 어두운 부분이 왼쪽으로 줄어듭니다.
- **생성**: 아래 창에서 보병, 탱크, 대포, 전투기를 만듭니다. 탱크부터는 군사기지 단계가 필요합니다.
- **전쟁하기**: 적 도시마다 있는 `전쟁하기` 버튼으로 그 도시를 뺏습니다. 사거리 밖에 있는 도시를 치려면 군사기지를 올려야 합니다.
- **전쟁 화면**: `전쟁하기`를 누르면 전쟁 화면으로 넘어갑니다. 위에는 적국, 아래에는 아군이 있고 오른쪽 창에서 병력을 고른 뒤 공격합니다. 전투 중에는 오른쪽에 전투 기록이 나옵니다.
- **결과 화면**: 전투가 끝나면 따로 결과 화면에 `승리!` / `패배...` 도장이 찍히고, 위에는 다른 나라, 아래에는 아군, 오른쪽에는 어떻게 됐는지가 정리됩니다.
- **지지율**: 세금을 걷거나 전투에서 지면 지지율이 떨어집니다. 0%가 되면 **탄핵**되어 슬픈 엔딩이 나오고, 그 세계는 지워져 처음부터 다시 해야 합니다.
- **통일**: 전 세계 354개 도시를 모두 점령하면 해피엔딩입니다.
- 세계(저장 슬롯)는 최대 3개까지 만들 수 있고, 브라우저(localStorage)에 자동으로 저장됩니다.

## 재미 요소
- **K-방산 무기**: 국군 보병, K2 흑표 전차, K9 자주포, KF-21 보라매 전투기
- **세금 콤보**: 세금을 빠르게 연속으로 걷으면 콤보가 쌓여 수입이 늘어나고, 30콤보면 10초 동안 **피버 타임**(세금 2배, 지지율 안 깎임). 가끔 **대박!**(5배)도 터집니다.
- **보급 상자**: 하늘에서 낙하산 상자가 떨어집니다. 눌러서 열면 일반/희귀/전설 보상!
- **긴급 결정**: 치킨값 폭등, 아이돌 입대, 평양냉면 회담, 수능 날, 한강 괴물, 김장철 등 선택지 사건
- **한류로 설득**: 전쟁 화면에서 K-팝 콘서트를 열어 싸우지 않고 도시를 얻을 수 있습니다. (시설 탭 **한류 센터**로 성공률 상승)
- **보스전**: 강대국 수도를 함락하면 보너스 상금
- **남북 통일**: 북한의 모든 도시를 얻으면 특별 축하 장면
- **업적·칭호·속보**: 업적 14개, '새내기 대통령'부터 '우주 최강 대통령'까지 칭호, 지도 아래 속보 뉴스

## 조작
- 지도 드래그: 이동 / 마우스 휠, 두 손가락: 확대·축소
- 왼쪽 위 버튼: 확대, 축소, 대한민국으로 돌아가기

## 파일
| 파일 | 내용 |
|---|---|
| `js/geo.js` | 세계 국경 데이터 (Natural Earth 1:50m, 공개 도메인 / world-atlas) |
| `js/data.js` | 나라·도시 한국어 이름, 국력, 스토리 |
| `js/sketch.js` | 손그림 선, 졸라맨, 무기, 아이콘, 종이 질감 |
| `js/map.js` | 지도 그리기 (밀러 도법, 영토 색칠, 해안선·국경선) |
| `js/art.js` | 스토리 그림, 전투 장면, 엔딩 장면 |
| `js/war.js` | 전쟁 화면과 전쟁 결과 화면 |
| `js/kdata.js` | 선택지 사건, 속보, 칭호, 업적 데이터 |
| `js/game.js` | 경제, 전쟁, 적 반격, 사건, 저장, 아래 창 |
| `js/main.js` | 화면 흐름 (메인 → 세계 선택 → 스토리 → 게임 → 엔딩) |
| `js/audio.js` | 효과음·배경음악 (WebAudio 합성) |
