    지도 드래그 = 이동 · 휠/핀치 = 확대 · WASD/화살표 = 이동

    나라 클릭 = 정보 · 선전포고 · 공격(땅 뺏기) · 평화 제안

    소환 유닛 버튼(1~9) 누르고 우리 땅 클릭 → 그 자리에 소환 (군함은 우리 해안 근처 바다)

    미사일/핵 버튼 누르고 목표 지점 클릭 → 수도에서 발사

    유닛 명령 선택 모드(Q)에서 드래그로 선택(E = 전체 선택) → 클릭 지점으로 이동 / PC는 우클릭으로 이동

    공격 = 병력을 보내 국경선을 실시간으로 밀어냄. 국경이 없으면 클릭한 곳으로 상륙!

    지상 유닛(군인·탱크·포병·방공포)은 지나가는 적 땅을 점령합니다. 회색 땅(남극 등)은 무주지라 누구나 점령 가능.

    수도를 빼앗기면 병력·자금 손실, 땅이 0이 되면 멸망!
