# ♞ Chess Auto Bot (Android)

다른 앱 위에 떠 있는 체스 봇 창 + 자체 개발 체스 엔진.

## 설치
1. GitHub → **Actions** → `Chess Auto Bot APK` → 최신 실행 → **ChessAutoBot-apk** 다운로드
2. 압축을 풀고 `app-debug.apk` 설치 (출처를 알 수 없는 앱 허용 필요)

## 사용법
| 화면 | 기능 |
|---|---|
| 메인 | 🌐 언어 선택(20개 언어) · **봇 시작하기**(초록) ↔ **멈추기**(빨강) |
| 떠 있는 창 | 체스판 · **봇 작동하기** · 새 게임 · 색 바꾸기 · 상대(사람/AI) |
| ✕ 닫기 | 체스 나이트 모양 동그란 버튼으로 축소 → 누르면 다시 창으로. 드래그로 이동 |

- 앱을 나가도 창이 계속 떠 있습니다(포그라운드 서비스 + '다른 앱 위에 표시' 권한).
- 봇이 둘 때는 출발/도착 칸에 **자동 터치** 표시가 나타납니다.
- **상대: 사람** — 내가 터치로 두고 봇이 응수. **상대: AI** — 봇과 연습 AI가 자동 대국하며 계속 학습.

## 엔진
- 0x88 보드, 반복 심화 PVS 알파-베타, 치환표, 정지 탐색, 널무브·LMR·퓨틸리티 가지치기, 킬러/히스토리 수 정렬
- 평가: 재료·위치표(중반/종반 보간)·폰 구조·통과한 폰·룩 열린 줄·킹 실드·종반 킹 몰이(빠른 메이트)
- perft 표준 5개 국면 검증 통과, PC 기준 약 100만 노드/초
- **패턴 학습**: 상대가 국면마다 둔 수를 저장(앱 재시작 후에도 유지) → 성향(공격/수비/균형) 분석, 다음 수 예측,
  상대가 습관적으로 두는 응수가 실수라면 그 수순으로 유도(🎯 패턴 공략)

## 빌드
```
cd chessbot && gradle assembleDebug   # Android SDK 필요 (compileSdk 34, minSdk 26)
```
