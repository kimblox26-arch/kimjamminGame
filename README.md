# FREE FREELY ✈️ — 물리 기반 웹 비행 시뮬레이터

브라우저에서 바로 실행되는 3D 비행 시뮬레이터입니다.
**설계도에서 기체를 직접 만들고**, 실제 공기역학·중력·부력이 적용된 하늘을 날 수 있습니다.
비행기, 전투기, 여객기, 우주선, 열기구, 글라이더, 복엽기, 수상기 — 모두 같은 물리 엔진 위에서 동작합니다.

```
index.html 을 로컬 웹서버로 열면 바로 실행됩니다.
  python3 -m http.server 8080     →  http://localhost:8080
```
> 파일을 더블클릭(`file://`)하면 ES 모듈 보안 정책 때문에 실행되지 않습니다. 반드시 웹서버로 여세요.
> 필요 라이브러리(three.js)는 `vendor/` 에 포함되어 있어 **인터넷 없이도 동작**합니다.

> 🌿 **같은 저장소에 두 번째 게임이 있습니다 — [고요 GOYO](#-고요-goyo--숲-속-1인칭-힐링-산책) (`walk.html`)**

## 3. 기체 제작 (설계실)

1. 메인 메뉴 → **기체 제작**
2. 왼쪽 팔레트에서 부품 선택 → 도면 클릭으로 배치
3. 상단 탭으로 **측면도 / 평면도 / 정면도** 전환 (`Tab` 키)
4. 드래그로 이동, `[` `]` 크기, `,` `.` 취부각, `D` 복제, `Del` 삭제
5. 오른쪽 패널에서 질량·추력·실속속도·정적 마진·경고를 실시간 확인
6. **▶ 비행 시작** 으로 즉시 이륙

### 설계 규칙 (물리적으로 실제와 동일)
- **무게중심(CG)이 공력중심(AC)보다 앞(기수 쪽)** 에 있어야 피치가 안정합니다. 설계실에 두 지점이 표시되고 정적 마진이 계산됩니다.
- **주 착륙장치는 CG보다 뒤**, 앞바퀴는 기수 쪽에. 접지점 높이가 서로 맞아야 수평으로 섭니다(스프링 강성은 설계 질량에 맞춰 자동 보정됩니다).
- 좌우 대칭 부품(`날개`, `주 착륙장치`, `엔진` 등)은 `bz ≠ 0` 이면 반대쪽에도 자동으로 생성됩니다.
- 수평 미익이 없으면 피치 제어가, 수직 미익이 없으면 방향 안정성이 사라집니다.
- 열기구는 봉투 부피로 부력이 정해지고, 버너 가열 온도에 따라 상승/하강합니다.

부품 카테고리: 구조 · 날개 · 추진 · 착륙장치 · 기구 · 시스템 · 무장 (총 40여 종)

## 5. 물리 모델 요약

```
익면(AeroSurface) 하나하나에 대해
  ├ 국소 유동 = 기체 속도 + 각속도×위치 − 바람
  ├ 받음각 α → CL = lerp(부착유동 2πAR/(AR+2)·α, 박리유동 1.05·sin2α, 실속혼합)
  ├ 압축성 보정(Prandtl–Glauert, 초음속 감쇠), 지면효과, 플랩·조종면 캠버
  ├ CD = cd0 + CL²/(π·AR·e) + 박리항력 + 조종면 항력 + 항력발산(M>0.82)
  └ 양력·항력을 공력중심에 적용 → 모멘트가 자연스럽게 발생 (실속·스핀·나선강하 재현)

대기: ISA 표준대기(고도별 밀도·온도·음속, 90 km 까지)
바람: 고도별 윈드시어 + 제트기류 + 프랙탈 난류 + 열상승기류
추진: 프로펠러(속도에 따른 추력 감소) / 제트(램압축·스풀·A/B) / 로켓(진공 추력·짐벌) / 이온 / RCS / 열기구 버너
부력: 열기구(내부 공기 온도 → 밀도차), 헬륨, 수중 구체 부분부피 적분
지상: 접지점별 스프링–댐퍼 서스펜션(범프 스톱), 노면별 마찰계수, 조향·제동·타이어 슬립
충돌: 구 충돌체 다중 배치, 임펄스 응답 + 마찰, 속도·재질별 손상/파손/화재/폭발
```

조종 보조(설정 → 조작 → 조작 감도/보조)는 실제 플라이바이와이어처럼 **각속도 감쇠 + 수평 복원 + 요 댐퍼 + 받음각 보호**만 추가하며, 물리 자체를 바꾸지 않습니다. `off` 로 끄면 완전한 수동 비행이 됩니다.

## 7. 성능 설정

`설정 → 그래픽`에서 품질 프리셋(낮음/보통/높음/울트라), 렌더 배율, 그림자, 블룸, 입체 구름, 구름 밀도, 시야각을 조절할 수 있습니다.
저사양에서는 **낮음** 프리셋(렌더 배율 0.72, 그림자·블룸·구름 끄기)을 권장합니다.

WebGL2 지원 브라우저(Chrome, Edge, Firefox, Safari 16+)에서 동작합니다.

## 8. 개발 참고

- 물리와 렌더는 분리되어 있으며, 물리는 120 Hz 고정 스텝(최대 6 서브스텝)으로 적분합니다.
- 지형 하이트맵은 CPU에서 생성되어 충돌 판정과 렌더 형상이 **완전히 일치**합니다.
- 콘솔에서 `__FREEFREELY__` 로 게임 인스턴스에 접근할 수 있고, `__FREEFREELY__.debugStep(초)` 로 렌더 없이 물리만 진행시켜 비행 특성을 검증할 수 있습니다.

| `W` `A` `S` `D` | 걷기 |
| `Shift` | 달리기 (숨이 차고 동물이 놀란다) |
| `Ctrl` / `C` | 살금살금 (가장 조용하다) |
| `Space` | 뛰어오르기 |
| `R` | 앉아서 쉬기 — 숨이 고르게 돌아오고 '고요'가 빨리 찬다 |
| `P` | 사진 모드(UI 숨김) · `H` HUD 토글 · `M` 음악 |
| `Esc` | 설정 (음량·감도·시야각·하루 길이·시간 고정) |

모바일에서는 화면 왼쪽 절반을 끌어 이동, 오른쪽 절반을 끌어 시점을 돌립니다.

## 고요(Calm)와 발견

조용히 머물수록, 동물 곁에 있을수록, 물가와 노을 아래에 있을수록 화면 왼쪽 아래 '고요'가 천천히 찹니다.
호숫가에 닿기 · 사슴을 가까이서 보기 · 일출과 노을 · 별 · 반딧불이 · 언덕 꼭대기 · 잠시 앉아 쉬기 — 여덟 가지 순간을 만나면 조용히 기록됩니다.

## 구조

```
walk.html               진입점
styles/walk.css         UI
src/stroll/
  main.js               부팅 · 게임 루프 · 발견 이벤트
  terrain.js            높이장(빠른 노이즈) · 청크 지형 · 재질/비옥도 판정
  sky.js                하늘 돔 셰이더 · 해/달/별/구름 · 하루 주기 조명
  water.js              호수 셰이더 · 물결 파문
  flora.js              풀밭 · 산포 레이어(셀 풀) · 숲 배치 · 바람 셰이더
  fauna.js              동물 · 새 · 나비 · 물고기 · 반딧불이
  player.js             1인칭 컨트롤러 · 장애물 격자
  audio.js              절차적 사운드 엔진
  ui.js                 HUD · 설정 메뉴
  util.js               지수 보간
```

품질(낮음/보통/높음)은 기기 메모리와 모바일 여부로 자동 선택되며, 풀·잡동사니 밀도와 지형 해상도·그림자 크기에 반영됩니다.
콘솔에서 `__goyo` 로 게임 인스턴스에 접근할 수 있습니다. (`__goyo.sky.time = 0.8` 로 밤을 부르는 식)
