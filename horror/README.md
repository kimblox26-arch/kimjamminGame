# 초록모자 — CHAPTER 1 · 저택

초록모자를 **팔로우하지 않은 사람**들이 납치되어 갇힌 저택에서 탈출하는 3D 공포 방탈출 게임입니다.
**1인칭 시점**으로만 플레이합니다. 브라우저에서 바로 실행되고, 휴대폰(가로 화면)과 PC 모두 지원합니다.

```
저장소 최상위 폴더에서:  python3 -m http.server 8080
→ http://localhost:8080/horror/
```
> 마이크(소리 감지 센서)는 **https://** 주소나 **localhost** 에서만 켜집니다.

## 이야기
1. **프롤로그** (처음 한 번 자동 재생, 타이틀에서 다시 보기 가능): 휴대폰에 초록모자의 팔로우 알림 → "나중에" → "내가 직접 데리러 갈게 :)" → 밤길 가로등이 꺼졌다 켜지면 초록모자가 눈앞에... → 끌려감
2. **저택에서 깨어남** → 열쇠 4개와 일기 4장을 모아 현관문으로 탈출
3. **탈출** → 현관문이 열리면 밖은 보이지 않고 눈부신 빛만 가득

## 저택 (번호가 붙은 방 11개)
| 번호 | 방 | 내용 |
|---|---|---|
| 01 | 침실 (시작) | 일기 1, 옷장·침대 밑 |
| 02 | 욕실 | 물 떨어지는 욕조, 서랍장 |
| 03 | 창고 | 상자, 옷장 |
| 04 | 서재 🔒녹슨 | 일기 2, 벽난로 |
| 05 | 음악실 | 은색 열쇠, 피아노 |
| — | 복도 (40m) | 등이 줄지어 달린 긴 복도, 흉상 |
| 06 | 아이방 🔒은색 | 일기 3(크레용), 장난감 상자 속 검은 열쇠 |
| 07 | 식당 | 긴 식탁, 샹들리에 2개 |
| 08 | 부엌 | 싱크대 서랍 속 녹슨 열쇠 |
| 09 | 동상 갤러리 🔒검은 | 안 볼 때 고개를 돌리는 초록모자 동상들 |
| 10 | 현관 홀 | 거대한 동상, 괘종시계, 현관문(금색 자물쇠 + 비밀번호) |
| 11 | 예배당 | 일기 4, 제단 서랍 속 금색 열쇠 |

- 왼쪽 위에 **열쇠 n/4 · 일기 n/4** 가 표시됩니다.
- 일기마다 현관문 **비밀번호 숫자가 하나씩** 적혀 있습니다(판마다 바뀜). 일기장의 "단서" 탭에 모입니다.
- 숨는 곳 17곳: 옷장, 침대 밑, 서랍장, 찬장, 고해실

## 초록모자
- 사용자가 준 그린스크린 사진(앞·뒤)을 부위별로 잘라 입힌 **관절 3D 몸**입니다. 목·어깨·엉덩이가 움직여서 걸을 때 팔다리가 번갈아 흔들리고, 쫓아올 때는 두 팔을 앞으로 뻗습니다.
- 저택을 **천천히** 돌아다니다가(걷기 1.1m/s), 멀리서 나를 보면 잠깐 멈춰 쳐다본 뒤 쫓아옵니다(3m/s, 내가 달리면 4.6m/s).
- 가까이 오면 등이 마구 깜빡이고 무거운 발소리와 심장 소리가 커집니다.
- 숨는 걸 보면 문을 열고 끌어냅니다. 공격 한 번에 체력 34.

## 소리 감지 센서 (마이크)
- **켜면**: 실제 목소리 크기를 재서(녹음·전송 없음) 크게 말하면 그 자리로 옵니다. 숨어서 떠들면 숨은 곳을 열어 봅니다.
- **끄면**: 초록모자는 어떤 소리에도 반응하지 않고, 돌아다니다 **눈에 보일 때만** 쫓아옵니다.

## 소리
실제 녹음된 효과음을 씁니다 — 바닥에 따라 다른 발소리(나무·카펫·돌), 문 열고 닫기, 삐걱임, 서랍, 책장 넘기기, 열쇠, 자물쇠, 옷장에 숨는 소리, 빗소리·바람·천둥, 괘종시계, 물방울, 심장 소리, 동상이 돌아가는 돌 긁히는 소리 등.
출처는 [`sounds/CREDITS.md`](sounds/CREDITS.md) (전부 CC0).
