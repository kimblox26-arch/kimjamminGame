# 초록모자 — CHAPTER 1 · 저택

초록모자를 **팔로우하지 않은 사람**들이 납치되어 갇힌 저택에서 탈출하는 3D 공포 방탈출 게임입니다.
브라우저에서 바로 실행되고, 휴대폰(가로 화면)과 PC 모두 지원합니다.

```
저장소 최상위 폴더에서:  python3 -m http.server 8080
→ http://localhost:8080/horror/
```
> 마이크(소리 감지 센서)는 **https://** 주소나 **localhost** 에서만 켜집니다.

## 이야기
1. **프롤로그** (처음 한 번 자동 재생, 타이틀에서 다시 보기 가능)
   휴대폰에 초록모자의 팔로우 알림 → "나중에"를 누름 → "내가 직접 데리러 갈게 :)" →
   밤길 가로등이 꺼졌다 켜지면 초록모자가 눈앞에... → 끌려감
2. **저택에서 깨어남** → 일기와 열쇠, 비밀번호 단서를 찾아 현관문으로 탈출
3. **탈출** → 카메라가 현관문 쪽으로 옮겨 가고, 문이 열리면 밖은 보이지 않고 눈부신 빛만 가득

## 탈출 순서 (스포일러)
| 단계 | 장소 | 내용 |
|---|---|---|
| 1 | 침실 책상 | 일기 1 — 숨는 법, 녹슨 열쇠 위치 |
| 2 | 침대 옆 협탁 서랍 | **녹슨 열쇠** → 복도의 서재 문 |
| 3 | 서재 책상 | 일기 2 — 비밀번호 순서(거울 → 괘종시계 → 초상화 → 피아노) |
| 4 | 서재 책상 서랍 | **은색 열쇠** → 아이방 문 |
| 5 | 아이방 | 크레용 일기, 장난감 상자 속 **금색 열쇠** |
| 6 | 욕실 거울 · 현관 괘종시계 · 복도 초상화 · 식당 피아노 | 비밀번호 숫자 4개 (판마다 바뀜) |
| 7 | 현관문 | 금색 자물쇠 + 비밀번호 → 탈출 |

## 초록모자
- 사용자가 준 그린스크린 사진(앞·뒤)을 크로마키로 따서 만든 **2D 스프라이트**. 앞/뒤 8프레임 걷기, 팔 들어 공격하는 프레임이 있습니다.
  카메라가 앞에 있으면 앞모습, 뒤에 있으면 뒷모습이 보입니다.
- 순찰 → 소리가 나면 확인하러 옴 → 보이면 추격(공격 1번에 체력 34) → 놓치면 주변 수색, 숨는 곳을 열어 보기도 합니다.
- 숨는 걸 들키면 문을 열고 끌어냅니다. 근처에선 조명이 마구 깜빡이고 심장 소리가 빨라집니다.

## 소리 감지 센서 (마이크)
- 실제 목소리 크기를 재서(녹음·전송 없음) 크게 말하면 초록모자가 그 자리로 옵니다.
- **숨어 있을 때 떠들면** 숨은 곳을 정확히 알아채고 끌어냅니다. 바로 앞에 와 있을 땐 작은 소리도 들킵니다.
- 오른쪽 위 막대가 내 목소리 크기, 흰 선이 들키는 기준입니다. 설정에서 민감도를 바꿀 수 있습니다.
- 마이크가 없어도 발소리(달리기)·문·서랍·피아노·경보음 소리에 반응합니다.

## 조작
| 기능 | 휴대폰 | PC |
|---|---|---|
| 이동 | 왼쪽 조이스틱 | WASD / 방향키 |
| 둘러보기 | 화면 끌기 | 마우스 드래그 |
| 조사 · 숨기 · 나가기 | 손 버튼 | E / 스페이스 |
| 달리기 | 달리기 버튼(켜기/끄기) | Shift |
| 손전등 | 손전등 버튼 | F |
| 일기 · 단서 | 책 버튼 | Tab / N |
| 일시정지 | 일시정지 버튼 | Esc |

손전등을 켜면 잘 보이지만 초록모자에게 더 멀리서 보입니다. 달리면 기력이 줄고 발소리가 커집니다.
