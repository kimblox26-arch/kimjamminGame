# KOBLOX — 한국형 블록 게임 플랫폼 (혼자 플레이 버전)

```
# 저장소 최상위 폴더에서
python3 -m http.server 8080
# 브라우저로 접속
http://localhost:8080/koblox/
```

## 들어있는 것
- **인트로**, 가입(사용자 이름만, 나이 인증 없음), 메인 화면(홈, 차트, 나)
- **아바타**: 꾸미기와 마켓플레이스, 아이템 120개 이상(헤드리스, 코블록스 다리, 장비 포함), 입어 보기, 되돌리기, 아바타 저장, 신체 크기(키, 너비, 머리)
- **코벅스 상점**: 모든 패키지 무료, 코블록스 플러스(무료 구독, 20% 할인)
- **게임**
  - 이동, 점프, 카메라, 모바일 조이스틱
  - 화면 고정(Shift), 1인칭 시점, 채팅 말풍선, 감정 표현
  - 장비 핫바: 검, 로켓 발사기, 블록 빌더, 중력 코일, 스피드 코일, 풍선
  - 순위표(코인, 단계), 배지 12개, 캡처, 그래픽 품질 1~10단계
- **스튜디오(만들기)**: 블록, 공, 원통과 스폰, 체크포인트, 용암, 점프대, 코인을 놓아 체험을 만들고, 테스트하고, 게시하면 홈에 나와요.
- **그래픽**: 둥근 블록, 실사 재질(PBR), 하늘 셰이더, 환경 반사, 부드러운 그림자, 빛 번짐 효과

결제와 멀티플레이는 없고, 데이터는 브라우저(localStorage)에만 저장돼요.

## 파일
| 파일 | 역할 |
|---|---|
| `js/items.js` | 아이템과 배지 목록 |
| `js/avatar.js` | 블록 캐릭터, 장비 모양, 애니메이션 |
| `js/gfx.js` | 그래픽(재질, 하늘, 후처리, 품질 단계) |
| `js/world.js` | 맵 데이터를 3D 월드로 만들기, 스튜디오 템플릿 |
| `js/game.js` | 게임 실행기 |
| `js/studio.js` | 스튜디오 |
| `js/app.js` | 앱 화면 전체 |
| `js/icons.js` | 그림 아이콘(SVG) |
| `style.css` | 디자인 |
