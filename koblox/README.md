# KOBLOX 🧱 — 한국형 블록 게임 플랫폼 (혼자 플레이 버전)

```
# 저장소 최상위 폴더에서
python3 -m http.server 8080
# 브라우저로 접속
http://localhost:8080/koblox/
```

## 들어있는 것
- **인트로** → 가입(사용자 이름만, 나이 인증 없음) → 메인 화면
- **홈 / 차트 / 나(아바타)** 탭, 메뉴(드로어), 검색, 알림(Test 게임 1개)
- **아바타 꾸미기**: 꾸미기 / 마켓플레이스, 아이템 110여 개 (헤드리스, 코블록스 다리, 왕관, 날개, 오라, 애니메이션, 감정 표현 등), 입어보기, 되돌리기, 아바타 저장
- **코벅스 상점**: 모든 패키지 무료, 코블록스 플러스(무료 구독, 20% 할인)
- **설정**: 계정 정보, 개인정보, 알림, 앱 설정(테마), 게임 설정(그래픽·감도·시야각 등), 소리, 정보/초기화
- **게임 "Test"**: 파란 하늘 + 회색 바닥, 이동·점프·카메라, 모바일 조이스틱/점프 버튼, 채팅 말풍선, 감정 표현(`/e dance`), 캐릭터 재설정, 게임 메뉴

결제와 멀티플레이는 없고, 데이터는 브라우저(localStorage)에만 저장돼요.

## 파일
| 파일 | 역할 |
|---|---|
| `js/items.js` | 아이템 목록 (여기에 추가하면 상점/꾸미기에 자동으로 나와요) |
| `js/avatar.js` | 블록 캐릭터 모양과 애니메이션 |
| `js/app.js` | 화면(UI) 전체 |
| `js/game.js` | 게임 Test |
| `js/store.js` | 저장 데이터 |
| `style.css` | 디자인 (색은 맨 위 변수에서 바꿔요) |
