# FORGE 철공소 🔥 — 실제처럼 만드는 물리 제작 샌드박스

철판을 맞대고 **용접**하고, 각재에 **못**을 박고, **볼트**를 조이고, 벽돌에 **모르타르**를 바르고, **그라인더**로 자르고, **도장**까지 —
자기 손으로 건물이든 자동차든 원하는 무엇이든 만드는 1인칭 3D 제작 게임입니다. 모든 부품은 실제 재질·치수·질량을 가지며,
접합부는 실제처럼 하중을 받다가 **강도를 넘으면 끊어집니다.**

```
저장소 루트에서 웹서버 실행 → 브라우저로 forge/ 열기
  python3 -m http.server 8080     →  http://localhost:8080/forge/
```
> `file://` 로는 ES 모듈이 막혀 실행되지 않습니다. three.js · Rapier 물리엔진은 `vendor/` 에 포함되어 **오프라인 동작**합니다.
> 그래픽 품질은 설정에서 바꾸거나 주소에 `?q=low|medium|high|ultra` 를 붙여 지정할 수 있습니다.

## 무엇이 들어있나

| 분야 | 내용 |
|---|---|
| 물리 | **Rapier** 강체 엔진 120 Hz 고정 스텝 · CCD · 접합된 부품은 하나의 복합 강체로 병합 · 관성력/충돌력으로 접합 파손 → 연결 요소 분석 후 자동 분리 · 레이캐스트 서스펜션 차량 · 공기 저항 |
| 재질 | SS400 강판(7850 kg/m³) · 알루미늄 · 소나무/합판 · 점토 벽돌 · 콘크리트 블록 · 판유리 · 고무 — 실제 밀도로 질량 계산 (H빔 150 = 31 kg/m 등 KS 규격) |
| 접합 | 클램프(임시, 2.6 kN) · 용접 비드(1 cm ≈ 2.6 kN) · 못(750 N, 3번 쳐야 완전 체결, 가끔 휨) · M12 볼트(16 kN) · 모르타르(20초 양생) · 앵커 볼트(바닥 고정) |
| 손상 | 얇은 판재 **찌그러짐**(망치·충돌, 정점 변형 + 저장) · 유리 **산산조각** · 벽돌/블록 **깨짐** · 충돌 시 약한 접합부 **이탈** |
| 그래픽 | PBR + 절차적 텍스처(흑피·헤어라인·아연도 스팽글·녹·체크플레이트·나뭇결·합판·벽돌·콘크리트·아스팔트·골강판) · 모따기된 부품 모서리 · MSAA · GTAO · 블룸 · ACES · 실시간 그림자 · 하늘 산란 + 환경 반사 |
| 이펙트 | 용접 아크광(점광원) · 튀고 구르는 불꽃 · 비드 백열→냉각 색 변화 · 열변색(템퍼 컬러) 데칼 · 그을림 · 연기/분진/톱밥 · 파편 · 유리 조각 · 추진 화염 · **자동차광 용접 헬멧 필터** |
| 사운드 | 전부 WebAudio 실시간 합성 — 지글거리는 아크, 비조화 금속 타격음(부품 크기별 음높이), 나무 타격, 못 박는 소리, 임팩트 드라이버, 그라인더 부하음, 스프레이, 유리 깨짐, 엔진 회전수/기어, 추진기, 작업장 잔향 |
| 월드 | 32×24 m 철골 작업장(정반·용접기·가스통·목공 작업대·자재 랙·천장 크레인·채광창) · 자재 야적장 · 타원형 시험 주행로 · 점프대 · 요철 구간 · 1.4 km 지형 |
| 차량 | 바퀴 + 엔진(단기통 5 kW / 전기 80 kW / V8 300 kW) + 운전석이 한 구조물에 있으면 주행. 질량·출력·접지력·공기저항이 실제처럼 반영 · 속도 감응 조향 · 주차 브레이크 · 헤드라이트 · 로켓 추진기 |
| 예제 | 고카트 · 오프로드 버기 · 목조 창고 골조 · 벽돌 벽 · 철골 탑 (접촉면 자동 용접/못/볼트/모르타르) |
| 저장 | 3개 슬롯 + 자동 저장 — 부품·접합·체결 위치·찌그러짐·도장·앵커까지 그대로 복원 |

## 조작

| 키 | 기능 |
|---|---|
| `WASD` `Shift` `Space` `C` | 이동 · 달리기 · 점프 · 앉기 |
| `1`–`8` / `Q` | 공구 선택 / 이전 공구 |
| `Tab` | 자재 카탈로그 (치수 조절 가능) |
| `E` / `F` | 운전석 탑승·라이트 / 앵커 볼트로 바닥 고정·해제 |
| `Esc` | 일시정지 · 저장/불러오기 · 설정 |

| 공구 | 좌클릭 | 우클릭 · 기타 |
|---|---|---|
| 1 손 | 잡고 운반(사람 힘 ≈ 750 N) | 던지기 · 휠 거리 · R/T 회전 |
| 2 자재 배치 | 배치(모서리 자석 스냅 + 격자) | 철거 · R/휠 회전 · T 세우기 · G 격자 · Ctrl+Z |
| 3 MIG 용접기 | 이음매 따라 비드 쌓기 | 영구 접합되면 클램프 자동 해제 |
| 4 망치 + 못 | 못 박기 · 판 두드리기(찌그러짐) | 못 뽑기 |
| 5 임팩트 드릴 | 구멍 뚫고 볼트 체결 | 볼트 풀기 |
| 6 흙손 | 모르타르 바르기 | — |
| 7 앵글 그라인더 | 부품 절단(커프 2 mm) · 접합부 갈아내기 | T 절단 방향 |
| 8 스프레이 건 | 도장 | 색 변경 |

**차량**: `W/S` 가속·제동/후진 · `A/D` 조향 · `Space` 핸드브레이크 · `Shift` 추진기 · `L` 라이트 · `H` 경적 · `V` 시점 · `E` 하차
