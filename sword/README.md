# SKY BLADE — 비행 프로토타입

검 게임의 첫 단계입니다. 하얀 바닥, 실제 같은 하늘(산란 대기, 해, 뭉게구름), 로블록스 R6 스타일 하얀 캐릭터, 그리고 **비행**을 구현했습니다.

```
저장소 루트에서:  python3 -m http.server 8080
브라우저:        http://localhost:8080/sword/
```
- `file://`로 직접 열면 ES 모듈 보안 정책 때문에 실행되지 않습니다.
- 휴대폰은 같은 와이파이에서 `http://<PC IP>:8080/sword/`로 접속하면 터치 조작으로 플레이할 수 있습니다.
- 주소 끝에 `?q=low`(저사양) 또는 `?q=high`(고사양)를 붙이면 그래픽 품질을 직접 고를 수 있습니다.

## 조작

| 키 | 동작 |
|---|---|
| `W A S D` | 이동 (비행 중에는 카메라가 보는 방향으로) |
| 마우스 | 시점 (클릭하면 포인터 고정, 휠 = 줌) |
| `Space` | 점프 → 공중에서 한 번 더 누르면 비행 시작 / 비행 중 상승 |
| `F` | 바로 이륙 / 비행 해제(낙하) |
| `C` | 하강 |
| `Shift` | 지상: 질주 (스태미나 소모) · 비행: 빠르게, 계속 누르면 **음속 돌파(소닉붐)** → **극초음속 보우쇼크** |
| `Z` | 느리게 비행 (지상에서는 살금살금) |
| `Q` / `E` | 배럴 롤 (저속에서는 옆돌기) |
| `R` | 공중제비 |
| `M` / `P` / `H` | 소리 / 120 FPS 제한 켜고 끄기 / 도움말 |

터치: 화면 왼쪽을 드래그하면 조이스틱, 오른쪽을 드래그하면 시점, 오른쪽 아래 버튼으로 나머지 동작을 합니다.

## v2: 서울, 하늘에서 우주까지, 행성 폭발

- **맵**: 서울을 닮은 지형입니다.
  - 한강, 여의도, 남산, 북한산, 관악산이 있고, 서쪽은 서해, 그 밖은 끝없는 시골 산맥입니다.
  - 건물로는 아파트 단지, 강남·여의도 빌딩, 63빌딩, 롯데월드타워, N서울타워, 한강 다리가 있습니다.
  - 지구 곡률이 있어서 높이 올라가면 지평선이 둥글게 보입니다.
- **하늘**: 고도에 따라 색이 바뀝니다. 대류권의 파란 하늘에서 성층권의 짙은 남색, 중간권의 보랏빛 검정을 거쳐 우주로 갑니다.
  우주에서는 별, 은하수, 해, 달, 그리고 구형의 지구가 보입니다.
- **속도**:
  - 부스트는 지수적으로 붙습니다. 해면 근처 최고 속도는 초속 12 km이고, 공기가 옅을수록 빨라집니다.
  - 우주에서는 광속의 수백 배까지 갑니다. 물리적으로는 불가능하지만 의도적으로 그렇게 했습니다.
  - 부스트를 놓으면 대기가 진할수록 공기 저항으로 빨리 감속합니다.
- **충돌 에너지**: 운동에너지 E = ½mv²에 따라 결과가 달라지고, 충격파 반경은 E의 세제곱근에 비례합니다.
  - 착지 → 크레이터 → 주변 건물 파괴 → 도시 규모 폭발(버섯구름) 순으로 커집니다.
  - 지구에 초속 3,000 km 이상으로 부딪히면 **지구가 폭발**합니다. Enter 키나 화면의 지구 복원 버튼으로 되돌립니다.
  - 달에 초속 20 km 이상으로 부딪히면 **달이 폭발**하고, 태양에 들어가면 **초신성 폭발**이 일어납니다.
- **건물**: 빠르게 날면 건물을 뚫고 지나가며 부수고, 느리게 부딪히면 튕겨 나옵니다. 옥상에 착지할 수 있습니다.
- **기술**:
  - 플로팅 원점: 플레이어 근처를 렌더 원점으로 유지해서 수천 km를 날아도 화면이 떨리지 않습니다.
  - 근거리·원거리 2단 렌더로 수백 km 시야에서도 깊이가 깨지지 않습니다.
  - 우주 장면을 먼저 그리고 대기를 반투명하게 겹칩니다.

## 구현 내용

- **120 FPS**: 물리와 애니메이션은 고정 120 Hz로 돌고, 렌더는 그 사이를 보간합니다.
  - 120 FPS 제한은 기본으로 켜져 있지만, 프레임 간격을 고르게 유지하려고 모니터 주사율의 정수배로만 건너뜁니다.
    240 Hz 모니터는 120 FPS로 제한되고, 120 Hz와 144 Hz 모니터는 주사율 그대로 그립니다.
  - 화면 표시는 모니터 주사율을 넘을 수 없습니다. 60 Hz 모니터에서는 60 FPS로 보이지만 내부 시뮬레이션은 그대로 120 Hz입니다.
  - 성능이 모자라면 해상도를 자동으로 낮춥니다. 한 번 실패한 해상도는 30초 동안 다시 시도하지 않습니다.
- **로블록스 스타일**: R6 비율의 블록 몸, 둥근 원통 머리, 클래식 스마일 얼굴, 플라스틱 재질.
- **애니메이션**: 관절(목, 어깨, 엉덩이)과 몸통의 채널마다 2차 스프링을 달았습니다. 그래서 팔다리가 몸보다 살짝 늦게 따라오고(겹침 동작),
  가속이나 회전에 관성이 생깁니다. 무릎이 없는 R6 다리 각도로 골반 높이를 계산해 발이 땅에 붙어 있습니다.
  - 지상 (로블록스 **포세이큰** 방식): 기본은 걷기 12 스터드/초, `Shift`를 누르면 질주 26 스터드/초입니다 (1 스터드 = 0.4 m).
    스태미나 100은 질주할 때 초당 10씩 줄고, 질주하지 않을 때 초당 20씩 찹니다.
    바닥나면 3초간 탈진해서 회복도 멈추고, 20까지 찰 때까지 질주할 수 없습니다. 탈진하면 고개가 처지고, 멈춰 서면 무릎에 손을 짚고 헐떡입니다.
    질주는 상체를 숙이고 팔을 크게 흔들며, 화면 아래 가운데에 스태미나 바가 뜹니다.
    대기(호흡, 체중 이동, 두리번)와 방향 전환 시 안쪽 기울기도 있습니다.
  - 이륙: 0.13초 동안 깊게 웅크렸다가, 한 주먹을 하늘로 뻗으며 솟아오릅니다.
  - 점프: 상승, 정점, 낙하(허우적), 착지 충격, 높은 곳에서 떨어졌을 때의 런지 착지.
  - 비행: 호버(다리 흔들림), 느린 활공(날개처럼 팔 펼치기), 순항, 고속 슈퍼맨 자세, 초음속(두 주먹 모으기), 급제동(몸을 세우며 팔다리 펼치기),
    상승과 하강 자세, 선회할 때의 뱅크, 고속에서의 떨림.
  - 트릭: 배럴 롤, 옆돌기, 공중제비. 트릭마다 예비 동작과 회전 후의 오버슈트가 있습니다.
  - 슈퍼히어로 착지: 3점 착지 후 고개를 들고 일어섭니다.
- **임팩트**: 점프, 이륙, 착지, 영웅 착지(크레이터, 파편), 부스트, 소닉붐, 롤, 공중제비, 급제동, 발걸음마다 효과가 다릅니다.
  히트스톱, 카메라 흔들림, FOV 킥, 화면 충격파도 들어갑니다.
- **속도 효과**: 마하 0.85~1.3에서는 증기 원뿔, 마하 1.6 이상에서는 운석처럼 빛나는 **보우쇼크** 플라즈마와 불꽃 꼬리가 나옵니다.
  이때 몸이 달아오르고, 화면에 열 왜곡과 방사형 블러가 걸립니다.
