# 🌍 세계 지도 편집기

실제 세계 지도에서 출발해 **국가·지방·도시·바다**를 마음대로 바꾸는 샌드박스 지도 편집기입니다.
설치 없이 브라우저에서 동작하고, 데이터가 모두 들어 있어 **인터넷 없이도** 쓸 수 있습니다.

```
저장소 루트에서:  python3 -m http.server 8080   →   http://localhost:8080/worldmap/
```

## 기능

| 분류 | 내용 |
|---|---|
| 지도 | 실제 세계 지도(국가 251개, 지방 4,596개, 도시 1,100여 개, 바다 이름) · 2D 평면 지도 ↔ 3D 회전 지구본 |
| 간편 모드 | **지방 칠하기**: 지방을 누르거나 끌어서 영토 확장 · **국가 합병**: 누른 국가 전체를 흡수 |
| 정밀 모드 | **브러시**: 국경을 픽셀 단위로 자유롭게 그리기 · **지방 분할** · **지우개**(무주지) |
| 지형 | **땅 만들기**(새 섬) · **바다 만들기** |
| 국가 | 이름·색 바꾸기, 국기(기본 국기 271종 / 직접 만들기 / 사진), **배경 사진**으로 영토 채우기, 새 국가, 다른 국가에 합병, 지방별 해체, 삭제 |
| 지방 | 이름 바꾸기, 소속 바꾸기, 독립시키기, 무주지로 만들기 |
| 라벨 | 도시·바다 이름 바꾸기/옮기기/삭제, 새 도시·새 바다 이름 추가, 수도 표시 |
| 표시 | 국가 이름·국기·지방 경계선·지방 이름·도시·바다 이름 켜고 끄기, 바다/무주지 색 |
| 저장 | 자동 저장, 저장 슬롯 여러 개, 백업 파일 내보내기/가져오기, PNG 이미지로 저장 |
| 새 지도 | 실제 세계 / 빈 세계(모두 무주지) / 지방마다 독립국 |
| 편의 | 실행 취소·다시 실행, 스포이드, 마우스·터치(두 손가락 확대/이동) 지원 |

## 단축키

`V` 선택 · `H` 이동 · `P` 지방 칠하기 · `B` 브러시 · `F` 국가 합병 · `X` 지방 분할 · `E` 지우개 · `L` 땅 만들기 · `O` 바다 만들기 · `T` 도시·라벨 · `I` 스포이드
`[` `]` 브러시 크기 · `G` 2D/3D 전환 · `Ctrl+Z` / `Ctrl+Y` 실행 취소/다시 실행 · `Space`+끌기 / 오른쪽 버튼 끌기 이동

## 구조

- `js/world.js` — 4096×2048 픽셀 격자(픽셀 → 지방 ID), 지방 → 국가 소유, 렌더링(국경·해안선·얕은 바다), 브러시, 실행 취소, 저장 형식
- `js/view2d.js` / `js/globe.js` — 2D 지도 / three.js 지구본 (같은 지도 이미지를 공유)
- `js/labels.js` — 국가·지방·도시·바다 라벨 배치, 국기
- `js/main.js` — 도구, 패널, 대화상자 · `js/store.js` — IndexedDB 저장
- `data/` — `tools/build-data.js` 로 만든 데이터 (지방 격자 RLE, 이름, 국기 아틀라스)
