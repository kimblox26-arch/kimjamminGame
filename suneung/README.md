# 수능 감독관: AI 안경을 찾아라

수능 시험장에서 **AI 안경**으로 부정행위하는 학생을 찾아내는 3D 웹 게임입니다.

```
python3 -m http.server 8080   →   http://localhost:8080/suneung/
```

## 모드
- **선생님 모드** — 감독관이 되어 교실을 돌아다니며 AI 안경 학생을 찾습니다. AI 안경은 옆에 파란 LED가 깜빡이고, 학생이 허공을 보다가 갑자기 빠르게 답을 씁니다. 하트 3개: AI 안경이 아닌 학생을 쓰러뜨리면 하트가 하나 줄어듭니다.
- **학생 모드** — AI 안경을 쓴 수험생이 됩니다. `AI 안경에게 묻기`로 아무 질문이나 하고, `문제 풀기`를 누르면 답이 써집니다. 너무 빨리 풀거나 감독관 앞에서 AI를 쓰면 의심도가 올라가 적발됩니다.

## 진행
입실 애니메이션 → 1교시 국어 → 2교시 수학 → 점심시간(남은 AI 안경 학생 수 발표) → 3교시 영어 → 4교시 탐구 → 수능 종료(남은 AI 학생 = 빨강, 일반 학생 = 초록)

## 무기 상점 (감독관 의자 = 노란 원)
의자에 가면 자리에 앉으면서 시점이 책상 위 무기로 옮겨집니다. 무기 아래 가격표가 있고, 한 번 탭하면 선택, 한 번 더 탭하면 구매/장착됩니다. 조이스틱을 움직이거나 `일어나기`를 누르면 나옵니다.

| 무기 | 가격 |
|---|---|
| 안경 뺏기(반으로 쪼개기) · 주먹 기절 · 분필 던지기 · 호루라기 | 기본 |
| 야구방망이 | 10 코인 |
| 금속 탐지기 (AI 안경에 가까이 대면 삑삑) | 15 코인 |
| 페인트 권총 (12발) | 25 코인 |
| AK-47 페인트건 (30발 연사) | 40 코인 |
| 페인트 샷건 (6발, 펌프) | 50 코인 |
| 저격 페인트총 (5발, 볼트액션, 조준경) | 85 코인 |
| RPG 폭죽포 (자리 파괴 + 파편) | 67 코인 |
| 태클 제압 (수갑) | 100 코인 |

AI 안경 학생을 적발할 때마다 1코인. 총알은 무한(탄창만 갈아 끼움): `R` 또는 재장전 버튼, 조준은 마우스 오른쪽/조준 버튼. 코인과 무기는 브라우저에 저장됩니다.

## 조작
- 모바일: 왼쪽 조이스틱, 오른쪽 공격/점프 버튼, 아래 무기 칸(핫바), 화면 드래그로 시점 회전
- 선생님 모드는 **1인칭**(손과 무기가 보임)
- PC: 화면 클릭 → 마우스로 시점(포인터 잠금), 클릭 공격, WASD 이동, Space 점프, F 공격, 1~7 무기 선택, Enter 말하기, Esc 마우스 해제
- 말하기 창에 쓴 글은 채팅에 남고, 선생님이 실제 목소리(TTS)로 말하며 학생들이 반응합니다.

## 설정
- 소리 / 음성 / 그래픽(저·중·최고)
- **해킹**: 비밀번호 `수능2026game` → 돈 무한, 공격 쿨타임 없애기, AI 안경 쓴 학생 찾기. 창을 닫으면 동그란 버튼으로 작아지고, 누르면 다시 열립니다.

## 그래픽 · 사운드
- 사람: 얼굴 없이 깔끔한 머리, 단정한 머리 모양, 원단 질감(패딩 누빔·니트·데님), 손가락
- 교실: LED 천장등, 천장 선풍기, 창문 롤 블라인드, 복도 쪽 창, 분리수거함
- UI: 반투명 유리 느낌 버튼
- PBR 재질 + 환경 반사, ACES 톤매핑, 블룸, 비네트/필름 그레인, MSAA
- 창문으로만 들어오는 햇빛(그림자) + 빛줄기 + 떠다니는 먼지
- 학생마다 따로 그려지는 시험지(필기 · 페이지 넘김), OMR 답안지, 수험표
- 교실 잔향(컨볼루션 리버브) + 3D 위치 음향(HRTF), 겹겹이 합성한 효과음, 한국어 음성 안내
