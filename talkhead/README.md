# 🗣️ 보이스 엑스레이 — 말하는 해부학 머리

글이나 노래 제목을 적으면 **소리 내어 읽어주고**, 말하는 동안 사람 머리 옆모습 단면 속
**뼈·근육·혀·치아·뇌·성대·연구개·공기 흐름**이 어떻게 움직이는지 **실시간**으로 보여줘요.

## 실행

```
# 저장소 최상위 폴더에서
python3 -m http.server 8080
# Chrome / Edge 로 접속
http://localhost:8080/talkhead/
```
`talkhead/index.html` 을 그냥 더블클릭해도 열려요. 외부 라이브러리·인터넷 연결이 필요 없어요.

## 사용법
- **오른쪽 텍스트 칸**에 글을 쓰고 `▶ 읽어주기` (또는 Ctrl+Enter)
- 그 아래 **🎵 노래 제목** 칸에 제목을 쓰고
  - `🔊 제목 읽기` : 제목을 그대로 읽어요
  - `🎤 노래처럼 부르기` : 제목 글자마다 음을 붙여(제목마다 다른 멜로디) 노래하듯 불러요
- 모드: 👦 어린 남자 · 👧 어린 여자 · 👨 성인 남자 · 👩 성인 여자
  — 목소리 높낮이와 머리 모양(크기, 얼굴 비율, 후두 위치, 울대뼈, 머리카락)이 바뀌어요
- 설정: 읽기 속도, 목소리 직접 고르기, 이름표/공기 흐름 켜고 끄기

## 그래픽
- 실제 해부도처럼 **머리 한가운데를 세로로 자른 단면**(정중 시상 단면)을 그려요: 대뇌 이랑, 뇌량, 시상, 뇌하수체, 뇌간, 소뇌(생명수 모양 백질), 머리뼈(치밀뼈+해면뼈), 코선반, 경구개·연구개, 치아(법랑질·상아질·치수), 설골, 후두개, 갑상연골, 성대, 기관 연골, 식도, 척추뼈·추간판·척수, 목 근육, 피부·피하지방
- 근육 결, 해면뼈, 지방 소엽, 점막, 연골, 머리카락 질감을 코드로 만들어 입히고, 안쪽 그림자로 입체감을 줘요 (이미지 파일 없음)
- 움직이지 않는 부분은 한 번만 그려 두고 턱·혀·입술·연구개·성대만 매 프레임 다시 그려서 부드럽게(60fps) 움직여요
- 화면 위 버튼으로 이름표 / 공기 흐름 / 신경 신호를 켜고 끌 수 있어요

## 화면에서 보이는 것
| 부분 | 움직임 |
|---|---|
| 턱뼈 | 모음에 따라 열리고 닫힘 (턱관절 기준 회전) |
| 혀 | 혀끝·혓몸·혀뿌리가 음소마다 위치를 바꿈 (ㅣ는 앞쪽 높이, ㅜ는 뒤쪽 높이, ㄱ은 연구개에 닿음) |
| 입술 | 닫힘(ㅁㅂㅍ), 둥글게 내밂(ㅗㅜ), 옆으로(ㅣ), 아랫입술-윗니(f, v) |
| 연구개 | 코 소리(ㅁㄴㅇ)에서 내려가고 그 밖에는 올라가 콧길을 막음 |
| 성대 | 유성음에서 떨림, 무성음·숨쉬기에서 열림 (왼쪽 아래 위에서 본 모습) |
| 뇌 | 읽기 경로(시각→각회→베르니케→브로카→운동 피질)에 불이 켜지고, 신경을 따라 혀·입술·턱·성대로 신호가 내려감 |
| 공기 | 입·코로 나가는 공기, 막혔다 터지는 파열음, 마찰음의 난류 |

## 동기화 방식
브라우저의 음성 합성(Web Speech API)을 쓰고, 글자를 음소로 바꿔(한글은 초·중·종성 분해, 영어는 철자 규칙)
시간표를 만든 뒤 음성 엔진의 단어 경계 신호(boundary)가 오면 그 단어에 맞춰 다시 맞춥니다.
경계 신호가 없는 목소리는 실제 말한 길이로 속도를 자동 보정해요.
음성 엔진이 없거나 응답하지 않으면 소리 없이 입 모양만 보여줘요.

> 노래 가사는 저작권 때문에 자동으로 가져오지 않아요. 가사를 텍스트 칸에 직접 적으면 읽어줘요.

## 파일
- `js/phonemes.js` — 글자 → 음소 → 조음 목표값 (한글·영어)
- `js/head.js` — 머리 단면 그리기와 효과
- `js/app.js` — 음성 재생, 실시간 동기화, 화면 조작
