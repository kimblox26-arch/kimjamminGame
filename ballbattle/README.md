# 볼박스 배틀

틱톡 프로필 사진이 들어간 공끼리 박스 안에서 자동으로 싸우는 웹 게임입니다.

```
cd ballbattle && python3 -m http.server 8080   →  http://localhost:8080
```
(GitHub Pages처럼 https 주소에 올리면 휴대폰에서도 그대로 플레이할 수 있어요.)

## 기능
- **로딩 → 환영 문구 → 플레이 버튼 → 로그인/회원가입 → 메인**: 모든 화면 전환에 애니메이션이 들어가 있어요.
- **회원가입**: 나이, 이메일, 비밀번호, 아이디(본인 틱톡 아이디, 중복 불가), 닉네임. 아이디+비밀번호로 로그인, 로그아웃.
- **구글 로그인**: `js/config.js`에 `GOOGLE_CLIENT_ID`를 넣으면 켜져요.
- **하단 목록**: 랭킹 · 영상 · 만들기(+) · 홈 · 프로필. 선택된 버튼은 커지고 색이 바뀌어요.
- **홈**: 내 틱톡 스타일 프로필(배너 + 배경으로 이어지는 그라데이션), 왼쪽 위 반투명 연필 버튼(프로필 편집), 플레이, 공 스킬 제작, 다른 사람 스킬 쓰기.
- **프로필 편집**: 배경 변경(사진 업로드 / 내 게시물에서 선택 / 삭제), 사진 변경, 이름, 아이디, 틱톡 링크 복사, 자기소개.
- **게임**: 매칭 → VS 화면(상대 왼쪽 위, 나 오른쪽 아래) → 맵 고르기(랜덤 포함, 상대도 고름) → 3·2·1 → 자동 전투. 체력 150, 1승 = 1코인. 60초가 지나면 서든데스.
- **맵**: 기본 박스 / 정글(줄기에 걸리면 잠시 멈추고, 빠져나오면 줄기가 사라짐) / 용암(닿으면 1초에 HP 1) / 하늘(구름에 닿으면 느려짐).
- **스킬 제작**: 13가지 효과를 섞어서 만들고, 쿨타임·색·소리(기본음/파일/녹음)·영상(배경 제거 포함)을 정할 수 있어요. 스킬 2개를 **융합**하거나 코인으로 **업그레이드**할 수 있어요. **공유**한 스킬만 다른 사람이 쓸 수 있어요.
- **영상**: 플레이가 자동으로 녹화돼요. 편집(자르기, 속도, 필터, 보정, AI/크로마키 배경 제거, 텍스트, 회전·반전, 확대·투명도, 볼륨)해서 숏츠/동영상으로 올리고 좋아요·댓글·저장·공유, 구독을 할 수 있어요. 라이브는 구독자 15명부터 할 수 있어요.
- **랭킹**: 1·2·3등은 금·은·동 단상, 나머지는 목록. 승수/코인 정렬.
- **신고 / 개발자**: 플레이어를 신고할 수 있어요. 개발자 계정은 이름 옆에 인증 마크와 `개발자` 표시가 붙고, 랭킹·게임 화면·프로필에서 밴 버튼(아이디 + 개발자 비밀번호 입력 후 확인)을 쓸 수 있어요.

## 알아둘 점
- 서버가 없어서 계정·영상·스킬 데이터는 **이 브라우저(기기)에만** 저장돼요. 다른 사람과 진짜로 매칭하거나 영상/스킬을 공유하려면 Firebase 같은 서버가 필요해요. 지금은 같은 기기의 다른 계정과 `AI` 표시가 붙은 연습 상대가 매칭돼요.
- 틱톡은 다른 앱에서 아이디를 확인하는 방법을 열어두지 않아서, 아이디가 진짜 본인 틱톡인지는 확인할 수 없어요(형식과 중복만 확인해요). 프로필 사진은 직접 올리거나 `틱톡 사진 불러오기`(unavatar.io)로 가져와요.
- 비밀번호는 해시(SHA-256)로만 저장해요. 다만 브라우저에서만 돌아가는 게임이라 보안이 완벽하지는 않아요.
