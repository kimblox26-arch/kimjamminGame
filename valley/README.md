# 계곡 물막이 🪨💧

돌을 직접 주워 쌓고, 삽으로 흙을 파서 돌 틈을 메워 **계곡물을 막는** 1인칭 물리 샌드박스 게임입니다.

```
python3 -m http.server 8080   →   http://localhost:8080/valley/
```
(저장소 루트에서 실행하세요. three.js 와 Rapier 물리엔진이 `vendor/` 에 들어 있어 인터넷 없이 동작합니다.)

## 조작
| 키 | 동작 |
|---|---|
| `W A S D` / `Shift` / `Space` | 이동 / 달리기 / 점프 |
| `1` 손 | `클릭`·`E` 돌 줍기·내려놓기, `우클릭` 던지기, `휠` 드는 거리, `Q`/`R` 돌 돌리기 |
| `2` 삽 | `좌클릭` 흙 파기(삽에 담김), `우클릭` 흙 붓기 |
| `Esc` | 일시정지 |

터치 기기에서는 화면 왼쪽 조이스틱 + 오른쪽 버튼으로 조작합니다.

## 게임 목표
1. 물길의 50% 막기 → 2. 80% 막기 → 3. 돌 틈을 흙으로 메워 95% 막기 → 4. **장마**(폭우로 물이 2배) 버티기 → 자유 놀이
화면 왼쪽 위 막대가 "막은 비율"(하류로 빠져나가는 물 / 상류에서 들어오는 물)입니다.

## 시뮬레이션
- **물**: 0.2 m 격자 얕은물 시뮬레이션(가상 파이프 + 체지 마찰). 실제처럼 웅덩이가 차오르고, 둑을 넘치고, 옆으로 돌아 흐릅니다.
- **돌**: Rapier 강체 물리(볼록 껍질 충돌체). 각 돌의 모양을 격자에 래스터화해서 물을 막습니다. 둥근 돌 사이 틈으로는 물이 샙니다.
- **물의 힘**: 돌마다 수압 차이·유속 항력·부력이 작용합니다. 작은 돌은 센 물살에 굴러가고, 물이 깊이 차면 얇은 둑은 밀립니다.
- **흙**: 파낸 만큼 삽에 담기고(최대 0.3 m³), 부은 흙은 안식각으로 흘러내리며 돌 틈을 메웁니다. 부은 흙은 빠른 물살에 **침식**되어 흙탕물로 떠내려가므로 돌로 보호해야 합니다.

## 그래픽
물리 기반 렌더링 + ACES 톤매핑 + 블룸, 4K 그림자맵, 굴절(화면 공간)·흡수·프레넬 반사·햇빛 반짝임·흐름 방향 잔물결·거품·흙탕물을 표현하는 물 셰이더, 물속 바닥의 코스틱, 젖은 돌/자갈 표현, 절차적 자갈·암반·흙 텍스처, 바람에 흔들리는 풀 1만6천 포기, 침엽수·활엽수 숲, 폭포와 물안개, 비. 모든 소리는 WebAudio 로 실시간 합성됩니다.
