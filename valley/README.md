# 계곡 물막이 🪨💧

돌을 직접 주워 쌓고, 삽으로 흙을 파서 돌 틈을 메워 **계곡물을 막는** 1인칭 물리 샌드박스 게임입니다.

```
python3 -m http.server 8080   →   http://localhost:8080/valley/
```
안드로이드 APK: https://github.com/kimblox26-arch/kimjamminGame/releases/download/valley-apk/valley-dam.apk (GitHub Actions 가 `android/` 를 빌드해 올립니다)

(저장소 루트에서 실행하세요. three.js 와 Rapier 물리엔진이 `vendor/` 에 들어 있어 인터넷 없이 동작합니다.)

## 조작
| 키 | 동작 |
|---|---|
| `W A S D` / `Shift` / `Space` | 이동 / 달리기 / 점프 |
| `1` 손 | `클릭`·`E` 돌·바위 줍기·내려놓기(큰 바위는 무거워 느리게 움직임), `우클릭` 던지기, `휠` 드는 거리, `Q`/`R` 돌 돌리기 |
| `2` 삽 | `좌클릭` 진흙 파기, `우클릭` 진흙 붓기 |
| `3` 곡괭이 | `좌클릭` 내려찍기 — 여러 번 찍으면 돌·바위가 2~4조각으로 깨짐(조각도 다시 깰 수 있음) |
| `4` 진흙 | 누르고 있으면 진흙을 무한으로 붓기 (파지 않아도 됨) |
| `F` 작업 속도 | 삽·진흙: 보통 ×1 → 약간 빠르게 ×3 → 엄청 빠르게 ×8 (삽은 담는 양 제한 없음) |
| `5` 낙석 | 조준한 곳 하늘(9~12 m)에서 바위가 떨어짐 — 흙이 패이고 물보라 |
| `6` / `7` | 비 켜기·끄기 / 최적화 모드 |
| `Esc` | 일시정지 |

화면 아래 버튼으로도 도구·비·최적화 모드를 바꿀 수 있습니다. 화면 위 막대는 막은 물의 비율입니다.

## 시뮬레이션
- **물**: 0.15 m 격자 얕은물 시뮬레이션(가상 파이프 + 체지 마찰). 웅덩이가 차오르고, 둑을 넘치고, 옆으로 돌아 흐릅니다.
- **돌 틈 침투**: 돌을 쌓은 자리는 공극률 38%의 돌무더기로 계산되어, 물이 돌 사이 틈으로 스며 빠져나갑니다(다시 법칙 흐름). 돌만 두 겹 쌓으면 약 65%만 막힙니다.
- **흙 침투**: 부어 놓은 흙더미와 돌 틈을 메운 진흙도 투수계수 0.02 m/s 로 아주 조금씩 물이 스며 나갑니다(흙둑 약 1~2% 누수). 수위가 오를수록 수압이 커져 더 많이 샙니다.
- **진흙**: 돌 위에 진흙을 부으면 먼저 돌 틈(공극)을 채우고, 다 차면 돌 위에 얹힙니다. 틈을 메우면 물이 거의 완전히 막힙니다. 빠른 물살에 드러난 진흙은 침식되어 흙탕물로 떠내려갑니다.
- **돌**: Rapier 강체 물리. 수압 차이·유속 항력·부력이 돌에 작용합니다. 높이서 떨어뜨리면 흙이 패이고 가장자리에 흙이 밀려 쌓입니다(암반은 안 패임).

## 성능
- 계곡 길이 36 m · 폭 24 m, 안개 너머(약 100 m 밖) 지형·나무는 만들지 않습니다. 풀·꽃·나무는 구역별로 나눠 화면 밖·먼 구역은 그리지 않습니다.
- 30fps 고정 + 자동 해상도: 30fps가 안 나오면 렌더 해상도를 자동으로 낮추고, 여유가 생기면 다시 올립니다.
- 물 계산은 물이 있는 곳 주변만 합니다(1/60초 간격). 굴절 패스에는 지형과 돌만 그립니다.

### 최적화 모드 (고화질 유지)
내부 해상도 최대 1.25배 + FXAA, 가벼운 셰이더(자갈·돌 결 단순화, 물속 빛무늬 끔), 블룸 끔, 굴절 0.45배, 풀 60%·26 m 이내, 그림자 1024·격프레임 갱신.

렌더 해상도 75%, 굴절 패스 생략(가벼운 반투명 물), 블룸·MSAA 끔, 풀 35%, 그림자 1024·3프레임마다 갱신, 물 계산 프레임당 최대 2회. 게임 중에도 `4` 키나 ⚡ 버튼으로 켜고 끌 수 있습니다.

## 그래픽
물 표면은 화면 공간 반사(SSR)로 계곡 벽·바위가 비치고, 1 mm 정도로 얇게 스며 나온 물도 젖은 막으로 보입니다.
물리 기반 렌더링 + ACES 톤매핑 + 블룸, 4K 그림자맵, 굴절(화면 공간)·흡수·프레넬 반사·햇빛 반짝임·흐름 방향 잔물결·거품·흙탕물을 표현하는 물 셰이더, 물속 바닥의 코스틱, 젖은 돌/자갈 표현, 절차적 자갈·암반·흙 텍스처, 바람에 흔들리는 풀 1만6천 포기, 침엽수·활엽수 숲, 폭포와 물안개, 비. 모든 소리는 WebAudio 로 실시간 합성됩니다.
