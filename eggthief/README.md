# 알 도둑 대작전 🥚

다른 기지에서 알을 훔쳐 내 둥지로 가져오는 블록 캐릭터 3D 웹 게임입니다. (봇 3명과 대결)

```
# 저장소 최상위 폴더에서
python3 -m http.server 8080
# → http://localhost:8080/eggthief/
```

## 규칙
- 둥지에 있는 알은 매초 코인을 벌어 줍니다: 보통 1 · 희귀 3 · 에픽 8 · 전설 20 · 신화 50
- **4분** 동안 누적 코인이 가장 많은 사람이 우승
- 남의 둥지 알이나 바닥에 떨어진 알을 훔쳐서 내 기지(파란색)로 들고 오면 자동으로 보관
- 알을 든 사람을 때리면 알을 떨어뜨림 → 15초 동안 아무도 안 주우면 원래 기지로 돌아감
- 기지 잠금(방어막): 10초 동안 다른 사람이 못 들어옴, 이후 30초 대기
- 둥지가 꽉 차면 가장 싼 알을 팔고 더 좋은 알로 교체
- 중앙 분수에서 야생 알이 계속 나옴

## 조작
| 키 | 동작 |
|---|---|
| WASD / 방향키 | 이동 |
| Space | 점프 |
| E | 훔치기 / 줍기 |
| F / 클릭 | 펀치 |
| Q / 기지의 초록 발판 | 기지 잠금 |
| B | 상점 (속도·둥지 칸·잠금 시간·펀치) |
| 마우스 드래그 · 휠 | 시점 회전 · 확대 |

모바일: 왼쪽 조이스틱 + 오른쪽 버튼, 화면 드래그로 시점 회전.
