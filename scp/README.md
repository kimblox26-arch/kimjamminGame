# SCP-096 — 격리 실패 (3D 웹 공포 게임)

SCP-096 이 격리실을 뜯고 나왔다. D계급 인원이 되어 **관측실의 LEVEL 3 키카드**를 찾고 **Gate A**로 탈출하세요.
**SCP-096 의 얼굴을 보면** 096 이 발작(얼굴을 감싸고 비명)한 뒤 문을 부수며 전력질주로 쫓아옵니다.

```
# 저장소 최상위 폴더에서
python3 -m http.server 8080
# → http://localhost:8080/scp/
```

## 조작
| 키 | 기능 |
|---|---|
| `W A S D` + 마우스 | 이동 / 시점 |
| `Shift` | 달리기 (스태미나) |
| `Space` | 점프 (상자·책상 위로 올라감) |
| `C` | 웅크리기 |
| `E` / `F` / `V` | 줍기 / 손전등 / 1인칭·3인칭 |

## 들어있는 것
- **SCP-096**: 2.4m 앙상한 몸, 긴 팔과 손가락, 갈비뼈·척추 융기, 크게 찢어지는 턱. 행동: 앉아서 흐느낌 → 가끔 고개를 들어 두리번(위험!) → 일어나 배회 → 얼굴 목격 시 발작 → 추격(문 파괴) → 처치
- **애니메이션**(모두 절차적): 096 흐느낌·배회·발작·질주(팔을 휘두르며 앞으로 쏠린 달리기)·처치, 플레이어 대기·걷기·달리기·점프·착지·웅크리기·사망, 머리가 시선을 따라감
- **사운드**(WebAudio 실시간 합성, 3D 위치): 096 흐느낌(들이쉬는 딸꾹질 숨·떨리는 울음·훌쩍임), 발작 울부짖음, 추격 비명, 발소리, 문, 문 파괴, 경보 사이렌, 심장박동, 숨소리, 환경음
- **얼굴 판정**: 카메라 화면 안 + 얼굴이 카메라 쪽 + 벽에 가리지 않음(유리창은 통과) + 손으로 가리지 않음

## 096 소리를 원본처럼 바꾸기
저작권 때문에 원본 음원은 넣지 않았습니다. 직접 가진 음원 파일을 아래 이름으로 `scp/sounds/` 에 넣으면 합성음 대신 그 파일이 재생됩니다 (mp3/ogg/wav).
- `scp096_cry.mp3` — 평소 울음
- `scp096_scream.mp3` — 발작·추격 비명
