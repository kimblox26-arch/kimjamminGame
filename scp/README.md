# SCP: 격리 실패 (3D 웹 공포 게임)

Site-19 격리 시설. 시작 화면에서 **캐릭터를 골라** 플레이합니다.

- **D계급 인원**: 관측실의 LEVEL 3 키카드를 찾아 Gate A 로 탈출. SCP-096 의 얼굴을 보면(유리창 너머라도) 096 이 강철문을 부수고 쫓아옵니다.
- **SCP 로 플레이**: 자기 격리실에서 시작해 문을 부수고 Gate A 로 시설을 빠져나가면 승리. 각 SCP 마다 움직임·애니메이션·능력이 다릅니다.

```
# 저장소 최상위 폴더에서
python3 -m http.server 8080
# PC: http://localhost:8080/scp/
# 휴대폰: 같은 와이파이에서 http://<PC의 IP>:8080/scp/  (가로 화면)
```

## 등장 SCP (각자 격리실에 갇혀 있음)
| SCP | 등급 | 플레이할 때 |
|---|---|---|
| SCP-096 수줍은 자 | Keter | 최고 10 m/s 질주, 부딪히면 문이 날아감 · 능력: 비명 발작 |
| SCP-173 조각상 | Euclid | 콘크리트 조각상. 매우 빠름, 점프 불가 · 능력: 순간 이동. (NPC 일 때는 아무도 보지 않을 때만 움직임) |
| SCP-049 역병 의사 | Euclid | 부리 가면·두건·로브, 느린 걸음 · 능력: 손길 |
| SCP-106 노인 | Keter | 벽을 통과, 걸을 때 부식 웅덩이 · 능력: 웃음 |
| SCP-939 수많은 목소리 | Keter | 붉은 네발 포식자, 높은 점프 · 능력: 울음 흉내(으르렁) |
| SCP-682 죽일 수 없는 파충류 | Keter | 거대한 파충류, 부딪히면 문이 날아감 · 능력: 포효 |
| SCP-999 간지럼 괴물 | Safe | 출렁이며 통통 튀는 주황 젤리, 아주 높은 점프 · 능력: 웃음소리 |

SCP 위키에는 수천 개의 SCP 가 있어 전부 넣을 수는 없어서, 잘 알려진 7종을 넣었습니다. 모델은 모두 위키 문서의 설명을 바탕으로 새로 만든 절차적 3D 모델입니다.
선택 화면의 초상화도 이모티콘이 아니라 이 3D 모델을 실제로 렌더링한 그림입니다.

## 조작
| PC | 모바일 | 기능 |
|---|---|---|
| `W A S D` + 마우스 | 왼쪽 스틱 + 화면 끌기 | 이동 / 시점 |
| `Shift` | 달리기 버튼(켜고 끄기) | 달리기 |
| `Space` | 점프 버튼 | 점프 |
| `C` | 웅크리기 버튼 | 웅크리기 |
| `E` | 행동 버튼 | 키카드 줍기(D계급) · 문 부수기(SCP) |
| `Q` | 능력 버튼 | SCP 능력 |
| `F` / `V` | 손전등 / 시점 버튼 | 손전등 / 1인칭·3인칭 |

모바일에서는 자동으로 성능 모드(해상도·그림자·블룸 축소)가 켜집니다. 버튼 아이콘은 모두 SVG 로 그린 그림입니다.

## 096 소리를 원본처럼 바꾸기
저작권 때문에 원본 음원은 넣지 않았습니다. 직접 가진 음원 파일을 아래 이름으로 `scp/sounds/` 에 넣으면 합성음 대신 그 파일이 재생됩니다 (mp3/ogg/wav).
- `scp096_cry.mp3` — 평소 울음
- `scp096_scream.mp3` — 발작·추격 비명
