# 도파민 리듬게임 제작 프롬프트

아래 블록 전체를 AI에게 그대로 붙여넣어 사용하세요.

---

```
너는 AAA급 리듬게임을 만들어 온 시니어 게임 개발자이자 모션 디자이너야.
"한 판만 더"를 멈출 수 없는, 도파민이 터지는 웹 리듬게임을 만들어줘.

## 0. 결과물
- 브라우저에서 바로 실행되는 단일 index.html (HTML + CSS + JS 한 파일, 외부 에셋 없이 동작)
- 렌더링: Canvas 2D 또는 WebGL, 60fps 이상 유지
- 오디오: Web Audio API로 음악을 직접 합성 (킥/스네어/하이햇/베이스/신스 리드) → 저작권 걱정 없이 바로 플레이
- 추가로 사용자가 MP3를 업로드하면 BPM·온셋 분석으로 채보를 자동 생성하는 모드
- 코드는 모듈 단위(Audio, Chart, Input, Judge, Render, FX, UI)로 깔끔하게 분리하고 주석은 핵심만

## 1. 핵심 게임플레이
- 4레인 (D F J K) 하강형 노트, 모바일은 터치 레인 지원
- 노트 종류: 탭 / 롱노트(홀드) / 동시치기 / 슬라이드(플릭)
- 판정 (오디오 시간 기준, performance.now 아님):
  PERFECT ±35ms / GREAT ±70ms / GOOD ±110ms / MISS
- 오디오 레이턴시 보정(오프셋 캘리브레이션) 화면 제공
- 노트 속도(하이스피드) 1.0~10.0 조절
- 곡 3개 이상 내장, 각 곡 난이도 EASY / NORMAL / HARD / EXTREME
- 채보는 실제 음악 구조(인트로→빌드업→드롭→브레이크)에 맞춰 밀도가 오르내려야 함
  드롭 구간에서 노트 밀도와 이펙트가 폭발하도록 설계

## 2. 도파민 장치 (가장 중요)
- 타격감: 노트를 칠 때마다 레인이 번쩍, 히트 사운드, 파티클 버스트, 판정 텍스트가 튀어오르며 스케일 바운스
- 콤보 카운터: 숫자가 올라갈 때마다 펀치 스케일 애니메이션, 50/100/200/500 콤보마다 화면 전체 플래시 + 특수 이펙트 + 보이스풍 SFX
- FEVER 모드: 게이지가 차면 발동 → 점수 2배, 배경이 하이퍼스페이스로 전환, 색상 반전/무지개 사이클, 카메라 줌 펄스
- 스크린 셰이크, 색수차(chromatic aberration), 블룸/글로우, 모션 트레일, 화면 가장자리 비네트 펄스를 비트에 동기화
- 배경 전체가 음악에 반응: 킥에 맞춰 펄스, 베이스에 맞춰 이퀄라이저 바, 하이햇에 맞춰 별 반짝임
- 미스 시: 화면 살짝 붉게 + 글리치 효과, 콤보 깨지는 소리 (짜증 아닌 '다시 하고 싶은' 느낌)
- 결과 화면: 점수가 빠르게 카운트업, 랭크(SSS/SS/S/A/B/C)가 쾅 하고 찍히며 파티클 폭발, FULL COMBO / ALL PERFECT 전용 연출
- 최고 기록 갱신 시 "NEW RECORD!" 연출, localStorage에 기록 저장

## 3. 비주얼 스타일
- 컨셉: 네온 사이버펑크 × Y2K 홀로그램, 다크 배경 위 형광 컬러
- 팔레트: 딥 네이비(#0a0a1f) 배경 + 핫핑크(#ff2e88) / 일렉트릭 시안(#00f0ff) / 라임(#b6ff00) / 퍼플(#8a2eff)
- 레인별 고유 색상, 노트는 유리질 그라데이션 + 외곽 글로우
- 판정선은 빛나는 레이저 바, 비트마다 숨 쉬듯 밝기 변화
- 폰트: 굵은 디스플레이 폰트(Orbitron, Russo One 등 웹폰트 또는 시스템 대체)
- 모든 UI 전환에 이징(easeOutBack, easeOutExpo) 적용, 딱딱한 전환 금지

## 4. 화면 구성
1) 타이틀: 로고가 비트에 맞춰 펄스, "PRESS ANY KEY"
2) 곡 선택: 카드형 캐러셀, 선택 시 프리뷰 음악 재생 + 앨범아트풍 생성 그래픽, 난이도 별
3) 플레이: 상단 점수/정확도, 중앙 콤보, 하단 판정선, 진행바, FEVER 게이지
4) 일시정지: ESC, 블러 오버레이
5) 결과: 판정별 개수, 최대 콤보, 정확도, 랭크, 재시작/곡선택 버튼
6) 설정: 키 바인딩, 하이스피드, 오프셋, 이펙트 강도(저사양/광과민 대응), 볼륨

## 5. 품질 기준
- 입력 지연 최소화: keydown 즉시 처리, 판정은 AudioContext.currentTime 기준
- 파티클은 오브젝트 풀링으로 GC 스파이크 방지
- devicePixelRatio 대응으로 레티나에서도 선명하게
- 창 크기 변경/모바일 세로 화면에 반응형 대응
- 이펙트 강도 0~100% 슬라이더, 광과민성 경고 및 플래시 감소 옵션
- 콘솔 에러 0개

## 6. 작업 방식
- 먼저 전체 구조와 채보 데이터 포맷을 짧게 설명한 뒤 완성 코드를 작성
- 생략("...나머지 동일") 없이 바로 실행 가능한 전체 코드 제공
- 마지막에 조작법과 커스텀 곡/채보 추가 방법을 5줄 이내로 정리
```
