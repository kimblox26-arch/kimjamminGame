# SpaceSim 🪐 — Astrophysical Simulation Software

브라우저에서 동작하는 천체물리 시뮬레이션 소프트웨어입니다.
**N체 중력 적분기 · 케플러 궤도역학 · 항성물리 · 우주론 계산**을 하나의 작업환경에서 다룹니다.

```
저장소 루트에서 로컬 웹서버를 띄우고 /spacesim/ 을 여세요.
  python3 -m http.server 8080     →  http://localhost:8080/spacesim/
```
> `file://` 로 직접 열면 ES 모듈 보안 정책 때문에 실행되지 않습니다.
> three.js 는 저장소의 `vendor/` 를 재사용하므로 **인터넷 없이 동작**합니다.

설치 없이 바로 쓰려면 GitHub Pages 배포본을 여세요 — **https://kimblox26-arch.github.io/kimjamminGame/spacesim/**

## 1. 수치 모형

### 단위계
내부 계산은 천문 단위계를 씁니다 — 길이 **AU**, 시간 **일(day)**, 질량 **M☉**.
이 단위계에서 중력상수는 가우스 중력상수의 제곱 `G = k² = 2.959122082855911e-4` 입니다.
추상 시나리오(3체 문제, 성단, 은하)는 `G = 1` 의 코드 단위를 씁니다.

### 적분기

| 적분기 | 차수 | 심플렉틱 | 스텝당 힘 계산 | 용도 |
|---|---|---|---|---|
| 심플렉틱 오일러 | 1 | ○ | 1 | 오차 비교용 교보재 |
| 속도 베를레 (KDK) | 2 | ○ | 1 | 대규모 N, 기본값 |
| Forest-Ruth | 4 | ○ | 3 | 고정밀 소규모 계 |
| PEFRL | 4 | ○ | 4 | 태양계 장기 적분(권장) |
| Runge-Kutta 4 | 4 | ✕ | 4 | 비교 대상(에너지 드리프트) |

심플렉틱 적분기는 에너지 오차가 **유계로 진동**하고, RK4 는 시간에 따라 **단조 증가**합니다.
진단 탭의 보존량 그래프에서 두 거동을 직접 비교할 수 있습니다.

### 중력 모형
- **뉴턴 중력** — 소프트닝 ε 을 포함한 직접합 `a = Σ G m_j (r_j−r_i) / (|r|²+ε²)^{3/2}`
- **Barnes-Hut 8분트리** — 열림각 θ 로 정밀도/속도를 조절하는 O(N log N) 근사
- **1PN 상대론 보정** — 중심 천체 기준 슈바르츠실트 항

  `a_GR = GM/(c²r³) · [ (4GM/r − v²)·r⃗ + 4(r⃗·v⃗)·v⃗ ]`

  이 항만으로 수성 근일점 이동 **42.9″/세기**가 재현됩니다(이론값 42.98″).
- **충돌 병합** — 반지름이 겹치면 운동량 보존 완전비탄성 합체, 부피 합으로 새 반지름 결정

### 케플러 역학
상태벡터 ↔ 궤도요소(a, e, i, Ω, ω, ν, M) 양방향 변환, 타원·쌍곡선 케플러 방정식의
3차 수렴(Halley) 해법, 궤도 곡선 샘플링, 힐 반경·로슈 한계·비스비바 방정식을 제공합니다.

### 우주론
프리드만 방정식 `E(z) = √(Ω_r(1+z)⁴ + Ω_m(1+z)³ + Ω_k(1+z)² + Ω_Λ)` 를 심프슨 적분해
공변거리·각지름거리·광도거리·거리지수·후퇴시간·우주 나이·입자/사건 지평선을 계산하고,
척도인자 `a(t)` 를 RK4 로 적분해 팽창사를 그립니다. Planck 2018 기준 우주 나이 **13.79 Gyr**.

### 항성물리
플랑크 함수를 CIE 등색함수로 적분한 정확한 흑체색, 구간별 질량-광도 관계, 주계열 수명,
분광형 분류, HR 도표, 거주가능영역·서리선, 슈바르츠실트 반지름, 최종 운명 예측.

### 실측 데이터
- **궤도요소** — JPL *Keplerian Elements for Approximate Positions of the Major Planets*
  (1800–2050년 유효). J2000 값과 세기당 변화율을 함께 갖고 있어 **임의 날짜로 초기화**할 수
  있습니다. `오늘` 버튼을 누르면 오늘의 실제 행성 배치가 됩니다.
- **물리 제원** — NASA Planetary Fact Sheet 기준의 반지름·질량·자전주기·자전축 기울기·
  알베도·표면온도·중력·탈출속도·밀도·대기 조성. 선택 천체 패널에 그대로 표시됩니다.
- **항성 카탈로그** — 3.5등급까지의 실측 항성 163개를 J2000 적경·적위에서 황도좌표계로
  변환해 배치합니다. 별자리 선 16개와 은하 북극 기준으로 생성한 은하수 띠를 함께 그립니다.

### 렌더링
화면에서 4 px 이상으로 커진 천체는 점 스프라이트 대신 **실제 구체**로 전환됩니다.
- 표면 텍스처는 구면 좌표 3D 값 노이즈로 합성 — 이음매·극 왜곡이 없고 외부 이미지가 필요 없습니다.
  (지구: 대륙·해양·빙관·구름 / 목성·토성: 위도 띠와 대적점 / 이오: 유황과 화산 칼데라 /
  유로파: 리네아 균열 / 달·수성·칼리스토: 크레이터)
- 조명 방향은 **시뮬레이션 좌표계의 항성 방향**에서 구하므로 위상(초승달·반달)과
  명암경계가 실제 배치와 일치합니다. 대기가 있는 천체는 낮쪽 가장자리에 산란 림라이트가 생깁니다.
- 자전주기와 자전축 기울기를 적용해 회전합니다(금성·천왕성·명왕성은 역행).
- 토성 고리는 실제 C/B/A 고리와 카시니 간극 구조를 재현하고, 행성 그림자가 고리에 드리웁니다.

| 외계 행성계 | 쌍성 + 주연성 행성 | Kepler-16 형 circumbinary 궤도의 세차 |
| 외계 행성계 | 코자이-리도프 진동 | √(1−e²)·cos i ≈ 일정 관계의 주기적 교환 |

| 항성계 역학 | 은하 충돌 | 조석꼬리·다리 형성 후 병합 (Barnes-Hut) |
| 항성계 역학 | 블랙홀 조석 파괴 | 조석 반경 통과 시 절반 강착 / 절반 초고속 방출 |

## 3. 인터페이스

- **좌측 패널** — 시나리오 선택, 적분 설정(적분기·Δt·소프트닝·θ·1PN·충돌), 표시 설정
- **우측 패널** — 5개 탭
  - `천체` 천체 목록과 선택 천체의 전체 궤도요소·힐 반경·탈출속도
  - `진단` 에너지/각운동량 보존 오차 시계열, 비리얼비, 계 전체량, 이벤트 로그
  - `항성` 질량·나이 슬라이더 기반 항성 계산기, HR 도표, 흑체 스펙트럼
  - `우주론` 우주 모형 슬라이더, 거리 척도 전체, a(t) 팽창사, 거리-적색편이 곡선
  - `도구` 궤도요소로 천체 투입, CSV/JSON/PNG 내보내기, 단위 환산표
- **하단** — 실행/일시정지, 한 스텝, 초기화, 속도 배율(0.01×–250×)

### 조작

| 입력 | 동작 |
|---|---|
| 드래그 | 궤도 회전 |
| 휠 · 핀치 | 줌 |
| Shift+드래그 · 우클릭 드래그 | 화면 이동 |
| 클릭 / 더블클릭 | 천체 선택 / 카메라 추적 |
| `Space` `.` `R` | 실행·정지 / 한 스텝 / 초기화 |
| `[` `]` | 속도 감소 / 증가 |
| `T` `L` `G` `F` `C` | 궤적 / 라벨 / 격자 / 추적 / 질량중심 고정 |
| 더블클릭 · `F` | 천체 추적 — 구체가 화면을 채우는 거리로 이동 |
| `1`–`5` | 우측 탭 전환 |

### 공간 스케일
`로그` 모드는 반경 방향을 `log₁₀(1 + r/r₀)` 로 압축해 수성부터 명왕성까지 한 화면에 담습니다.
**표시 전용 변환이며 물리 계산에는 전혀 영향을 주지 않습니다.**

## 5. 코드 구조

```
spacesim/
  index.html              UI 마크업
  styles/spacesim.css     관측 장비 테마
  src/
    main.js               상태 · 렌더 루프 · UI 바인딩
    core/constants.js     상수 · 단위 환산 · 포맷터
    data/
      bodies.js           JPL 궤도요소 + NASA 물리 제원
      skycatalog.js       실측 항성 163개 · 별자리 · 은하좌표
    physics/
      nbody.js            적분기 · 힘 계산 · 보존량 진단
      kepler.js           궤도요소 변환 · 케플러 방정식
      barneshut.js        평탄화 8분트리
    astro/
      stars.js            흑체복사 · 주계열 관계 · HR
      cosmology.js        프리드만 방정식 · 거리 척도
    sim/scenarios.js      시나리오 라이브러리
    render/
      view.js             three.js 씬 · 포인트 셰이더 · 궤적 · 카메라
      bodies.js           구체 LOD · 조명/위상 셰이더 · 토성 고리
      textures.js         절차적 표면 텍스처 (구면 노이즈)
      sky.js              실측 항성 · 별자리 · 은하수
      overlay.js          2D 라벨 · 스케일바 · 도표
    ui/tools.js           항성 · 우주론 · 단위 패널
```

상태는 전부 `Float64Array` 에 평탄 저장되며, 힘 계산과 적분은 할당 없이 수행됩니다.
프레임당 물리 예산(12 ms)을 초과하면 서브스텝을 중단해 대규모 N에서도 프레임률이 유지됩니다.
