# SpaceSim 🪐

행성을 구슬처럼 던져 보는 간단한 3D 중력 샌드박스입니다.
뉴턴 만유인력(N체)과 충돌 병합이 적용됩니다.

```
저장소 루트에서:  python3 -m http.server 8080   →  http://localhost:8080/spacesim/
```

- 장면: 태양계 · 쌍성계 · 삼체 문제(8자 궤도) · 빈 우주
- **＋ 천체 추가** 후 클릭하면 원궤도, 드래그하면 그 방향으로 던집니다
- 마우스 드래그 회전 · 휠 확대 · 클릭 선택 · 더블클릭 따라가기 · `Space` 일시정지 · `Esc` 따라가기 해제

파일: `src/physics.js` (중력·충돌), `src/main.js` (화면·조작)
