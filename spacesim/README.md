# SpaceSim — Astrophysical Simulation Software 🌌

브라우저에서 바로 실행되는 **3D 천체물리 시뮬레이터 + 우주선 조종 게임**입니다.
모든 천체는 실제 물리 법칙(뉴턴 만유인력 N체 직접합, 일반상대론 보정, 블랙홀 의사뉴턴 퍼텐셜)으로 실시간 계산됩니다.

```
저장소 루트에서 웹서버 실행 → http://localhost:8080/spacesim/
  python3 -m http.server 8080
```
> `file://` 로는 ES 모듈이 막혀 실행되지 않습니다. three.js 는 `../vendor/` 의 것을 사용하므로 오프라인에서도 동작합니다.

## 시나리오

| 시나리오 | 내용 |
|---|---|
| 태양계 (실시간) | JPL 근사 궤도요소(J2000 + 평균경도 변화율)로 **오늘 날짜의 실제 행성 위치**에서 시작. 행성 9 · 위성 8 · 소행성대/트로이군/카이퍼대 4,500개. 지구 저궤도(400 km) 우주선 조종 |
| 쌍성계 Kepler-16 | 실측값 기반 주쌍성 행성계. 쌍성 근처 불안정 영역에서 잔해 원반이 깎여 나감 |
| 삼체 — 8자 궤도 | Chenciner–Montgomery 주기해. 적분기를 바꿔 수치 오차 비교 |
| 삼체 — 피타고라스 | 질량 3·4·5 별의 카오스적 근접조우와 방출 (Burrau 문제) |
| 은하 충돌 | Toomre & Toomre(1972) 제한 3체 모형, 15,000개 항성 → 조석 꼬리·다리 형성 |
| 초대질량 블랙홀 | Sgr A* 규모. 파친스키–비타 퍼텐셜(ISCO 6GM/c²), 점성 강착원반, 도플러 빔효과, 중력렌즈, **조석 붕괴(TDE)** |
| 원시 행성계 원반 | 미행성 90개가 충돌·병합하며 원시 행성으로 성장 |
| 샌드박스 | 행성·항성·블랙홀을 직접 배치 (클릭 = 원궤도, 드래그 = 속도 지정) |

## 물리 엔진 (`src/physics.js`)

- **N체 직접합 O(N²)**, 적응 시간 간격 `dt = η·min√(r³/GM)`
- 적분기 4종: **Yoshida 4차 심플렉틱**(기본) · Leapfrog KDK · RK4 · 오일러 — 진단 패널에서 에너지(ΔE/E₀)·각운동량 보존을 실시간 비교
- **일반상대론 1PN 보정** (Schwarzschild 시험입자 근사) — 수성 근일점 세차 43″/세기 재현
- **블랙홀**: 파친스키–비타 퍼텐셜 `Φ = −GM/(r−r_s)`, 사건지평선 흡수
- **충돌**: 운동량 보존 완전 비탄성 병합 (부피 합산 반지름, 항성 질량–광도 관계)
- **조석 붕괴**: `r < R*(M_BH/M*)^(1/3)` 에서 항성이 잔해 흐름으로 분해
- **제한 N체**: 질량 없는 시험 입자 수만 개를 주요 섭동체 위치 보간으로 적분 (입자별 서브스텝)
- Plummer 연화(은하), 영향권(SOI) 계층 자동 계산

### 검증 결과 (헤드리스 Node 테스트)
| 항목 | 결과 |
|---|---|
| 태양계 10년 에너지 오차 (Yoshida) | ΔE/E ≈ 7×10⁻¹³ |
| Kepler-16 쌍성 공전주기 | 41.08 일 (실측 41.08 일) |
| 8자 궤도 1주기 후 복귀 오차 | 4×10⁻⁸ AU |
| 수성 근일점 GR 세차 | 43.0″/세기 (이론 43.0″) |
| 지구→달 전이 Δv | 약 3.1 km/s (실제 TLI와 일치) |

## 우주선 (`src/ship.js`)

- 치올코프스키 로켓 방정식 (건조질량 4 t + 연료 18 t), 엔진 3종: 화학(Isp 450 s) · 핵열(900 s) · 핵융합 토치(가상, 10⁵ s)
- SAS 자동 자세: 자세유지 · 순행 · 역행 · 법선 · 반법선 · 방사 외향/내향
- 지수 대기 항력 + Sutton–Graves 공력가열 (지구·화성·금성·타이탄·가스행성)
- **N체 수치 적분 궤적 예측**: 다른 천체 영향권 진입(주황색 구간)·충돌 경고
- 저속 접지 시 착륙, 고속이면 파괴

## 그래픽 (`src/view.js`, `src/shaders.js`)

- 카메라 상대 좌표(부동 원점) + 로그 깊이 버퍼 → 10 m 우주선부터 100 kpc 은하까지 한 장면
- 절차적 행성 셰이더(지구형 대륙·구름·도시 불빛, 가스행성 띠·폭풍, 크레이터, 얼음 균열, 이오 화산), 범프 매핑
- 대기 산란 림, 토성 고리(카시니 간극, 고리 그림자 ↔ 행성 그림자), **일식/월식 소프트 섀도**
- 흑체 온도 기반 항성 색, 쌀알무늬·흑점·주연감광 항성 표면, 코로나
- 은하수 배경 (실제 은하 좌표 방향) + 9,000개 배경 별, ACES 톤매핑 + 블룸, 중력렌즈 후처리

## 조작

| 키 | 기능 |
|---|---|
| 드래그 / 휠 | 카메라 회전 / 확대 |
| 클릭 / 더블클릭 | 선택 / 포커스 |
| `[` `]` · `F` · `G` | 천체 전환 · 우주선 · 질량중심 |
| `,` `.` `/` `Space` | 시간 가속 감소·증가 · 실시간 · 일시정지 |
| `W S A D Q E` | 피치 · 요 · 롤 |
| `Shift` / `C` · `Z` / `X` | 스로틀 증가/감소 · 최대/차단 |
| `1`~`7` · `T` | SAS 모드 · SAS 끔 |
| `R` · `O` · `L` · `H` | 우주선 재배치 · 궤도 표시 · 이름표 · 도움말 |

## 구조

```
spacesim/
  index.html, style.css
  src/orbit.js       상수 · 케플러 궤도요소 ↔ 상태벡터 · 흑체색
  src/physics.js     N체 엔진 · 적분기 · GR · 충돌 · 조석 붕괴 · 시험 입자
  src/scenarios.js   실제 천체 데이터 · 시나리오 8종
  src/ship.js        우주선 동역학 · SAS · 궤적 예측
  src/shaders.js     GLSL (행성 · 대기 · 고리 · 항성 · 은하수 · 입자 · 렌즈)
  src/view.js        three.js 렌더러
  src/main.js        게임 루프 · 카메라 · 입력 · UI
```
