# SpaceSim 🌌 — Astrophysical Simulation Software

브라우저에서 바로 실행되는 3D 천체물리 시뮬레이터. 데스크톱과 모바일(터치)에서 모두 동작합니다.

```
python3 -m http.server 8080      # 저장소 루트에서 실행
→ http://localhost:8080/spacesim/
```
> `file://`로 열면 ES 모듈 정책 때문에 실행되지 않습니다. three.js는 `../vendor/`의 로컬 사본을 사용하므로 오프라인에서도 동작합니다(폰트만 온라인).
> 모바일에서는 브라우저 메뉴의 "홈 화면에 추가"로 전체 화면 앱처럼 실행할 수 있습니다(PWA 매니페스트 포함).

## 시나리오

| # | 시나리오 | 물리 모델 |
|---|---|---|
| 1 | **태양계** | JPL 근사 궤도 요소로 *오늘 날짜*의 실제 행성 배치를 계산해 시작. 태양·8행성·명왕성·달·갈릴레이 위성·타이탄을 직접 N-체 적분(KDK 립프로그, Δt≈26분). 소행성대·카이퍼대 수천 개는 GPU 케플러 방정식으로 계산 |
| 2 | **블랙홀** | 픽셀마다 슈바르츠실트 널 측지선(x″ = −3/2·h²x/r⁵)을 거꾸로 추적. 중력 렌즈, 광자 고리, 그림자, Shakura–Sunyaev 원반 온도, 상대론적 도플러 빔, 중력 적색편이 |
| 3 | **은하 충돌** | Toomre & Toomre 제한 N-체 + 동역학적 마찰. 최대 10만 입자(별·HII 성운·가스). 안테나 / M51 / 우리은하×안드로메다 / 역행 비교 |
| 4 | **구상성단** | 플러머 구(Aarseth–Hénon–Wielen) + 살피터 IMF, O(N²) 직접 합산. 반질량 반경·비리얼 비·탈출 별 실시간 측정, 중심 IMBH 옵션 |
| 5 | **삼체 문제** | 8자 궤도, 나비·나방 주기 해, 라그랑주 삼각형, 피타고라스 혼돈 (적응형 시간 간격). 미세 섭동으로 나비 효과 실험 |
| 6 | **쌍성계** | Kepler-16 실측 궤도 요소 + 안정/불안정 영역 시험 행성 |
| 7 | **샌드박스** | 탭 = 원궤도 발사, 드래그 = 속도 지정(예상 궤적 표시). 운동량 보존 충돌 병합, 원시행성 원반 강착 실험 |

## 그래픽
- HDR 렌더링 + ACES 톤매핑 + 블룸, MSAA, 동적 해상도(프레임 유지)
- 텍스처 파일 없이 전부 절차적 셰이더: 지구(대륙·해양 반사·구름·도시 불빛·대기 산란), 목성 대적점, 토성 고리(카시니 간극·행성 그림자·고리 그림자), 크레이터, 이오 화산, 유로파 균열, 항성 쌀알 무늬·흑점·주연 감광·코로나
- 절차적 은하수(먼지띠·성운) + 항성 2만 6천 개(흑체 색)
- 품질 단계: 자동 / 낮음 / 중간 / 높음 / 울트라

## 조작
| 입력 | 동작 |
|---|---|
| 한 손가락 드래그 / 마우스 왼쪽 | 회전 (관성) |
| 핀치 / 휠 | 확대·축소 |
| 두 손가락 드래그 / 오른쪽 버튼 | 이동 |
| 천체·이름표 탭 | 추적 + 정보 패널 · 더블탭: 근접 |
| `Space` · `[` `]` · `R` · `F` · `H` · `1`–`7` | 재생/정지 · 배속 · 초기화 · 추적 해제 · UI 숨김 · 시나리오 |

## 구조
```
spacesim/
  index.html · style.css · manifest.webmanifest · icon.svg
  js/main.js        앱·렌더러·후처리·루프·품질/동적 해상도
  js/physics.js     N-체 적분기 (Float64 SoA, 립프로그, 적응 Δt, 병합)
  js/bodies.js      행성/항성/고리/대기 셰이더
  js/sky.js         은하수 + 항성 배경, 블랙홀용 큐브맵
  js/controls.js    터치/마우스 궤도 카메라
  js/trails.js      궤적·마커·궤도 타원·섬광·발광 입자
  js/scenarios/     7개 시나리오
```
