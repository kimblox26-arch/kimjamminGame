# 🔨 못 박기 3D

숲속 나무 그루터기에 망치로 못을 박는 3D 게임입니다. (마우스·터치 모두 지원)
three.js(`vendor/three`)로 그렸습니다.
- 그루터기: 실제로 울퉁불퉁한 나무껍질(지오메트리 변위 + 노멀맵), 나이테·톱자국·톱밥이 있는 단면
- 숲: 3D 낙엽 수천 장, 바람에 떨어지는 낙엽, 풀싹, 가지 모양 나무, 멀리 보이는 숲
- 하늘: 해와 햇빛 번짐, 뭉게구름, 대기 원근감(안개)
- 후처리: 블룸, MSAA 안티에일리어싱, 색 보정·비네팅, 4K 그림자(모바일은 자동으로 낮춤)
화면에 글씨·점수·스테이지 없이 못 박기만 합니다.

## 실행
```
# 저장소 최상위 폴더에서
python3 -m http.server 8080
http://localhost:8080/nailgame/
```
> 파일을 더블클릭(`file://`)하면 ES 모듈 보안 정책 때문에 실행되지 않습니다. 반드시 웹서버로 여세요. (인터넷 연결은 필요 없음)

## 하는 법
- 화면 아무 곳이나 눌러 망치를 잡고, 못 위에서 **빠르게 아래로 휘두르세요.** 빠를수록 깊이 박힙니다.
- 천천히 누르기만 하면 박히지 않아요. 한 번 친 뒤에는 망치를 살짝 들어 올려야 다시 칠 수 있습니다.
- 망치 가장자리로 세게 치면 못이 휘어요.
- 못을 다 박으면 잠시 뒤 새 못이 올라옵니다.
