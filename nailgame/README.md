# 🔨 못 박기 (Nail It!)

망치를 **드래그**해서 위에서 아래로 내려쳐 못을 나무에 박는 게임입니다. (마우스·터치 모두 지원)

## 실행
```
# 저장소 최상위 폴더에서
python3 -m http.server 8080
http://localhost:8080/nailgame/
```
`nailgame/index.html` 파일 하나로 되어 있어서 더블클릭으로 열어도 실행됩니다.

## 규칙
- 화면 아무 곳이나 눌러 망치를 잡고, 못 위에서 **빠르게 아래로 휘두르세요.** 빠를수록 깊이 박힙니다.
- 천천히 누르기만 하면 박히지 않아요. 한 번 친 뒤에는 망치를 살짝 들어 올려야 다시 칠 수 있습니다.
- 망치 **가장자리로 세게 치면 못이 휘어요** (♥ -1). 하트 3개를 모두 잃거나 시간이 끝나면 게임 오버.
- 적은 횟수로 박을수록 높은 점수: `ONE SHOT!` 300 · `PERFECT!` 150 · `GOOD` 100, 연속 성공 시 콤보 보너스, 남은 시간 보너스.
- 스테이지가 오를수록 못이 늘어나고 나무가 단단해집니다: 소나무 → 참나무 → 마호가니 → 흑단.
