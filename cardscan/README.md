# 📷 카드 스캐너

포켓몬 카드를 카메라로 찍으면 **카드 이름·세트·희귀도·시세**를 찾아주는 웹앱(PWA)입니다.

```
python3 -m http.server 8080   →  http://localhost:8080/cardscan/
```
> 휴대폰 카메라는 **https** 또는 localhost에서만 열립니다. GitHub Pages 등에 올리면 폰에서 바로 쓸 수 있고, "홈 화면에 추가"로 앱처럼 설치됩니다.

## 기능
- **찍어서 찾기**: 카드를 틀에 맞추고 찍으면 OCR(Tesseract.js)로 위쪽 *이름*과 아래쪽 *카드 번호(예: 025/198)*를 읽습니다.
  번호/전체 수 → 해당 세트 → 카드를 찾고, 이름으로 한 번 더 걸러냅니다.
- **사진 올리기 / 이름·번호 검색**: 카메라가 없을 때.
- **내 컬렉션**: 담은 카드와 수량, 예상 가치 합계 (브라우저에 저장).
- 카드 언어 선택: 한국어 / English / 日本語.

## 구조
| 파일 | 역할 |
|---|---|
| `index.html`, `style.css` | 화면 (모바일 우선, 다크모드) |
| `app.js` | 카메라 · OCR · 카드 DB 검색 · 컬렉션 |
| `sw.js`, `manifest.json` | 홈 화면 설치 / 오프라인 앱 화면 |

## 참고
- 카드 데이터: [TCGdex](https://tcgdex.dev) 무료 API (키 불필요). 언어별 데이터 양은 다를 수 있어요.
- 시세는 TCGplayer(USD)/Cardmarket(EUR) 참고값입니다.
- 비공식 팬 제작 도구입니다.
