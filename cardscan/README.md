# 포켓 컬렉터 (카드 시세 스캔 · 띠부씰 기록장)

휴대폰 카메라로 포켓몬 카드를 비추면 **자동으로 어떤 카드인지 알아내고 시세(원화)를 보여주는** 웹앱입니다.
포켓몬빵 **띠부씰 기록장**도 들어 있습니다. AI·유료 서비스 없이 무료로 동작합니다.

## 화면
- **홈**: 내 컬렉션 가치(카드 + 띠부씰 합계), 카드 스캔 / 띠부씰 기록장 바로가기, 최근 스캔한 카드
- **카드 스캔**: 카메라 화면. 인식되면 카드 위에 가격이 크게 뜨고, 아래에 최근 카드 묶음과 "카드 N장" 버튼
- **스캔한 카드**: 2열 카드 목록 + 합계, 선택해서 삭제
- **띠부씰 스캔**: 띠부씰은 공개 이미지·시세 데이터가 없어서 **처음 한 번은 어떤 포켓몬인지 골라 등록**하면,
  그 모습(지문)을 기억해 다음부터 자동으로 알아보고 가격을 띄웁니다. 볼 때마다 지문이 쌓여 점점 잘 알아봅니다.
  가격은 내가 적은 가격, 없으면 참고 시세(뮤츠·뮤·리자몽·잠만보만, 2026년 6월 기사 기준)를 씁니다.
- **내 띠부씰**: 세대별 도감, 개수·가격·메모·사진, 번개장터/네이버 시세 검색 링크

## 쓰는 법
1. 휴대폰 브라우저로 `cardscan/` 페이지를 엽니다 (HTTPS 필요 — GitHub Pages 등).
2. **카드 스캔** → 카드를 화면의 네모 안에 맞추면 "삑" 소리와 함께 자동으로 목록에 추가됩니다.
3. 카드를 빼고 다음 카드를 넣으면 계속 이어서 인식합니다.
4. **목록 보기**: 스캔한 카드와 총합 금액. 카드를 누르면 종류(일반/홀로/리버스)·카드 상태를 바꾸거나, 비슷한 다른 카드로 바꿀 수 있습니다.
5. 인식이 안 되면 돋보기(**직접 검색**)에서 한글·영어 이름이나 번호(`025/165`)로 찾습니다.
6. 카드 이름은 포켓몬 이름을 한글로 바꿔 보여줍니다 (`data/pokemon-names.json`, npm `pokemon` 패키지 MIT).

## 어떻게 동작하나
- **이미지 매칭**: 카드 약 2만 장의 그림을 미리 64비트 "지문"(perceptual hash) 두 개(카드 전체·일러스트)로 만들어 `data/hashes.bin`에 저장해 두고,
  카메라 화면의 지문과 가장 가까운 카드를 찾습니다. 모든 계산은 휴대폰 안에서 합니다.
- **시세**: [Pokémon TCG API](https://pokemontcg.io)의 TCGplayer 시세(달러)를 `data/cards.json`에 함께 저장하고, 환율(open.er-api.com)로 원화로 바꿉니다.
- 시뮬레이션(흐림·기울어짐·빛 반사를 섞은 사진 200장) 결과: 1순위 정답 96.5%, 후보 3개 안 98.5%, 장당 약 25ms.

## 한계
- 영어판 카드 기준입니다. 한국판도 그림이 같으면 영어판으로 인식되고, 시세도 영어판 기준입니다.
- 이미지가 없는 최신 세트 일부(약 1,000장)는 사진 인식은 안 되고 직접 검색으로만 찾을 수 있습니다.
- 시세는 실시간이 아니라 데이터를 만든 시점 기준입니다.

## 데이터 다시 만들기 (시세 갱신)
```bash
cd cardscan/tools && npm install
NODE_USE_ENV_PROXY=1 node fetch-cards.mjs /tmp/cards 8     # 카드 목록 + 시세
NODE_USE_ENV_PROXY=1 node build-db.mjs /tmp/cards 32       # 이미지 지문 → ../data/
```
`NO_DL=1`을 붙이면 이미지는 다시 받지 않고(캐시 사용) 시세만 갱신합니다.
테스트: `python3 test/make-frames.py /tmp/cards/raw-cards.json /tmp/frames 200 && node test/run-test.mjs /tmp/frames`
