# 가족 타워 디펜스

브라우저 2D 타워 디펜스 (개발 중).

```
python3 -m http.server 8080   →  http://localhost:8080/tower-defense/
```

## 게임 흐름 (유튜브 '코테고리' 가족 타워 디펜스 따라 만들기)
1. **전장**: 잼민이(농부)가 맵 오른쪽 아래에서 웨이브 없이 계속 나와 흙길을 돈다.
   - 전장 아래: **잼민이 강화**(왼쪽) · **가족 생성**(사용자가 그린 네모 자리) · 타워로 가기
   - 잼민이 Lv.1: 체력 10, 잡으면 **5원** → 잼민이 강화(100원) Lv.2: 빨간 옷, 체력 20, 잡으면 **10원**
2. **타워(집) Lv.1**: 빈 잔디밭의 집을 **끌어다 놓으면** 엄마·아빠가 걸어 나와 만세 → 전장으로.
   이때는 `대출이자 갚기`와 `타워 추가 2/3`만 보인다(처음부터 최대가 아님).
3. **타워 추가 = 아기 만들기(300원)**: 엄마는 싫다고 화내고 아빠는 엎드려 빌고 → 하트 → 아기가 기어 나와 **벌떡 일어서고**(Lv.1 애기) → 전장.
   전장에서도 아기는 기어 들어와 자리에서 일어선 모습으로 젖병을 던진다. 전장의 `가족 생성` 버튼도 같은 기능.
4. **대출이자 갚기(1000원)**: 집이 무너지고 Lv.2 집으로 다시 지어짐 → 그때부터 카드가 생긴다:
   엄마 강화 · 학교(1500원) · 상점 · 회사 · 분양소. 다 산 카드는 사라져서 할 수 있는 것만 보인다.
5. **애기 강화(500원, 학교를 지으면 생김)**: 아기가 학교에 들어가 → 어둠 속 푸른 기운·붉은 마법진 → 깔깔 웃는 **Lv.2 잼민이**가 나온다.
   전장에서는 **흙길로 들어가 길을 막고 주먹으로** 적을 때린다(발밑 하늘색 고리 = 아군). 끌어서 옮기면 흙길 위에 선다.
6. **배치**: 가족은 끌어서 원하는 곳에 놓는다(사거리 원 표시). 엄마·아빠·아기는 흙길에 놓으면 잔디로 밀려난다.
7. **자리 비움**: 다른 창에 다녀오면 엄마는 담배, 아빠는 누워 쉬고, 아기·잼민이는 존다(잼민이가 졸면 길이 뚫린다). 돌아오면 화들짝.

## 화면 / UI
- 맵은 화면을 가득 채우고 길·버튼 영역은 항상 보인다. 화면이 맵보다 넓으면 남는 곳은 숲(잔디) 무늬로 채운다.
- 세로 화면: 가족 생성 버튼은 길 아래 숲(맵 좌표 x 215-470, y 1205-1397), 그 아래 이동 버튼. 가로 화면은 맵 오른쪽.
- 돈 표시는 영상처럼 반투명 판 + 금화 + 노란 테두리 숫자, 숫자는 부드럽게 오르내린다.
- 버튼은 나타날 때·누를 때·흔들릴 때 모두 부드러운 애니메이션. 설명 문구 팝업·제목 글씨·웨이브 표시는 없다.
- 버튼 그림은 픽셀 그림 대신 **실제 사진**(금화·아기·엄마·잼민이·집)과 **직접 그린 벡터 그림**(학교·상점·회사·분양소·자물쇠·손, `art.js`). 이모지 없음.

## 움직임
- 로직은 1/60초 고정 스텝, 화면은 보간 렌더링(120Hz 화면에서도 부드럽게).
- 길 모서리를 둥글게 만들어 방향 전환이 매끄럽고, 걷기 사진은 즉시 넘기고 자세 바꾸기만 겹침 없이 크로스페이드.

## 캐릭터 인식 (스프라이트 추출)
- `tools/extract_sprites.py`: 게임 화면 스크린샷에서 잔디·흙길 색을 지워 농부 스프라이트 추출 → `assets/characters/farmer/`
- `tools/extract_family.py`: 집만 있는 장면을 사람이 있는 장면에 정렬(SIFT)해 차이로 엄마·아빠를 분리 → `assets/characters/family/`,
  집 클로즈업에서 잔디·꽃가루를 걷어내 `assets/house.png`
- `tools/extract_poses.py`: 앞모습·담배·누움·걷기·날아차기·만세 포즈. 만세는 자막 띠를 옷 색으로 복원. 모든 포즈를 같은 사람 크기로 저장
- `tools/extract_round5.py`: 일어선 아기(2자세)·아기 뒷모습·Lv.2 잼민이(아군 3자세)·학교. 건물 앞 사람은 빈 장면과의 차이로, 머리에 걸친 자막은 머리 윤곽으로 걷어냄
- `tools/extract_round4.py`: Lv.2 집(검은 배경 제거), 무너진 집, 금화, 하트, 2레벨 잼민이(줄지어 선 복사본으로 다리 분리), Lv.2 엄마, 걸어 나오는 아빠, 비는 아빠, 아기

## 조정 값 (`game.js` 상단)
`PRICE` 가격 · `ENEMY_LV` 잼민이 체력·보상 · `UNIT` 가족 공격력·사거리(아군 잼민이 `jam` 포함) · `GUARD_GAP` 막는 거리 · `HOUSE_LV` 집 레벨 · `SALARY` 월급 · `FAMILY_SLOTS` 기본 자리 · `PATH_CORNERS` 경로
