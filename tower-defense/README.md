# 가족 타워 디펜스

브라우저 2D 타워 디펜스 (개발 중).

```
python3 -m http.server 8080   →  http://localhost:8080/tower-defense/
```

## 게임 흐름
1. **전장**: 농부(적)가 웨이브마다 맵 오른쪽 아래에서 생성되어 흙길을 시계 방향으로 계속 돈다.
   적 머리 위에 체력바, 잡을 때마다 **+5원**.
2. **타워로 가기**: 빈 잔디밭 + 제목. 터(또는 `집 짓기`)를 누르면 *Lv.1 대출이 반인 집*이 떨어지며 꽃가루가 터지고,
   문이 열리며 **엄마·아빠가 걸어 나와** 집을 바라본다.
3. **가족 생성**: 집을 지어야 열린다. 엄마(슬리퍼)·아빠(리모컨)가 번갈아 생성되어 안쪽 잔디밭 자리에서 적에게 던진다.
   가격 10원부터 한 명마다 +5원, 최대 8명.

## 화면 / UI
- 맵은 화면을 가득 채우고 길·버튼 영역은 항상 보인다. 화면이 맵보다 넓으면 남는 곳은 숲(잔디) 무늬로 채운다.
- 세로 화면: 가족 생성 버튼은 길 아래 숲(맵 좌표 x 215-470, y 1205-1397), 그 아래 이동 버튼.
  가로 화면: 버튼을 맵 오른쪽 숲으로 옮긴다.
- 아이콘(코인·가족·집·칼·자물쇠)은 모두 직접 찍은 도트 SVG, 투사체는 캔버스로 그린다. 이모지 없음.
- 설명 문구 팝업은 없다. 잠긴 버튼·돈 부족은 버튼 흔들림으로만 알려준다.

## 움직임
- 로직은 1/60초 고정 스텝, 화면은 보간 렌더링(120Hz 화면에서도 부드럽게).
- 길 모서리를 둥글게 만들어 방향 전환이 매끄럽고, 걷기 사진은 초당 2.2번 전환, 방향이 바뀔 때만 짧게 크로스페이드.

## 캐릭터 인식 (스프라이트 추출)
- `tools/extract_sprites.py`: 게임 화면 스크린샷에서 잔디·흙길 색을 지워 농부 스프라이트 추출 → `assets/characters/farmer/`
- `tools/extract_family.py`: 집만 있는 장면을 사람이 있는 장면에 정렬(SIFT)해 차이로 엄마·아빠를 분리 → `assets/characters/family/`,
  집 클로즈업에서 잔디·꽃가루를 걷어내 `assets/house.png`

## 조정 값 (`game.js` 상단)
`ENEMY_H` / `FAMILY_H` 키 · `REWARD` 보상 · `START_MONEY` · `familyCost` · `FAMILY_SLOTS` 자리 · `FAMILY_STATS` 공격력·사거리 · `PATH_CORNERS` 경로
