# 가족 타워 디펜스

브라우저 2D 타워 디펜스 (개발 중).

```
python3 -m http.server 8080   →  http://localhost:8080/tower-defense/
```

## 게임 흐름 (유튜브 '코테고리' 가족 타워 디펜스 따라 만들기)
1. **전장**: 잼민이가 맵 오른쪽 아래 입구에서 **2초마다** 나와 흙길을 돈다(뒤돌아보지 않고 앞만 보고 걷는다).
   - 전장 아래(위에서부터): **잼민이 업그레이드**(길과 버튼 사이 주황 막대, 100원) · **가족 생성**(200원, 엄마·아빠를 부름) · 타워로 가기
   - 잼민이 Lv.1: 체력 10, 잡으면 5원 → 업그레이드 Lv.2: 체력 25, 잡으면 10원, **1초마다 빠르게** 나온다
2. **타워(집) Lv.1**: 집을 **끌어다 놓으면** 엄마·아빠가 걸어 나와 만세 → 전장으로.
3. **타워 추가(200원) = 아기 만들기**: 아빠가 빌고 → 하트 → 아기. 첫 아기 때 **아빠가 Lv.2(파란 옷)**로 나온다.
4. **대출이자 갚기(1000원)**: 집이 무너지고 Lv.2 집 → 집 위에 `엄마 강화`, 아래 왼쪽에 `건물` 버튼이 생긴다.
   `건물` 버튼을 누르면 화면이 왼쪽 건물 터로 미끄러지고, 거기에 학교·회사·상점·분양소를 짓는다(`집` 버튼으로 복귀).
5. **학교 → 애기 강화(500원)**: 아기가 **Lv.2 잼민이(아군)**가 되어 유닛 칸을 나와 **적이 나오는 입구**에 서서 주먹으로 막는다(입구컷).
6. **회사 → 아빠 강화(500원, Lv.2 아빠 필요)**: 아빠가 **Lv.3 가장**이 되어 6초마다 30원을 벌어 오고, **엄마가 각성**(공격력 3배).
7. **공격력**: 엄마 Lv.1 7 / Lv.2 9(슬리퍼) · 아빠 Lv.1 6 / Lv.2·3 8(**코딱지**) · 아기 3(젖병) · 아군 잼민이 13(주먹)
8. **배치**: 가족은 끌어서 옮긴다. 엄마·아빠·아기는 흙길에 놓으면 잔디로 밀려나고, 아군 잼민이는 흙길 위에 선다.
9. **자리 비움**: 다른 창에 다녀오면 엄마는 담배, 아빠는 누워 쉬고, 아기·잼민이는 존다. 돌아오면 화들짝.

## 화면 / UI
- 맵은 화면을 가득 채우고 길·버튼 영역은 항상 보인다. 화면이 맵보다 넓으면 남는 곳은 숲(잔디) 무늬로 채운다.
- 세로 화면: 잼민이 업그레이드(맵 좌표 y 1158-1216) · 가족 생성(y 1232-1397) · 이동 버튼(y 1412-1478). 가로 화면은 맵 오른쪽.
- 돈 표시는 영상처럼 반투명 판 + 금화 + 노란 테두리 숫자, 숫자는 부드럽게 오르내린다.
- 버튼은 나타날 때·누를 때·흔들릴 때 모두 부드러운 애니메이션. 설명 문구 팝업·제목 글씨·웨이브 표시는 없다.
- 그림은 픽셀 그림 대신 **실제 사진**(금화·집·학교·회사·가족)과 **직접 그린 벡터 그림**(상점·분양소·자물쇠·손·화살표, `art.js`). 이모지 없음.
- 공격할 때 화난 표시는 띄우지 않는다.

## 움직임
- 로직은 1/60초 고정 스텝, 화면은 보간 렌더링(120Hz 화면에서도 부드럽게).
- 길 모서리를 둥글게 만들어 방향 전환이 매끄럽고, 걷기 사진은 즉시 넘기고 자세 바꾸기만 겹침 없이 크로스페이드.

## 캐릭터 인식 (스프라이트 추출)
- `tools/extract_sprites.py`: 게임 화면 스크린샷에서 잔디·흙길 색을 지워 농부 스프라이트 추출 → `assets/characters/farmer/`
- `tools/extract_family.py`: 집만 있는 장면을 사람이 있는 장면에 정렬(SIFT)해 차이로 엄마·아빠를 분리 → `assets/characters/family/`,
  집 클로즈업에서 잔디·꽃가루를 걷어내 `assets/house.png`
- `tools/extract_poses.py`: 앞모습·담배·누움·걷기·날아차기·만세 포즈. 만세는 자막 띠를 옷 색으로 복원. 모든 포즈를 같은 사람 크기로 저장
- `tools/extract_round5.py`: 일어선 아기(2자세)·아기 뒷모습·Lv.2 잼민이(아군 3자세)·학교. 건물 앞 사람은 빈 장면과의 차이로, 머리에 걸친 자막은 머리 윤곽으로 걷어냄
- `tools/extract_round6.py`: Lv.2 아빠(파란 옷, 코딱지 파기·튕기기), Lv.3 아빠(정장), 인사하는 엄마, 아군 잼민이 주먹 자세, 회사 건물
- `tools/extract_round4.py`: Lv.2 집(검은 배경 제거), 무너진 집, 금화, 하트, 2레벨 잼민이(줄지어 선 복사본으로 다리 분리), Lv.2 엄마, 걸어 나오는 아빠, 비는 아빠, 아기

## 조정 값 (`game.js` 상단)
`PRICE` 가격 · `ENEMY_LV` 잼민이 체력·보상 · `UNIT` 가족 공격력·사거리(아군 잼민이 `jam` 포함) · `GUARD_GAP` 막는 거리 · `HOUSE_LV` 집 레벨 · `SALARY` Lv.3 아빠 월급 · `FAMILY_SLOTS` 기본 자리 · `PATH_CORNERS` 경로
