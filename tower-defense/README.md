# 가족 타워 디펜스 🛡️

브라우저 2D 타워 디펜스 (개발 중). 현재 1단계: **맵 + 캐릭터 인식/생성/이동**.

```
python3 -m http.server 8080   →  http://localhost:8080/tower-defense/
```

## 현재 구현
- **맵**: `assets/map.png` (688×1529). 흙길 중앙선을 픽셀 분석해 경로로 사용.
- **캐릭터 인식**: 스크린샷에서 잔디·흙길 색을 배경으로 판별해 제거하고 사람만 투명 PNG로 추출
  (`tools/extract_sprites.py`). 결과: `assets/characters/farmer/`
  - `side_*` 옆모습(좌/우 이동, 오른쪽은 반전) · `back_*` 뒷모습(위로 이동) · `front_*` 앞모습(아래로 이동)
- **생성**: 맵 **오른쪽 아래** 코너에서 튀어나오는 연출과 함께 생성 → 시계 방향으로 길을 따라 이동.
  2.5초마다 자동 생성(최대 6), `+ 캐릭터` 버튼으로 추가.
- **60fps**: 로직을 1/60초 고정 스텝으로 업데이트하고 화면은 보간 렌더링.
  이동 방향마다 해당 사진(포즈)을 번갈아 보여주며 걷는 모션(흔들림·기울기)을 매 프레임 계산.

## 조정 값 (`game.js` 상단)
`CHAR_H` 캐릭터 키 · `SPEED` 이동 속도 · `FRAME_RATE` 초당 포즈 전환 수 · `AUTO_SPAWN` 자동 생성 · `PATH` 경로
