# 가족 타워 디펜스

브라우저 2D 타워 디펜스 (개발 중).

```
python3 -m http.server 8080   →  http://localhost:8080/tower-defense/
```

## 게임 흐름
1. **전장**: 농부(적)가 맵 오른쪽 아래에서 웨이브 없이 계속 나와 흙길을 돈다. 시간이 갈수록 조금씩 자주·튼튼하게.
   적은 줄을 서서 걷고, 가끔 멈춰 두리번거리며, 맞으면 뒤로 밀리고, 체력이 낮으면 진땀을 흘린다. 잡으면 쓰러지며 **+5원**.
2. **타워로 가기**: 빈 잔디밭의 집을 **끌어다 원하는 곳에 놓으면** 집이 떨어지며 꽃가루가 터지고,
   엄마·아빠가 문에서 걸어 나와 돌아서서 **만세**. 집은 지은 뒤에도 끌어서 옮길 수 있고 엄마 아빠가 따라 걸어간다.
   **대출이자 갚기(1000원)** 판을 누르면 동전이 집으로 들어가고 엄마 아빠가 다시 만세.
3. **가족 생성**: 집을 지어야 열린다. 엄마·아빠가 번갈아 숲에서 걸어 들어와(아빠는 걷기 사진 4장) 자리를 잡는다.
   - 공격: 준비 자세 → 던지기(엄마 슬리퍼 / 아빠 리모컨, 아빠는 네 번에 한 번 날아차기) → 흰 바람 꼬리 → 맞은 자리 소용돌이
   - 감정: 화남·신남·하트·심심(말줄임)·진땀·쿨쿨·느낌표를 도트 말풍선으로 표시
4. **자리 비움**: 플레이어가 다른 창/탭에 다녀오면 엄마는 담배, 아빠는 누워 쉰다.
   돌아오면 잠깐 땡땡이를 들킨 채로 있다가 화들짝(느낌표) → 담배꽁초를 떨어뜨리고 다시 공격.

## 화면 / UI
- 맵은 화면을 가득 채우고 길·버튼 영역은 항상 보인다. 화면이 맵보다 넓으면 남는 곳은 숲(잔디) 무늬로 채운다.
- 세로 화면: 가족 생성 버튼은 길 아래 숲(맵 좌표 x 215-470, y 1205-1397), 그 아래 이동 버튼. 가로 화면은 맵 오른쪽.
- 돈 표시는 영상처럼 반투명 판 + 금화 + 노란 테두리 숫자, 숫자는 부드럽게 오르내린다.
- 버튼은 나타날 때·누를 때·흔들릴 때 모두 부드러운 애니메이션. 설명 문구 팝업·제목 글씨·웨이브 표시는 없다.
- 아이콘(코인·가족·집·칼·자물쇠·손)은 모두 직접 찍은 도트 그림. 이모지 없음.

## 움직임
- 로직은 1/60초 고정 스텝, 화면은 보간 렌더링(120Hz 화면에서도 부드럽게).
- 길 모서리를 둥글게 만들어 방향 전환이 매끄럽고, 걷기 사진은 즉시 넘기고 자세 바꾸기만 겹침 없이 크로스페이드.

## 캐릭터 인식 (스프라이트 추출)
- `tools/extract_sprites.py`: 게임 화면 스크린샷에서 잔디·흙길 색을 지워 농부 스프라이트 추출 → `assets/characters/farmer/`
- `tools/extract_family.py`: 집만 있는 장면을 사람이 있는 장면에 정렬(SIFT)해 차이로 엄마·아빠를 분리 → `assets/characters/family/`,
  집 클로즈업에서 잔디·꽃가루를 걷어내 `assets/house.png`
- `tools/extract_poses.py`: 앞모습·담배·누움·걷기·날아차기·만세 포즈. 만세는 자막 띠를 옷 색으로 복원. 모든 포즈를 같은 사람 크기로 저장

## 조정 값 (`game.js` 상단)
`ENEMY_H` / `FAMILY_H` / `RESIDENT_H` 키 · `REWARD` 보상 · `START_MONEY` · `LOAN_INTEREST` 대출이자 · `familyCost` · `FAMILY_SLOTS` 자리 · `FAMILY_STATS` 공격력·사거리 · `PATH_CORNERS` 경로
