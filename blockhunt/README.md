# BLOCK HUNT

활이나 총으로 NPC를 쓰러뜨리는 1인칭 웹 게임입니다. 플레이어와 NPC 모두 사진으로 받은 아바타와 같은 모습입니다.

```
# 저장소 최상위 폴더에서
python3 -m http.server 8080
http://localhost:8080/blockhunt/
```

## 조작 (로블록스와 같은 방식)

| | PC | 휴대폰 |
|---|---|---|
| 이동 | WASD | 왼쪽 아래를 누르면 그 자리에 조이스틱 |
| 시점 | 화면 클릭 후 마우스 | 화면을 끌기 |
| 점프 | Space | 점프 버튼 |
| 도구 꺼내기/넣기 | 1, 2 또는 핫바 칸 클릭 | 핫바 칸 누르기 |
| 쏘기 | 클릭 (활은 누르고 있다가 놓기) | 화면 톡 치기 (활은 누르고 있다가 떼기) |
| 자동차 | 운전석 쪽에 닿으면 탑승, 점프로 내리기 | 같음 |
| 채팅 | `/` | 채팅 버튼 |
| 메뉴 | Esc | 왼쪽 위 버튼 |

## 얼굴 사진 넣기

`faces/` 폴더에 감정 이름으로 PNG를 넣으면 그 감정일 때 그 얼굴이 나옵니다.

| 파일 | 감정 | 지금 |
|---|---|---|
| `neutral.png` | 평온 | 사진에서 가져옴 |
| `scared.png` | 겁에 질림 | 사진에서 가져옴 |
| `panic.png` | 공포·비명 | 없음 → 겁에 질린 얼굴로 대신 |
| `pain.png` | 고통 | 없음 → 겁에 질린 얼굴로 대신 |
| `sad.png` | 슬픔·울음 | 없음 → 겁에 질린 얼굴로 대신 |
| `dead.png` | 죽음 | 없음 → 겁에 질린 얼굴로 대신 |
| `angry.png` | 화남 | 없음 → 평온 얼굴로 대신 |
| `happy.png` | 기쁨 | 없음 → 평온 얼굴로 대신 |
