# 대한민국 철도 운전 (KOREA RAIL DRIVE)

서울·부산·대구·광주·대전·인천의 지하철과 KTX·SRT·ITX·무궁화호를 실제 노선 위에서 직접 운전하는 웹 열차 시뮬레이터입니다.
제주도·울릉도·독도를 포함한 한반도 남쪽 전체가 실제 크기(1 단위 = 1 m)로 이어진 하나의 지도입니다.

## 실행

```
# 저장소 최상위 폴더에서
python3 -m http.server 8080
# 브라우저(Chrome/Edge 권장)
http://localhost:8080/train/
```

- 파일을 더블클릭해서 열면 동작하지 않습니다. 반드시 웹서버로 여세요.
- three.js 는 저장소의 `vendor/` 를 그대로 씁니다. 글꼴(Noto Sans KR)만 인터넷에서 받습니다.

## 들어있는 것

- **노선 39개, 역 800여 곳**: 경부·호남·전라·경전·강릉·중앙·수서 고속선, 경부·호남·장항·경전·동해·경춘선, 공항철도, 수도권 1~9호선(지선 포함)·신분당선, 인천 1·2호선, 부산 1~4호선, 대구 1~3호선, 광주 1호선, 대전 1호선
- **실제 열차 11종**: KTX, KTX-산천, KTX-청룡, KTX-이음, SRT, ITX-새마을, ITX-마음, ITX-청춘(2층 객차), 무궁화호(디젤기관차), 수도권 광역전동차, 도시철도 전동차(노선 색)
- **지형**: Natural Earth 해안선·섬, 직접 그린 한강(서울 구간), 낙동강·금강·영산강·북한강·섬진강 등, 주요 산 50여 곳(한라산·지리산·북한산·남산…)과 태백·소백산맥
- **선로**: 역 사이를 직선+원곡선으로 다듬고, 지형에 맞춰 흙쌓기·땅깎기·터널·교량·고가를 자동으로 판단합니다. 지하철은 지하 터널, 2호선 성수~강변·신대방~신도림은 고가로 달립니다. 일반철도는 실제 철도 선형(Natural Earth)을 따릅니다
- **역**: 승강장, 노란 안전선, 정지 위치 표지, 역명판(이전·다음 역), 지하역의 스크린도어·조명·노선 색 띠, 지상역 지붕·역사·육교
- **도시**: 역 주변 업무지구 고층 빌딩, 남향으로 늘어선 아파트 단지, 빌라·상가, 농촌 농가와 비닐하우스, 가을 산림. 밤에는 창문 불이 켜집니다
- **랜드마크**: 롯데월드타워, N서울타워, 63빌딩, 국회의사당, 경복궁 근정전, 숭례문, DDP, 무역센터, 잠실·상암 경기장, 광안대교, 인천대교, 해운대 엘시티, 부산타워, 83타워, 동북아트레이드타워, 부산국제금융센터

## 운전 (실제 순서)

1. 팬터그래프 상승 `P` → 주차단기가 들어올 때까지 대기 (디젤은 엔진 시동)
2. 출입문 닫기 `C` → 출입문 표시등 점등 (열린 상태에서는 역행 불가)
3. 역전기 전진 `F` (후진 `R`)
4. 제동 풀기 `D`, 역행 `W`
5. 제동 `E`/`S` 로 정지 위치에 맞춰 세우고 출입문 열기 `O`

| 키 | 기능 | 키 | 기능 |
|---|---|---|---|
| `W` `S` | 역행 올림/내림 (원핸들: 핸들 위/아래) | `E` `D` | 제동 강하게/약하게 |
| `Backspace` | 비상제동 | `N` | 역행 끊기 |
| `F` `R` | 역전기 | `O` `C` | 출입문 열기/닫기 |
| `H` | 기적 | `P` | 팬터그래프/엔진 |
| `L` | 전조등 | `V` | 시점(운전석·추적·자유·선로변) |
| `M` | 지도 | `Tab` | 계기판 숨기기 |
| `Esc` | 일시정지 | 마우스 | 핸들 끌기, 운전석에서 둘러보기 |

- 고속열차·간선형은 **투핸들**(역행 P1~P8 / 제동 B1~B7·비상), 지하철은 **원핸들 주간제어기**(P4~N~B7~EB)
- 견인력은 출력·점착 한계, 주행저항(구름·공기, 터널에서 증가), 기울기, 제동통 압력 지연(BC), 주공기통(MR)과 공기압축기를 계산합니다
- 곡선 반경으로 제한속도를 정하고 **ATC/ATS** 가 감시합니다. 넘으면 경보, 더 넘으면 자동 제동
- 정차하면 정지 위치 오차(정확 ±1 m / 양호 ±3 m / 보통 ±8 m)를 기록하고, 종착역에서 결과표를 보여줍니다

## 소리 (전부 실시간 합성)

VVVF 인버터 소리(속도에 따라 음이 바뀌는 단계), 견인 전동기, 고속열차 송풍기, 디젤 엔진·터보, 레일 이음매 "덜컹", 구름·바람 소리, 터널 잔향, 철교 울림, 곡선 쇳소리, 정차 직전 제동 쇳소리, 공기 배출음, 공기압축기, 출입문 차임·닫힘 소리, 기적, ATC 경보, 승강장 웅성거림, 안내 차임 + 한국어 음성 안내방송(브라우저 음성 합성)

## 사실과 다른 점

- 역 좌표는 실제 위치를 바탕으로 한 근사값이라 수십~수백 m 차이가 날 수 있습니다
- 건물은 랜드마크를 빼면 도시 규모·역과의 거리에 맞춰 자동 생성한 것으로, 실제 건물 하나하나와 같지 않습니다
- 지형 높이는 실제 고도 자료가 아니라 해안선·강·산맥·주요 산 위치로 만든 근사 지형입니다

## 구조

```
train/
  index.html, style.css
  data/geo.json          해안선·섬·강·일반철도 선형 (tools/build-geo.mjs 로 생성)
  tools/build-geo.mjs    Natural Earth 10m 자료 → geo.json
  js/data/stations.js    노선·역 (이름 위도 경도 구조)
  js/data/trains.js      열차 제원
  js/data/places.js      도시·산·산맥·강·섬·랜드마크
  js/geo.js              좌표 변환, 지형 높이
  js/network.js          선로 곡선·고저·터널/교량·제한속도·공용 구간
  js/world.js            하늘·바다·빛·타일 LOD·작업 대기열
  js/builders.js         지형·건물·나무·선로·역·랜드마크 생성
  js/trainmodel.js       열차 3D 모델
  js/sim.js              운전 물리·ATC·출입문·정차·안내방송
  js/audio.js            소리 합성
  js/hud.js, js/map.js   계기판, 지도
  js/main.js             화면 전환·메뉴·운행 준비·열차 만들기·루프
```

`geo.json` 다시 만들기: [Natural Earth](https://github.com/nvkelso/natural-earth-vector) 의 `ne_10m_land`, `ne_10m_minor_islands`, `ne_10m_rivers_lake_centerlines`, `ne_10m_railroads` GeoJSON 을 한 폴더에 받은 뒤
`node train/tools/build-geo.mjs <그 폴더>`
