# SKILL RPG ⚔ — 픽셀 스킬 테스트 버전

브라우저에서 바로 실행되는 2D 픽셀 스킬 RPG 테스트 빌드입니다. 설치·빌드 없이 `index.html` 하나로 동작합니다.

```
python3 -m http.server 8080   →  http://localhost:8080/skillrpg/
(skillrpg/index.html 을 더블클릭해서 열어도 실행됩니다)
```

## 화면 구성
| 영역 | 내용 |
|---|---|
| 📜 상태창 (맨 위) | 캐릭터 미리보기 + 머리·몸·다리 장비 칸 + 능력치, 그리고 스킬·머리·몸·다리 버튼 목록. 스킬 → 슬롯 장착/테스트 시전, 장비 → 착용/해제 |
| ⚔ 스킬 테스트 | 왼쪽 플레이어(상태창과 같은 모습), 오른쪽 슬라임. **일반 공격 / 크리티컬 공격 테스트 버튼** (Space / C), 스킬 칸 4개 (1~4), 자동 시전 |
| 🎁 뽑기 | **스킬 뽑기 / 장비 뽑기** 탭, 상자 4종 × 1회·10회. 등급이 오를수록 상자 빛 색이 단계별로 바뀌고 개봉 연출이 화려해짐 |

## 상자 확률
| 상자 | 비용 | 일반 | 희귀 | 에픽 | 고급 | 전설 | 신화 |
|---|---|---|---|---|---|---|---|
| 나무 상자 | 100 | 60% | 35% | 5% | | | |
| 강철 상자 | 300 | 35% | 45% | 19% | 1% | | |
| 황금 상자 | 1000 | 35% | 30% | 20% | 10% | 5% | |
| 신화 상자 | 5000 | | 35% | 30% | 20% | 10% | 5% |

> 신화 상자는 요청 값의 합이 105%여서 희귀를 40% → 35% 로 맞췄습니다.

## 스킬
- **기본 (항상 보유)** 일반 공격(돌진 베기) · 크리티컬 공격(기 모으기 → X자 베기, 반드시 치명타)
- 에픽 이상 스킬은 화면 위아래 레터박스 연출

**뽑기 스킬 17종**
- **일반** 파이어볼 · 아이스 샤드 · 바위 투척 · 바람 베기
- **희귀** 체인 라이트닝 · 독안개 · 그림자 단검 · 화염 기둥
- **에픽** 메테오 · 블리자드 · 썬더 스톰
- **고급** 드래곤 브레스 · 블랙홀
- **전설** 천상의 성검 · 불사조
- **신화** 오메가 캐논 · 시간 정지

## 장비 18종 (부위 × 등급)
- 머리 → 치명타 확률, 몸 → 공격력, 다리 → 쿨타임 감소
- 중복 획득 시 레벨 업 (스킬 +15% 피해, 장비 +10% 능력치)

## 기술
- 256×144 캔버스에 모든 그래픽을 픽셀 단위로 직접 그림 (스프라이트·파티클·이펙트)
- 효과음은 WebAudio 로 실시간 합성 (버튼, 스킬별 소리, 상자 흔들림·개봉 팡파레)
- 진행 상황은 브라우저 localStorage 에 저장
- 폰트: [Galmuri](https://github.com/quiple/galmuri) (SIL OFL 1.1, `fonts/OFL.md`)
