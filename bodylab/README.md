# BODY LAB — 해부 실험실 🩻

야외 실험장에서 여러 무기·장치·자동차로 실험체(사람 1명)에게 일어나는 일을 **오른쪽 엑스레이 화면**으로 지켜보는 1인칭 3D 웹 게임입니다.

```
python3 -m http.server 8080   →   http://localhost:8080/bodylab/
```
(느리면 화면 아래 **최적화** 버튼 또는 `O` 키)

## 들어있는 것
| 항목 | 내용 |
|---|---|
| 사람 | 실험체 1명 + 플레이어. 둘 다 같은 몸(래그돌 물리 + 근육으로 자세 유지). 팔·손은 업로드한 손·팔 3D 모델을 그대로 써서 뼈·손가락 관절을 붙였고, 몸 피부도 그 모델 텍스처로 맞춤 |
| 해부 | 뼈(두개골·척추·갈비뼈·골반·팔다리·손가락뼈), 근육, 장기(뇌·심장·폐·간·위·비장·신장·창자·방광) |
| 상처 | 총알 입구/출구, 베임, 찔림, 타박상, 화상, 으깨짐 — 피부에 그려지고 피가 흘러내림. 장기 파괴·골절·출혈량·산소 계산 |
| 엑스레이 | 오른쪽 화면. 총알이 몸을 지나간 길(빨간 선), 박힌 총알, 손상된 장기·부러진 뼈(빨갛게), 날아가는 총알. 보기: 전체/뼈/근육/장기, 대상: 실험체/나 |
| 슬로우 모션 | 맞으면 자동(끌 수 있음) + Q 키. 비명·소리도 느리고 낮게 |
| 감정 | 평온·불안·공포·고통·공황·절망·질식 공포·의식 없음·사망 — 표정(눈썹·눈꺼풀·입), 행동(손 들기, 도망, 상처 누르기), 말풍선, 비명·신음 |
| 도망 | 다치거나, 총소리·빗나간 총알에 놀라거나, 오래 겨눔당하거나, 칼·방망이를 들고 다가가거나, 수류탄이 떨어지면 반대쪽으로 전력 질주 — 벽 뒤(안 보이는 곳)를 골라 뛰고, 뛰면서 뒤를 돌아보고 비명을 지름. 다친 채 뛰다 넘어지기도 하고, 다리를 다치면 절뚝이며 느려짐. 멀리 숨으면 웅크리고 머리를 감싼 채 떨고, 궁지에 몰려도 웅크림. 다리가 부러지면 팔로 바닥을 짚고 기어서 도망 |
| 장기 튀어나옴 | 큰 피해(산탄총 근거리, 폭발, 톱, 프레스)를 받으면 장기가 몸 밖으로 튀어나오고 창자가 끌려 나옴 |
| 피 | 피 방울·안개, 벽/바닥에 튄 자국, 피 웅덩이, 물속 피 |
| 체력 | 체력바·혈액량(플레이어, 실험체, 머리 위) |
| 무기 | 권총, 돌격소총, 산탄총, 저격소총, 칼, 야구 방망이, 수류탄 — 아래 **무기** 버튼(Tab)으로 고르는 창. 1인칭으로 손에 쥔 모습 |
| 맵 | 야외: 하늘·해·그림자, 잔디, 도로(순환로), 나무, 창고, 먼 언덕. 가운데 콘크리트 실험장에 벽과 장치들 |
| 벽·물·장치 | 콘크리트 벽, 저수지(부력·헤엄·익사), 회전 톱, 유압 프레스, 가시 함정, 고압 전기 바닥, 발사대 |
| 자동차 | 빨간 차에 다가가 E 로 타고 운전 (가속·브레이크·후진·조향·핸드브레이크 미끄러짐). 1인칭 운전석에서 손이 운전대를 잡음. 실험체를 치면 날아가고 다침 — 차가 다가오면 실험체가 피해 도망 |
| 시점 | 1인칭 (쓰러지면 몸을 바깥에서 봄). 우클릭 정조준 |
| 최적화 모드 | 해상도·그림자·블룸·물 굴절·나무 수·물리 계산을 낮춰 빠르게 (설정 기억) |
| 살아나기 | 실험체 살리기(R) / 나 살리기(G) 버튼 |

## 조작
`WASD` 이동 · `Shift` 달리기 · 마우스 조준 · 좌클릭 공격 · 우클릭 정조준(저격소총은 확대) · `Tab` 무기 고르기 · `1~7`/휠 무기 · `F`(누르고 있기) 실험체 잡아 끌기 · `E` 차 타기/내리기 · 운전 `W/S/A/D` + `Space` 핸드브레이크 · `Q` 슬로우 모션 · `X` 엑스레이 보기 · `C` 엑스레이 대상 · `R` 실험체 살리기 · `G` 나 살리기 · `O` 최적화 모드 · `H` 조작법 · `Esc` 마우스 풀기

## 사용한 모델
"Hand and arm - Zbrush sculpt" by Andy Woodhead (https://sketchfab.com/Andywoodhead), CC BY 4.0 (https://creativecommons.org/licenses/by/4.0/) — `../handvr/models/` 의 변환본을 같이 씀. 바꾼 것: 오른팔은 좌우 반전, 뼈·손가락 관절과 스킨 가중치를 게임이 불러올 때 계산, 피부 일부를 잘라 몸 피부 무늬로 사용.
