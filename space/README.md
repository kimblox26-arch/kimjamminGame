# 구슬 우주 (알파) 🪐

3D 공간에서 **같은 크기의 동그란 구슬로 이루어진 천체**들을 충돌시키는 우주 물리 게임입니다.
태양계 행성을 검색해 원하는 곳에 놓고, 끌어서 속도를 주면 실제 물리법칙대로 움직입니다.

## 실행 방법

```
# 저장소 최상위 폴더에서
python3 -m http.server 8080
# 브라우저로 접속
http://localhost:8080/space/
```

3D 그리기에 쓰는 three.js 는 저장소 `vendor/` 에 들어 있어 인터넷 연결 없이 동작합니다.

## 조작

| 동작 | 방법 |
|---|---|
| 구슬 개수 | 검색창 아래 `구슬 개수`에 입력 (20 ~ 20,000). 다음에 추가하는 행성이 이 개수의 같은 크기 구슬로 만들어짐 |
| 행성 추가 | 왼쪽 위 검색창에 이름 입력(한글/영어) → 고르기 → 화면 중심을 지나는 수평면 위를 누른 채 **끌어서 속도·방향**을 정하고 놓기 (그냥 누르면 정지 상태로 놓임) |
| 회전 | 빈 곳을 끌기 / 한 손가락 |
| 화면 이동 | 오른쪽 버튼(또는 Shift) 끌기 / 두 손가락 |
| 확대·축소 | 마우스 휠 / 두 손가락 벌리기·오므리기 |
| 시간 | 오른쪽 위 `⏸`(Space) 일시정지, 슬라이더로 배속 (1초 = 1초 ~ 약 1일) |
| 취소 / 검색 | `Esc` / `/` |

## 들어있는 물리

- **천체 = 구슬 덩어리**: 행성마다 실제 질량·반지름·내부 구조(핵·맨틀·얼음·수소층 밀도)·자전 주기(NASA 자료)로, 정한 개수만큼 같은 크기 구슬을 공 모양으로 채웁니다. 구슬 질량은 그 구슬이 놓인 층의 밀도를 따릅니다.
- **중력**: 모든 구슬끼리 뉴턴 만유인력 (3차원).
- **충돌**: 구슬끼리 비탄성 충돌(반발계수) + 마찰 + 구슬 자체의 회전. 운동량·각운동량이 보존되고 충돌로 운동에너지가 사라집니다.
- **로슈 한계**: 구슬 사이에 접착력이 없어서 천체는 자기 중력으로만 뭉쳐 있습니다. 더 무거운 천체에 가까이 가면 기조력이 자기 중력을 이겨 실제처럼 찢어집니다. 화면의 붉은 점선은 유체 로슈 한계 `d = 2.44 · R · (ρ주천체/ρ위성)^(1/3)` 입니다.
  구슬 더미는 실제 '잔해 더미' 천체처럼 약간의 버티는 힘이 있어 점선보다 조금 안쪽에서 부서집니다 (시험, 구슬 500개씩: 목성 곁 화성은 점선의 88%에서는 버티고 77%에서 부서져 파편 대부분이 궤도에 남음).
- **고리·위성**: 따로 만들어 넣는 규칙은 없습니다. 찢어진 파편은 궤도를 돌며 서로 부딪쳐 에너지를 잃고 고리로 퍼지고, 로슈 한계 밖으로 나간 파편은 자기 중력으로 다시 뭉쳐 위성이 됩니다. 거대 충돌로 튀어나간 파편이 궤도에서 뭉쳐 위성이 되기도 합니다.
