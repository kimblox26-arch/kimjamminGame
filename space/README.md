# ORBITER 🚀 — 궤도역학 기반 웹 우주비행 시뮬레이터

브라우저에서 바로 돌아가는 2D 우주비행 시뮬레이터입니다.
**로켓을 부품 단위로 조립해서**, 실제 케플러 궤도역학 위에서 발사하고, 궤도에 올리고,
달에 내려앉고, 다른 행성까지 갑니다.

```
로컬 웹서버로 space/index.html 을 여세요.

  cd <저장소 루트>
  python3 -m http.server 8080
  → http://localhost:8080/space/
```

> ES 모듈을 쓰므로 파일 더블클릭(`file://`)으로는 실행되지 않습니다. 반드시 웹서버로 여세요.
> 외부 라이브러리를 전혀 쓰지 않습니다. 네트워크 없이도 그대로 동작합니다
> (구글 폰트만 있으면 더 예쁘고, 없으면 시스템 폰트로 대체됩니다).

## 2. 헬리오스 항성계

실제 태양계를 그대로 옮기면 저궤도 진입에만 9 km/s 가 들어 한 번의 비행이 너무 길어집니다.

## 3. 조작

| 키 | 동작 |
|---|---|
| `Space` | 스테이지 (점화 · 분리 · 낙하산) |
| `A` / `D` | 좌우 회전 (짐벌 · 반작용 휠 · 가동핀) |
| `Shift` / `Ctrl` | 스로틀 증가 / 감소 |
| `Z` / `X` | 스로틀 최대 / 정지 |
| `T` | SAS 자세 안정 |
| `R` | RCS 추력기 |
| `G` | 착륙 다리 |
| `P` | 낙하산 전개 |
| `M` | 궤도 지도 |
| `,` / `.` | 시간 가속 감소 / 증가 |
| `1`~`6` | SAS 방향: 진행 · 역행 · 구심 · 원심 · 목표 · 지표역행 |
| `C` | 카메라 전환 (추적 / 기체 고정 / 자유) |
| `F5` / `F9` | 빠른 저장 / 불러오기 |
| `Esc` | 일시정지 |

설계실: 좌클릭 배치·선택, 드래그 이동, 우클릭 삭제, 휠 확대, 우클릭 드래그 화면 이동, `X` 좌우 대칭 복제, `Ctrl+Z`/`Ctrl+Y` 실행취소.

## 4. 처음이라면

1. **바로 발사** → 오비터 I 이 발사대에 올라갑니다.
2. `Space` 로 점화.
3. 고도 1 km 부터 `D` 를 눌러 동쪽으로 조금씩 눕힙니다 (중력 선회).
4. 원점(Ap)이 80 km 를 넘으면 스로틀을 끄고, `M` 으로 지도를 열어 Ap 에 도달할 때까지 시간을 가속합니다.
5. Ap 근처에서 진행 방향(`1`)으로 정렬하고 다시 점화 — 근점(Pe)이 70 km 를 넘으면 궤도 진입입니다.

귀찮으면 화면 왼쪽 아래 **오토파일럿 → 상승** 버튼을 누르면 알아서 궤도에 올려줍니다.
착륙도 **오토파일럿 → 착륙** 이 이탈 분사부터 접지까지 전부 처리합니다.

## 6. 물리 모델에 대해

- **궤도**: 활성 기체는 현재 SOI 천체 중심 관성계에서 직접 적분합니다(심플렉틱 오일러 + 고정 스텝).
  궤도 요소는 매 스텝 상태벡터에서 역산해 HUD·지도·기동 노드에 씁니다.
  SOI 경계를 넘으면 좌표계를 갈아타고(`transferFrame`) 속도를 상대속도로 변환합니다.
- **대기**: 척도고도 기반 지수 감소 + 상단 부드러운 소멸. 온도는 대류권 기온감률과
  성층권 상승을 이어 붙이고, 밀도는 이상기체 상태방정식으로 냅니다.
- **항력**: 전면 단면적 하나로 계산합니다. 부품별 옆면적을 더하면 탱크를 길게 쌓을수록
  항력이 폭증해(실제와 반대) 로켓이 궤도에 오르지 못합니다.
  천음속 구간(M≈1)에서 항력계수가 2.6배까지 치솟는 "음속 장벽" 을 재현합니다.
- **안정성**: 압력중심이 무게중심보다 뒤(아래)에 있어야 복원 모멘트가 생깁니다.
  설계실의 정적 안정 마진이 음수면 상승 중 뒤집힙니다 — 하단에 핀을 다세요.
- **연료**: 엔진은 자기 **연료 그룹**(같은 분리기에 함께 떨어져 나갈 부품들)에서만
  추진제를 뽑습니다. 그래서 1단 엔진이 상단 탱크를 빨아먹지 않습니다.
- **가열**: Sutton-Graves 유사식으로 정체점 열유속을 내고, 삭마재가 타면서 열을 막습니다.
  진행 방향을 정면으로 맞는 부품일수록 더 뜨거워집니다.

## 7. 저장

모든 데이터는 브라우저 `localStorage` 에 `orbiter:` 접두사로 저장됩니다.

- `orbiter:settings` — 그래픽 · 사운드 · 난이도 · 조작
- `orbiter:blueprints:*` — 설계도 (JSON 파일로 내보내기·불러오기 가능)
- `orbiter:saves:*` — 비행 상태 (빠른 저장 F5 / 자동 저장)
- `orbiter:progress` — 자금 · 과학 · 업적 · 방문 천체 · 기록

설정 화면에서 전부 초기화할 수 있습니다.
