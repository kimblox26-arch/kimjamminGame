# AMONG US — 웹 팬 제작판

브라우저에서 돌아가는 어몽어스 팬 제작 게임입니다. 그림과 소리는 모두 코드(SVG·Canvas·WebAudio)로 그렸고, 외부 라이브러리 없이 **Node.js만 있으면** 실행됩니다.

> 비상업적 팬 프로젝트이며 Innersloth와 관련이 없습니다. 원작 © Innersloth LLC.

## 실행

```bash
cd amongus
npm start            # = node server/index.js  (Node 18 이상)
```

- 이 컴퓨터: `http://localhost:8080`
- 같은 와이파이의 휴대폰/PC: 서버를 켜면 콘솔에 나오는 `http://192.168.x.x:8080` 주소로 접속
- 온라인(멀리 있는 친구): 서버를 인터넷에 올리세요 (VPS, Render, Fly.io 등). 리버스 프록시 뒤라면 `TRUST_PROXY=1`

| 환경 변수 | 설명 | 기본값 |
|---|---|---|
| `PORT` | 포트 | 8080 |
| `MIN_PLAYERS` | 게임 시작 최소 인원 (혼자 테스트할 땐 2) | 4 |
| `SMTP_HOST` `SMTP_PORT` `SMTP_USER` `SMTP_PASS` `SMTP_FROM` | 보호자 인증 메일 발송용 SMTP (465 포트, TLS) | 없음 |
| `DATA_DIR` | 계정 저장 폴더 | `amongus/data` |
| `TRUST_PROXY` | `X-Forwarded-For` 신뢰 | 꺼짐 |

SMTP를 설정하지 않으면 메일은 실제로 발송되지 않고 **`/outbox`(개발용 보낸편지함)** 에 표시됩니다. 인증 링크를 거기서 눌러 테스트할 수 있습니다.

## 들어있는 것

**메인 화면** — 상단바(계정 아이콘 · 상태 불빛 · 친구 코드 · 친구), 플레이/인벤토리/상점, 게임 뉴스/내 계정/설정, 크레딧, 우주 창(떠다니는 크루원), 오른쪽 아래 +1 별(매일 콩 50개).
로딩 중에는 오른쪽 아래 **초록 크루원이 제자리에서 회전**하고, 로딩이 끝나면 화면 가운데에 **공지**가 뜹니다. 공지는 **게임 뉴스** 버튼으로 다시 볼 수 있습니다.

**연령 확인 · 계정과 상태 불빛**

| 불빛 | 조건 | 채팅 | 이름 변경 | 친구 | 온라인 |
|---|---|---|---|---|---|
| 🟢 초록 | 로그인한 계정 (만 14세 이상) | 자유 + 빠른 | 가능 | 가능 | 가능 |
| 🩷 핑크 | 게스트 | 빠른 채팅만 | 불가 (무작위 이름) | 불가 | 가능 |
| 🩵 청록 | 만 14세 미만 | 빠른 채팅만 | 불가 (무작위 이름) | 불가 | **보호자 이메일 인증 후** |

채팅 제한은 서버에서 막기 때문에 클라이언트를 고쳐도 우회되지 않습니다.

**플레이** → 로컬 / 온라인 / 플레이 방법 / 연습 모드
- **로컬**: 같은 와이파이(같은 공유기)에 연결된 기기에만 보이고 참가할 수 있는 "주최" 화면
- **온라인**: 게임 만들기 · 코드 입력(6글자) · 게임 찾기. 지역은 **북미/유럽/아시아**로 나뉘며, 채팅 언어를 **한국어로 고르면 아시아 서버**에서 열립니다.
- 게임 만들기: 게임 유형(클래식/숨바꼭질), 맵, 용량, 태그, 지역, 역할 / 채팅 탭에서 자유·빠른 채팅과 채팅 언어
- 게임 찾기: 지역 선택, 필터(게임 유형·맵·임포스터 수·역할·로비 크기·태그 / 채팅 유형·언어), 새로 고침, 온라인 수송선 수
- 맵 5개 모두 플레이 가능: **THE SKELD · MIRA HQ · POLUS · THE AIRSHIP · THE FUNGLE**
- **연습 모드**: 맵과 역할(크루원/임포스터)을 골라 더미들과 자유롭게 둘러보기

**설정** — 일반(음악·효과음·조작 방식·조이스틱 크기·채팅 검열·초대 허용·스트리머 모드·색맹 모드) / 그래픽(전체 화면·해상도·프레임 제한·조명·배경 애니메이션) / 데이터(맞춤 광고·통계·개인정보·데이터 내보내기/삭제·계정 삭제). **게임 방 안에서는 데이터 탭이 사라지고** "게임 나가기"가 생깁니다.

**내 계정** — 계정(캐릭터 카드: 키·무게·레벨·경험치, 👁 눌러 친구 코드 보기/복사, 계정 관리, 이름 변경은 초록불만) · 통계 · 보상 교환

**인벤토리/상점** — 색상 18종, 모자·바이저·스킨·애완동물·명판. 콩으로 구매, 보상 코드: `IMPOSTORMOON`, `HAPPY8TH`, `GHOST2026`, `SWEETCANDY`

**로비** — 드롭십, 노트북/상자로 꾸미기(같은 색 중복 불가), 방 설정 패널(용량·프리셋·개인 정보 보호·편집/보기), 설정 변경 기록, 시작 카운트다운, 강퇴/차단, 친구 초대, PING 표시

**게임 (최신 버전 기준)**
- **맵 5종** — 원작 맵 데이터(좌표)를 바탕으로 방·복도·환풍구 연결·문·임무 위치를 배치
  - THE SKELD: 자동으로 열리는 문 13개, 카메라 4대, 관리실 지도
  - MIRA HQ: 소독실(양쪽 자동문), 환풍구 하나의 네트워크, 문 기록 센서 3개, 통신 방해(두 곳 코드 입력)
  - POLUS: 눈 덮인 야외, 차단기를 재설정해야 열리는 문 12개, 소독실 2곳, 지반 안정 장치(60초), 카메라 6대, 바이탈
  - THE AIRSHIP: 시작 위치 선택, 사다리 3개, 갭 룸 이동 플랫폼, 전기실 미로, 문 패널, 추락 경로 회피, 조명 3곳 수리
  - THE FUNGLE: 해변·정글·고원, 사다리·짚라인, 두드려 여는 문, 버섯 혼란, 망원경
- **미니게임 50종 가까이** — 배선·카드·업로드/다운로드·스캔·원자로·소행성·전력 전환·연료·샘플 검사(60초)·Wi-Fi 재부팅(60초)·수로·날씨 노드 등 맵별 임무와 사보타주/문 수리 화면
- **역할 13종** — 크루원·임포스터·기술자·과학자·수호천사·추적자·노이즈 메이커·탐정·판사·형상 변환자·팬텀·바이퍼·인플루언서(유령)
- 처치·벤트·사보타주, 시체 신고·긴급 버튼, 토론/투표/추방, 유령, 그림자 시야(벽에 가려짐, 조명 고장 시 축소), 지도, 카메라/관리실/바이탈/문 기록, 숨바꼭질 모드, 승리/패배 화면과 보상
- **그래픽** — 정적 맵 타일 캐시, 높이 있는 벽·바닥 텍스처·소품, 벽에 가려지는 그림자 시야, 문·효과, 고해상도 크루원

**설정 창의 비밀 mod** — 설정 창 위에 앉아 있는 크루원을 10번 누르면 비밀번호 창이 뜹니다. 비밀번호가 맞으면 왼쪽 위에 끌어서 옮길 수 있는 동그란 **mod** 버튼이 생기고, 누르면 계정·플레이어·설정·시스템 해킹 메뉴가 열립니다. 비밀번호는 서버에서만 확인하며 환경 변수 `MOD_PASSWORD`로 바꿀 수 있습니다.

## 브라우저 전용판 (서버 없이)

```bash
node tools/build-web.mjs        # → dist/web (정적 파일만)
```

서버 게임 로직을 페이지 안에서 돌리는 판입니다. 아무 웹 호스팅에나 올리면 바로 플레이할 수 있습니다(`index.html`은 본문만 있는 버전, 일반 호스팅은 `full.html`).
방을 만들면 **AI 봇 7명**이 자동으로 들어오고, 대기실 패널의 −/+ 로 봇 수를 바꿀 수 있습니다. 계정·친구·여러 사람 접속은 서버판에서만 됩니다.

**AI 봇** (서버판에서도 대기실에서 추가 가능) — 크루원 봇은 임무를 하고, 시체를 보면 신고하고, 사보타주를 고치고, 처치를 목격하면 회의에서 지목합니다. 임포스터 봇은 임무하는 척 돌아다니다 보는 사람이 없을 때 처치하고, 가끔 사보타주를 겁니다.
